# 原始输入协议 — 多人多角色模式：《灰区：撤离》"黑潮"战役

> 当多个玩家各自控制不同角色时使用本协议。

---

## 一、DM 主权

```
DM 拥有最终裁决权。
玩家对裁决有异议 → DM 参考规则书解释 → 最终裁定
不允许无限争论打断游戏。
```

---

## 二、行动收录机制

### 2.1 行动提交

```
每个玩家将当前行动写入 playground.md 对应区域：
[角色A]
> 移动到废车掩体后方
> 向最近的敌人开火

[角色B]
> 掩护射击，告诉A"我掩护你"
> 搜索地上的尸体
```

### 2.2 DM收集与执行

```
1. DM 等待所有玩家提交完毕（或设定时限如1分钟）
2. 收集所有行动声明
3. 按先攻顺序（战斗中）或声明顺序（非战斗）执行
4. 统一输出结果
```

---

## 三、输入格式

| 格式 | 示例 | 处理 |
|------|------|------|
| **动作指令** | "我向铁门扔手雷" | 标准执行 |
| **对话指令** | 对NPC说："给我钥匙。" | 执行对话，可能触发NPC反应 |
| **信息询问** | "这间房里有藏身的地方吗？" | DM根据角色所知回答 |
| **保留/等待** | "我等他们先走再行动" | 标记为"等待中"，待触发后执行 |
| **预案** | "如果有人进门，我就开枪" | 写入playground，触发时自动执行 |

---

## 四、队伍角色分配

```
建议每队4-6人，覆盖以下战术定位：

- 突击手（前排接敌）
- 侦察兵（先行探路/信息侦察）
- 狙击手（远程火力支援）
- 军医（急救/状态恢复）
- 技师（破解/维修/制作）
- 谈判（社交/NPC交涉）

不全覆盖也可玩，但难度对应提升。
```

---

## 五、裁决规则

### 5.1 时序竞争

```
多人同时声明冲突行动：
  → 全部投AGI+RES/2 对抗，胜者先执行
  → 或由先攻顺序决定（战斗中）
```

### 5.2 协作行动

```
多人协作同一任务（如一起推倒墙）：
  → 选主执行者，辅助者提供修正
  → 1辅助=+5, 2辅助=+10, 3辅助=+15（上限）
```

### 5.3 隐藏行动

```
玩家希望向队友保密行动：
  → 用 DM 私信（如有）
  → 或在 playground.md 中用"仅DM可见"标记
  → DM 执行但不公开于队友日志
```

---

## 六、信息隔离

```
物理分离的队伍：
  - A队看不到B队正在遭遇什么
  - 对话不得引用分离后的信息
  - DM托管的NPC同受信息限制
  - 仅特殊手段（无线电）可跨队通讯

无线电通讯：
  - 通讯距离500m（基础无线电）
  - 地下/厚墙体阻挡信号
  - 通话内容可被附近敌人监听（PER检定）
```
