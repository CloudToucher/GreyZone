# 战斗一张纸：《灰区：撤离》黑潮

> DM 在战斗轮中只看这张卡。不翻其他文件。

---

## 一轮节奏

```
先攻顺序 → 每人: [1标准 + 1快速 + 自由动作] → 检查血槽/压制/流血 → 下一轮
```

## 标准动作
射击 / 近战 / 投掷 / 急救(INT+急救 DC15→1重→轻) / 拖曳濒死队友(半速)

## 快速动作
换弹 / 切武器 / 闪避 / 快速搜索 / 探头(掩体后短暂暴露射击) / 绷带(1轻→健)

## 自由动作
移动(AGI×2m) / 对话 / 丢弃物品 / 观察

---

## 命中

```
远程: d20 + AGI修正 + 技能 + 精度 vs 10 + 目标AGI修正 + 掩体
近战: d20 + STR修正 + 技能 vs 10 + 目标AGI修正
未察觉目标: DC 8 + 掩体 (目标不计AGI)
闪避(快速): d20 + AGI + PER/2↓ + 掩体 vs 攻击方投值
```

## 伤害

| 来源 | 减护甲 | 最低 |
|------|--------|------|
| 常规/近战(创伤) | -IR | 1 |
| 重创弹/爆炸/坠落(重创) | -CR | 1 |
| 暴击(自然20) | 同上 +1d6 | — |

## 血槽填充

```
创伤: H→L先, L→S后
重创: H→S先 (跳过轻伤) , L→S后
```

## 掩体

| 类型 | 加值 |
|------|------|
| 半掩体 | +2 |
| 全掩体 | +5（不能攻击） |
| 轻掩体 | +1（承受10点后摧毁） |

## 其他修正

| 条件 | 修正 |
|------|------|
| 高台对低位 | +1 命中 |
| 背后攻击 | +2 命中, 目标无法闪避 |
| 夹击(两人对角) | +2 命中 |
| 压制的目标 | -2 全检定 |
| 环境利用(爆炸桶等) | DM：+2 命中 或 +2 伤害 |
| 创造性描述 | DM：+1 命中 或 额外1创伤 |

## 射击模式

| 模式 | 修正 |
|------|------|
| 单发 | 0 |
| 2连发 | 第2发 -3 |
| 3连发 | 每发 -5 |

## 瞄准部位

| 部位 | 命中修正 | 伤害倍率 |
|------|---------|---------|
| 头 | -8 | ×2 |
| 躯干 | 0 | ×1 |
| 四肢 | -2 | ×0.5 |

## 重伤惩罚

| S槽 | 效果 |
|------|------|
| S=1 | -2 全检定 |
| S≥2 | -5 全检定 + 禁止复杂动作 |
| S > 总/2 | 昏迷 |
| S = 总 | 濒死 → 每轮CON DC12 → 连续2次失败=死亡 |
| S 首次≥总/2 | 肾上腺素激增(本战1次): 取消惩罚 ×1轮 + 速度×2 |

## 压制

```
被射击 → WIL DC (12+射手人数) → 失败 = -2 全检定持续1d3轮
```
