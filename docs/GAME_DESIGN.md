# 玩法与结算

## 角色和自由行动

玩家先向AI主持人提出自由角色概念，讨论背景、能力、装备、关系、偏好与边界。主持人整理完整草案，玩家可反复修改，采用后才进入适合这个人的开场。保留力量、敏捷、体质、感知、智力、意志、共鸣七项属性，但没有职业枚举和固定配点套餐。

有不确定性才检定。D100不超过“对应属性×5 + 训练 + 环境与临时状态修正 − 伤势/疲劳/超重影响”即成功，目标限制在5%至95%。自创专长有自己的关联属性、训练与适用范围；没专长也可以做未受训的属性检定。确定性操作无需骰子，场外讨论不推进时间。涉及真实资源与风险的骰子在确认后由服务器产生。

玩家可以自由交涉、布置机关、加工物资、勘查新道路、借用设施、建立约定和营地。模型可以查询资料、试算、创建对象、编写NPC事件。详细权责见 `SYSTEM_DESIGN.md`。快捷按钮只是可预期操作的便利入口。

## 资源与伤情

初始装备与现金来自共同确认的背景和来源，可以无枪、无欠款，也可以有标志性专业设备。自定义物品和目录物品进入同一本库存；枪械记录弹仓，护甲和医疗用品有功能字段。交易双方的物资和灰币实际转移；合同交付真实扣货，只付一次钱。负重超过力量×3公斤影响检定，普通步行快捷操作在其1.5倍以上会要求先安排运输；特殊搬运办法由主持人裁定。

伤口有部位、1—4级严重度和持续出血。躯干护甲按记录值减轻伤势，头部与四肢不受它保护。中弹即时失血，此后按分钟继续结算。血量低于35失去意识，归零、累计极重创伤或危重头伤会死亡。没有免费救援、回镇满血或强制保底。

绷带止血但不消除伤势。医疗耗材包可以清创，需要医疗检定；处理后的伤口经过至少一天并休整才改善一级。稳定的昏迷者在庇护处可缓慢恢复意识，同伴可替其止血。不能给昏迷者直接灌水。

饮水每份补充四小时需求，口粮每份十二小时；长时间缺水伤害血量。休息需要庇护与脱离敌人，恢复疲劳和能量，世界不会暂停。

## 异能

五系保留原名称，玩家与主持人可设计具体原理、应用、限制和代价。能力档案进入每轮主持上下文，能量上限为共鸣×3。实际使用必须在灰区内适应至少60分钟、接触结晶，裂隙关闭后失效。未满足条件的已知能力可以保留在角色上，草案会提醒当前缺少什么。

基础消耗与新增负荷依具体能力；重复使用的现有负荷增加耗能，黑潮中额外消耗1。共鸣、负荷和黑潮共振超过意志，产生最多90%的反噬概率。反噬损失能量、造成伤势并暴露位置。负荷随时间消退，能量通过休息恢复。临时变体可另谈本次条件并公开结算，持续增益或不利状态可有作用范围和到期时间。

## 世界与交互

地点按真实通行时间相连，允许新路线和新小地点，没有任务等级或章节解锁。撤离是移动，不是无条件传送。

NPC初始行动写为数据事件，带时间与条件。AI可以修改、替换或取消计划；失败条件不会被强行推进。黑潮默认八周扩展，符合世界因果的主持裁定可以遏制或关闭裂隙，环境变化会落实到规则。

对话是主要界面，档案、装备、地图、联系人与结算记录按需查看。询价不自动成交，询问不自动施术，确定性交流不机械要求掷骰。玩家可以直接质疑待执行裁定、修改办法，也可以与主持人讨论角色成长或更正档案。玩家亲自采用涉及自身能力的修订。

当前战斗是以一次意图为单位的抽象交锋，具有弹药、护甲、隐蔽和反击；尚非网格战棋或完整弹道模型。长期能力变化通过有理由的档案修订处理，没有自动经验树；需要的实际训练、资源与事件由主持人安排并结算。
