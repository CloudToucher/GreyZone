# 原设定基线

本次重构保留《灰区：撤离》的背景；新系统不载入旧程序。

- 2027年，UEG在近海人工岛的“湮灭”高能实验引发维度裂隙。约2030年扩张趋于稳定。
- 游戏从2037年3月15日开始。新沪港灰区位于中国东部沿海，覆盖旧工业港和周边城镇，半径约80公里。
- 围栏镇位于南缘，是常见入口。具体身份、来由和开局地点由玩家与主持人商定，可以是原住民、外来专业人士、回收者或其他符合背景的人。灰币由铁壁发行，区外价值极低。
- 0区围栏镇；1区工业外缘；2区城镇废墟；3区异常荒野；4区地下设施；5区零号井。地图保留石化工厂、旧药厂、集装箱码头、军事哨站、通讯站、采石场、地下实验室与观测站等地点。
- 铁壁安保提供回收合同，但玩家不必受雇于它；黑水亚洲与之竞争；龙盾国际掌握先进装备、情报与结晶加工；UEG仍在自动化采掘。拾荒者按各自生存需要合作或抢夺。
- 守望者是原住民群体。少校周若冰的扎根派保卫社区，老吕的回归派谋求关闭裂隙，烬的启示派试图进入镜界。分歧有实际生存背景。
- 原有人物包括军火商老高、医生老郑、机械师锯子、情报贩子鸦、合同官方远，以及电鳗陈、静默叶琳和铁心。保留其位置、利益与主要牵挂。
- 黑潮来自零号井，以约八周向外围扩散。它是环境与势力压力，可以被干预，不是每做一个动作就固定推进一格的剧情计数器。
- 异能保留身体强化、元素共鸣、感知扩张、空间干涉、精神支配五系。三法则是区域依赖、结晶传导和共鸣响应。结晶分S/A/B/C/D/E，工业精炼与手工拼接不是同一回事。

核对来源为原项目归档中的 `story/main_plot/主线剧情框架.md`、`story/灰区地图.md`、`story/main_plot/势力局势图.md`、`story/main_plot/黑潮_全局时钟.md`、`rules/00_游戏约定.md`、`rules/01_核心规则书.md`、`assets/npcs/NPC模板与列表.md`。源文献中的数值与程序并未直接恢复；新数值是这次规则重构的一部分。

原作没有唯一正确的行进路线。关闭、控制、继续利用或进入裂隙是可能的走向，条件由实际调查、合作与资源建立。新版未把它们做成三个章节之后的结局按钮。
