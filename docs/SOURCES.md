# 重建来源与取舍

原灰区设定从 Git 提交 `a15150d` 提取：游戏约定、灰区地图、主线框架、势力局势、黑潮时钟及 NPC 档案。原文副本位于 `.backups/setting-sources`。保留新沪港、2037 年、UEG 实验、黑潮、主要人物势力和异能三条基础规律；重新编写轻规则与可运行地点资料。移除强制职业、债务、雇主及固定开场。

参考仓库：[CloudToucher/trpg_table](https://github.com/CloudToucher/trpg_table)。参考的是模型主持、自然语言规则、多人分工、分层记录和实战迭代的方法。其早期 Cursor/文件协作方式在本项目中改为 dsh 原生 MCP、数据库权威状态、自动角色表与私密网页投影。没有把维护多份 Markdown 的劳动转嫁给玩家或主持模型。

旧 TypeScript 程序、React 界面、数值引擎、测试和设计文档已整体替换。新的固定代码用于桌务，不保留旧预写裁决分支、单步动作路由或自动攻击。旧 Git、存档备份、用户配置和无关未跟踪文件保留。
