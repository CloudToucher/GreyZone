# 架构

React/TypeScript/Vite前端；Fastify服务端；Zod协议；原子JSON存档；dsh headless传输。没有旧OpenCode调用链或旧规则引擎。

| 模块 | 责任 |
| --- | --- |
| `shared/types.ts` | 数据协议、校验、效果与世界编辑能力声明 |
| `server/content.ts` | 原设定摘要、人物与物资初始模板、地理 |
| `server/engine.ts` | 角色结算、检定、时间、生理状态、预览与提交、公开投影 |
| `server/creation.ts` | 尚未入场角色、草案一致性检查、采用档案并建立开场 |
| `server/ai/creation.ts` | 连续角色讨论、完整草案修订、辅助提醒和模型纠错 |
| `server/world.ts` | 世界编辑、条件时钟、NPC初始计划、信息查询 |
| `server/ai/adjudicator.ts` | query / validate / reply / propose / amend工具循环、纠错预算 |
| `server/ai/policy.ts` | 可审阅的主持语言约束与工具使用说明 |
| `server/ai/dsh.ts` | 游戏提示、无shell子进程、JSON解析、超时和取消 |
| `server/store.ts` | 散列凭据、进程锁、房间互斥、原子写盘 |
| `server/app.ts` | 鉴权、API、版本控制、幂等回执、SSE |
| `src/App.tsx` | 角色与场景交互、预览确认、重试、移动布局 |
| `src/Entry.tsx` | 自由概念入口、与主持人讨论、可读角色草案 |

每次模型请求只读当前版本。reply保存交流和本人的柔性自述；amend保存待本人采用的档案修订；propose先试算，短暂、确定且无即时威胁的互动直接结算，其余保存待确认提案。确认端点重新校验，在克隆状态中结算，持久化后才广播。角色讨论、采用、修订、行动、确认与撤回都有请求ID；同ID重试先命中回执，不重复生成、入场或扣款。客户端即使已经通过SSE收到更新，也保留响应丢失时的原请求用于重试。

每个席位拥有自己的workshop，包含最初想法、完整讨论、版本、当前草案和首轮请求ID。原始讨论与未采用草案只投影给本人。确认前不参与世界时间、敌人反应和物资结算；接受后将真实装备、技能、能力、关系与定制开场写入同一存档。草案提示与硬错误分开：缺导体或超重给出可讨论提示，非法引用、重复物品ID与超容量弹仓才导致协议校验失败。

模型自由度通过数据接口实现：专长映射属性与训练；异能保存语义及默认代价，临时powerTerms覆盖本次基准并公开理由；condition保存适用检定、修正与到期时间；amend允许提出背景、属性、训练、专长和能力的修订。修订不直接触及生命、伤口、现金和库存，提高能量上限也不会补满当前能量。

世界编辑有独立能力域，不能借entity.patch覆盖玩家。玩家档案调整走有所有权校核的amend，资产和伤情走结算效果。条件时钟逐个在草稿中执行；失效引用取消该事件并留内部记录。世界执行日志包含模型/时钟来源与因果说明。

公开投影不返回实体秘密、隐藏对象、待发生时钟、审计底稿或提案成功/失败的未发生分支。房间公开记录仍是共享的，尚未实现玩家之间的秘密视野。

每个数据目录只能一个进程写入。存档经过协议和引用校验；文件先写临时文件、同步磁盘、再rename。故障不会先改内存权威状态。新语义字段采用读取默认值兼容v2旧存档，不覆盖角色资产和凭据；v1中间试作存档移入legacy-v1目录；损坏文件保留并让启动报错。

运行范围是本机或可信局域网。没有公网账户体系、席位恢复服务或任意存档导入入口。
