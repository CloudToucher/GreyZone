# 灰区：撤离 — 合同中心门前

围栏镇据点的早晨没有鸟叫声，只有发电机低沉的震颤从基地深处传来，像一头还没醒透的巨兽在呼吸。铁丝网上的露水反射着灰蒙蒙的天光，几个早班的巡逻兵从哨塔上换岗，靴子踩着铁梯的节奏不紧不慢。

你站在合同中心门前的碎石地上。外环登记已经办完，入口处的登记员收走了你的生物数据——采血、虹膜扫描、声纹存档。一套干净利落的流程。那名登记员只在看到你右手腕的金属护具时多停了半秒，什么也没问。他把一张刚打印出来的临时通行卡推过柜台："合同中心，进门左转第二个窗口。方主管在等你。"

合同中心的建筑是预制板搭的，从外面看像个加宽的集装箱。门是半掩的，里面飘出打印机的机械嗡鸣和淡淡的咖啡味——在灰区里，咖啡味比任何通行证都更能说明这是一个什么样的地方。有人在里面说话，声音不大，但你从门缝里听得到一两个片段："……标准条款，回收分成三七开。你出人，公司出情报和后勤。觉得有问题现在说。"

碎石地上还积着夜里的潮气。空气里混着柴油、焊锡和远处垃圾焚烧的焦味。你的影子在晨光里被拉得很长，投在合同中心的门上。
