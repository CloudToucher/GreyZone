# 主线剧情框架：《灰区：撤离》"黑潮"战役

## 核心设定

- **时间**：2037年3月15日起（约8周游戏时间）
- **地点**：中国东部沿海，新沪港灰区（原工业港区+辐射城镇带，半径约80km）
- **起点**：灰区南缘 — 围栏镇（回收者据点+PMC前哨）
- **终点**：灰区核心 — 代号"零号井"的维度交汇原点
- **目标**：逐层深入灰区，在各方势力之间求生、积累、最终决定灰区的命运

---

## 第一章：灰区是怎么来的

2027年，联合能源集团（UEG）在新沪港外海人工岛上进行代号"湮灭"的高能物理实验。实验目标是打开一个可控的亚空间能量通道——理论上可以从此获得无限清洁能源。

实验失控。不是"炸了"——而是**撕开了一道口子**。一个通往未知维度的交汇点在外海人工岛形成，并以每天数米的速度向外扩张。直到2030年左右趋于稳定，形成半径约80km的**灰区**。

灰区内的物理法则不再完全遵循外部世界的规律：
- 重力异常：局部区域重力方向改变，建筑扭曲但不倒塌
- 时空折叠：两条街之间的物理距离可能比地图上远——或近
- 有机体突变：动物和植物在异常能量长期浸泡下变异。部分保持原生态，部分变得危险
- 异常结晶：维度交汇的物理副产品——在灰区环境中缓慢生长的晶体，是完美的能量储存介质
- 共鸣现象：部分人体对灰区能量产生生理反应——"觉醒"。可以主动引导这股能量

联合政府对外宣布封锁——灰区边界被军事隔离带包围。但对内默许私人武装公司（PMC）和自由回收者进入掠夺。灰区边缘正在形成一个半合法化的灰色经济体。

## 第二章：谁在里面 —— 公司格局

### 铁壁安保（Iron Wall Security）

**玩家的默认雇主**。

中国背景的大型综合安保企业，灾变后第一个拿下灰区作业牌照的PMC。总部在上海，灰区办公室设在围栏镇。他们的商业模式是：提供基础合同、装备租赁、矿区补给——回收者自行组队进入灰区，带出来的东西按比例分账。

- 在围栏镇经营：合同中心、工坊、医疗站、补给仓库
- 发行**灰币**（Coin）——围栏镇及灰区内通用的内部结算币
- 对回收者的态度：**工具化但不剥削**。给你合同和装备，剩下靠自己。不提供救援——除非你签了高昂的保险协议。
- 回收者可以划定自己在镇内或镇周边空建筑中的安全屋/领地。铁壁默认保护回收者之间的领地界限——破坏他人领地会被所有PMC列入黑名单。

### UEG（联合能源集团）

**灾变的始作俑者**。

表面上UEG已经退出了灰区——灾变后他们对外宣称"一切设施已废弃"。实际上，灰区深处有多个UEG的自动化研究设施仍在运行。他们仍在尝试控制和利用维度交汇，并视任何接近核心区的回收者为威胁。

- 灰区内的UEG安保机器人仍按旧编程运行——"格杀勿论"
- 灰区中层可能有UEG的暗哨或秘密观察员
- UEG手中掌握着"如何关闭灰区"的知识——如果他们愿意泄露的话

### 黑水亚洲（Blackwater Asia）

**竞争对手**。

国际PMC的亚洲分支，比铁壁更激进。他们的回收者小队装备更好、分成更低、风险更高。偶尔与铁壁的回收者在高价值区域发生摩擦——不一定会开火，但会抢先拿东西。

- 在围栏镇有秘密联络点（名义上是"私人会所"）
- 有时候会挖铁壁的回收者——开出更高的合同但附带更苛刻的条款

### 龙盾国际（Dragon Shield International）

**高端服务商**。

小型但精锐的科技企业，不做回收——做装备和信息生意。他们有灰区深处的地图（旧UEG内部资料）、高端异常探测设备、定制的异常结晶加工服务。

- 在围栏镇有一个不挂牌的工作室
- 价格极高——但他们卖的东西别处买不到

## 第三章：围栏镇 —— 玩家的家

### 小镇规模

围栏镇原本是新沪港外围的一个工业服务镇——五金店、汽修厂、工人宿舍。灾变后因为紧贴灰区南缘的隔离带，被回收者自发占据改造为据点。现在有约200-300常驻人口（回收者、商人、PMC雇员、少数逃难者）。

**镇内功能区**（铁壁安保公司围栏镇据点运营）：
- **合同中心**：签约、领灰币、接任务。回收者在这领装备包。
- **工坊**（可升级设施）：武器改造、弹药复装、异常结晶加工
- **医疗站**：轻伤处理、重伤手术（收费昂贵）
- **补给仓库**：基础弹药、食物、水的批发出售

**镇内自发形成的区域**：
- **铆钉巷**：黑市。老高（军火商）的地盘。可以买到非铁壁渠道的武器和物品。
- **酒馆"最后一杯"**：情报交易所。回收者在这里交换地图信息、Boss位置、异能军阀的动向。
- **龙盾的秘密工作室**：不挂牌，需要引荐才能找到。
- **黑水亚洲的会所**：名义上不招回收者——实际上经常"偶遇"并开价。

**镇周边**：
- 地广人稀，大量空建筑（旧厂房、民居、仓库）
- 回收者小队可以在这些建筑中划定安全屋或领地
- 领地权益受铁壁安保默许保护——但只在围栏镇周边有效

### 镇内不是安全的

围栏镇的防务靠铁壁的安保人员和回收者自发维护。偶尔有变异生物从灰区边界溜进来，或者竞品公司的人在巷子里"偶遇"。小镇有照明和监控，但夜晚的巷子不建议单独走。

## 第四章：灰币与结晶 —— 双重经济

### 灰币（Coin）

铁壁安保发行的内部结算代币。一灰币在围栏镇内有约1美元等值购买力，但**只能在围栏镇及铁壁合作商铺流通**。外部兑换率约1灰币=0.03美元——几乎等于废纸。这个极低的外部估值确保了回收者的经济命脉完全绑定在灰区：你赚的灰币只能在这里花，意味着你只能继续回来。离开灰区，你将一无所有。

发行灰币的真实目的（DM可知）：
- 规避外部金融监管：灰币交易不经过银行系统
- 锁定回收者：你的身家在镇里——你走不了
- 控制经济：铁壁通过调整灰币发行量间接控制物价

### 混合开局经济

**回收者不是英雄——是走投无路的亡命之徒。**

玩家初始不是"冒险者"，是**被生活逼到墙角的人**。每个人的背景里都有一个"为什么来灰区"：
- 欠了还不清的债
- 惹了惹不起的人
- 失去了所有，只剩一条命可赌
- 外面已经没有容身之处

铁壁根据角色的背景提供**初始灰币额度**（通常在100-500灰币之间），同时发放**基础合同装备包**：基础武器+基础护甲+3天口粮+少量弹药。初始灰币可用于向老高或补给仓库升级装备、多买弹药和医疗品。可以借债——但铁壁的利息不低（每10点灰币欠款，下次突袭结算扣5%）。

**这就是灰区的底层逻辑：你活着是因为你欠着。你还着是因为你怕死。你怕死所以你继续干活。**

### 异常结晶

灰区最重要的物资——也是最危险的。

- 异常结晶全部是同一种物质。区别仅在于体积/纯度/能量密度（S~E六级）
- **不能手动合并**——把一堆D级熔成C级需要工业级精炼设备
- UEG在灰区地下有唯一已知的**结晶精炼厂**（自动化运行，位于Zone 4地下实验室B区）。他们以约20:1的比例收购低级结晶→精炼成高级→卖给外部或龙盾等高价渠道。这是UEG在灰区经济中的核心优势
- 回收者可以囤低级结晶(做武器镀层不需要精炼)或卖给UEG换灰币。但要突破异能T2+需要高级结晶——你只能自己找到或花大价钱买
- 市价不稳定：大致20:1，随精炼厂产出率和供需波动

### 装备获取途径

| 途径 | 说明 |
|------|------|
| 合同装备包 | 每次签新突袭合同时发放。基础装备，够用但不充裕 |
| 灰币购买 | 镇内补给仓库+黑市 |
| 灰区搜刮 | 主要来源。最好的装备往往不在商店里 |
| 工坊自制 | 攒材料后在工坊升级/改造/合成 |
| 任务奖励 | 铁壁或NPC会给的特定任务报酬 |
| 交易/掠夺 | 和NPC交易，或者从敌人身上缴获 |

## 第五章：灰区内的势力

### 守望者（Watchers）—— **v4更新：三大派系**

**灰区里的原住民社区——不是理想化的守护者。**

灾变时被困在灰区内的数千人（UEG员工+家属+镇民），十年来在异常地带里自然形成的社区。**如今内部分为三个派系：**

- **扎根派（少校领导）**：认为灰区已是家园，重点在存活和延续。少校本人RSN在缓慢失控，她正在寻找继承人。务实的社区建设者。
- **回归派（老吕领导）**：前UEG工程师，认为裂隙必须被关闭。掌握结晶精炼和裂隙物理的关键知识。结局A（关闭裂隙）的技术核心。
- **启示派（"烬"领导）**：灰区二代，从未见过外部世界。认为裂隙不是灾难而是入口——人类应该走进去。结局D（镜中人）的天然向导。危险但关键。

内部矛盾是真实的：回归派想关、扎根派想守、启示派想走进去。少校努力维持平衡，但RSN失控正在消耗她的时间和权威。

**与回收者的关系**：务实。你可以站在任何一个派系一边——但选择会改变结局可能性和NPC生死。

### 拾荒者群

**中立偏敌对的流动群体。**

拒绝加入任何PMC的独立求生者。他们比回收者更穷、更危险、更不择手段。组成松散的小团体，在灰区各区域游荡。

- 装备低劣但熟悉地形——可能从通风管或天花板出现
- 部分可以交涉（用食物、水、弹药交换信息或暂时结盟）
- 部分敌意（会伏击落单的回收者）
- 人数不定——一个区域内可能出现1d4个拾荒者团伙

### 异能军阀

**高RSN的人类个体，各自割据。**

灾变中觉醒并在灰区内生存下来的高共鸣个体。每个人都有独特的能力和独特的领地。他们不是"Boss"——他们有动机、有恐惧、有关系、有自己的故事。

**已知军阀示例（DM可按需创建更多）**：

| 名称 | 位置 | 特点 | 态度 |
|------|------|------|------|
| "电鳗" 陈 | 旧石化工厂区域 | RSN=8，操控电流。可以瘫痪电子设备和机器人。收编了一群拾荒者做手下 | 可交涉——但他要你会"为他做一件事" |
| "静默" 叶琳 | 废弃通讯站区域 | RSN=9，感知型异能。可以远程探测任何进入她领地的人。独居，不招手下 | 可交涉——但需要先证明你不是UEG的人 |
| "铁心" 未知 | 荒野区旧采石场附近 | RSN=7，身体强化型。把自己改造成了半金属半肉体。保护着一小群逃难的平民 | 可交涉——他关心的是那些平民的安全 |

**军阀不是固定的**——不同游戏局中DM可以创建全新的异能军阀。他们应该让人感觉像"灰区的人"，而不是"副本Boss"。

### 镜界实体（Mirror-Realm Entities）

**不可交涉的跨维度生物。**

从维度交汇的另一端渗透进来的实体。它们不是"生物"——更像环境的一部分，但具有攻击性。不同形态：
- **镜界行者**：半透明银色漩涡形态，触须攻击。出现在裂隙附近。最常见的镜界生物
- **融合体**：镜界生物与灰区物质融合的产物。更强大、更难预测

镜界实体对灰区内的能量变化敏感。大量使用异能或异常设备可能吸引它们的注意。

### PMC远征队

**竞品公司的武装小队。**

当黑水或其他竞争对手发现高价值区域时，会派出自己的远征队——装备精良、训练有素。它们和回收者的关系取决于当前局面：竞争时敌对，有共同威胁时可能临时合作。

## 第六章：世界如何运转

> 灰区不是一条线性故事——它是一张活棋盘。
> 我们不再使用"序章→第一章→第三章"的推图结构。
> 取而代之的是两个实时运转的系统：

### 势力局势

**文件**：`story/main_plot/势力局势图.md`

七个势力，各自有目标、障碍和时钟：
- **UEG**：试图维持裂隙——黑潮正在打破他们的控制
- **铁壁安保**：你的雇主——但在黑潮逼近时，忠诚是双向的
- **守望者-扎根派（少校）**：想在灰区活下去——但她自己正在被 RSN 吞噬
- **守望者-回归派（老吕）**：想关闭裂隙——但他没有数据、没有权限、没有时间
- **守望者-启示派（烬）**：想走进裂隙——她知道别人不知道的东西
- **黑水亚太**：想抢在铁壁之前收割最后一波
- **拾荒者群体**：想活下去——仅此而已

每个势力都有**时钟**。当时走满一格，该势力主动做一件事。
玩家可以选择介入、利用、阻止或无视——但世界不会等他们。

DM 在每个 session 开始时检查所有时钟。

### 黑潮

**文件**：`story/main_plot/黑潮_全局时钟.md`

黑雾从 Zone 5（零号井）向外蔓延。约 2 个月后抵达围栏镇。
黑雾不是匀速的——它像潮汐，推进后微微后退，但净运动是向外的。

黑雾的效应：
- 可见度大幅下降
- RSN 被动共振增强（所有人的异能都更不稳定了）
- 镜界实体在雾中更强、更频繁
- "雾震"——维度波动，可能撕开临时裂隙

DM 在每个 session 开始时检查当前游戏日期 → 确认黑潮位置 → 应用环境效应。

### 二者如何共同驱动叙事

| 当玩家... | 世界会... |
|-----------|----------|
| 什么都不做 | 黑雾照样蔓延，势力时钟照样推进，后果照样发生 |
| 帮助了一个势力 | 该势力的后续时钟格加速或变强 |
| 对抗了一个势力 | 该势力可能失败、转向或消失——棋盘上少了一个玩家 |
| 发现了某个秘密 | 世界的另一个层面被揭开——新的叙事钩子诞生 |

玩家不需要沿着预设路线走到"终章"——因为**没有一个叫"终章"的地点**。
结局是势力博弈和黑潮逼近的共同结果，而不是"走到第 X 章"。

## 第七章：结局方向

> 以下是**可能的结局方向**，不是必须到达的路线。
> 黑潮不会等玩家"准备好"。黑雾到围栏镇的那一天——不管你做出了什么选择，世界会给出一个结局。
> DM 的工作不是"判断玩家够不够格走结局 X"——而是根据玩家已经做了什么、和谁站在一边、黑潮还剩多远，自然而然地呈现结局。

### A. "关上它" — 关闭裂隙，灰区消失

**方向**：与老吕（或研究员·林）合作 → 获取 UEG 加密数据 → 在核心控制室执行关闭程序。

**黑潮期限**：必须在第 8 周黑潮吞噬核心控制室之前完成。否则关闭程序无法启动——裂隙太大，关不上了。

**后果**：灰区消失。异常结晶失去能量。所有 RSN 降为 0。数万回收者失业。但黑雾停止蔓延。灰区边界不再扩张。

### B. "驯服它" — 与控制裂隙，而非关闭它

**方向**：与龙盾国际合作 + 扎根派支持 → 开发维度稳定化装置 → 将灰区变成有管理的禁区。

**黑潮期限**：必须在第 6 周前开始合作（龙盾和扎根派的资源都在被黑潮侵蚀）。

**后果**：黑雾停止扩展并被限制在 Zone 3 以内。异常结晶在受控条件下继续产出。回收者变为"灰区管理员"。但控制可能在未来失效。

### C. "榨干它" — 继续掠夺，不管明天

**方向**：与铁壁（或黑水）保持合同 → 在黑潮外围继续搜刮 → 无视长远威胁。

**黑潮期限**：没有主动期限——黑潮自己做期限。雾到围栏镇，你能搜刮的区域就会——消失。

**后果**：灰区继续缓慢扩张。这一代人赚到了钱。下一代人面对更大的灰区和一个更不稳定裂隙。但这个世界至少还能运作。

### D. "镜中人" — 走进裂隙

**方向**：收集 3 个真相碎片 → 与烬同行 → 在核心控制室选择"走进去"。

**黑潮期限**：必须在第 8 周前完成。黑潮达到最高密度的时候——裂隙"最清醒"。

**后果**：不一定是死亡。裂隙另一边有意识——或者说有存在。走进镜界，可能是接触。烬会是你见过的最平静的人。如果你没有选择走，她会独自走。

### E. "渡黑潮" — 成为潮行者（隐藏方向）

> 这是一个更稀有的可能性。DM 不应暗示它——它只能自然涌现。

**方向**：高 RSN（8+）+ 与启示派深度合作 + 在黑雾区多次存活并"聆听" → 发现自己可以和黑雾共处。不是抵抗它——是理解它。

**可能性**：黑雾中的镜界实体在某次遭遇中不攻击——而是停下来。它们看着你。然后离开。从那一刻起，你不再只是灰区的难民——你是两个世界之间的信使。

**后果**：如果你选择了这个方向——灰区保留。黑潮停下来，不再蔓延。你不再是回收者。你是一个新的分类——没有人知道该叫什么。

---

**主键**：DM 在每个 session 结束时检查玩家累积了什么：
- 和老吕的关系、UEG 数据 → A 方向开启
- 和龙盾的关系、少校的态度 → B 方向开启
- 铁壁/黑水的合同进度 → C 方向（被动）可能
- 真相碎片数量 + 烬的关系 → D 方向开启
- 高 RSN + 多次黑雾接触 → E 方向可能

玩家可以随时改变方向。这不是技能树——这是你的选择。而黑潮一直在走。

## 第八章：黑潮 — 灰区的新威胁

> 本节的"黑潮"是指**灰区内的居民和回收者所知道的黑潮**——即角色的视角。
> DM 使用的完整机制见 `黑潮_全局时钟.md`。

### 它是什么（在灰区传说中）

最早关于黑潮的报告来自 Zone 4 附近的拾荒者——"不是灰雾。灰色的雾我们见了十年。这个是黑色的。而且它是从地面往上长出来的——不是从天上掉下来的。"

目前没有人知道黑潮的成因。猜测包括：

- **守望者的解释**：裂隙在"恶化"。十年前是撕开——现在可能在撕裂第二次。
- **老郑的医学解释**：黑雾对神经有影响。在雾中待久了的人回来后有轻微的记忆问题——"好像有些东西他们忘了，但不知道是什么。"
- **鸦的情报**：UEG 的空投物资中包含"抗潮蚀护甲"。意味着 UEG 知道黑雾会发生——或者他们正在制造它。
- **烬的低语**："黑雾不是出了问题——黑雾是门开得更大了一点。有人在对面推。"

### 它的行为

- 黑雾贴着地面流动，密度如水，但摸上去像冷空气
- 它不匀速推进——有"潮涌"日子，雾一下子前进几公里；也有"退潮"日子，雾后退数百米
- 黑雾不喜欢强光——阳光能抑制它的扩散速度。这就是为什么白天的大雾不如夜晚的浓
- 黑雾中有**人形的东西在走动的说法**——没有人能证明，但在酒馆里至少有三个回收者说有

### 它对变异生物的影响

- 黑雾到来前 1-2 天，该区域的变异生物集体变得暴躁或集体逃离。好像它们比人类更能感知雾。
- 黑雾中出现的生物比普通的更危险——颜色更深、外壳更硬、攻击更不理性
- 一只正常的前哨鼠在黑雾中停留 1 天后会变成比狗还大的东西——但活不长

### 灰区内的反应

- 铁壁合同官：公开说"无需担心"，私下在买抗潮蚀装备。
- 老高：在囤积弹药。"雾不会伤人——但雾会把所有猎人赶到一个地方。人会互相抢。"
- 少校：沉默。"十年前撕裂了一次。十年后又要撕一次。这次我们不知道裂开的是什么。"
- 烬："我知道。他们告诉我的。"

## 第九章：突袭结构

每个游戏局（"突袭"）的节奏框架：

| 阶段 | 内容 |
|------|------|
| **镇内准备** | 在围栏镇签合同、配装备、收集情报、选择路线 |
| **进入** | 穿过隔离带进入灰区。氛围建立，第一次侦察 |
| **探索** | 按场景地图的「可搜索区域」搜索物品、遭遇敌人、发现线索。 |
| **高峰** | 突袭的核心目标：Boss战或重大剧情揭示 |
| **撤离** | 倒计时压力——前往撤离点，等待撤离窗口，应对追兵 |
| **结算** | 回到围栏镇。算物资、经验、灰币。回血回槽。准备下一次 |

每次突袭根据回收者的深入程度（外缘/中层/深层）自动缩放敌人和奖励的Tier。

## 第十章：DM调控杠杆

这不是给玩家看的——是DM的工具箱。

- **铁壁合同官**：可以用来推动目标（"最近需要XXX，报价很高"）或施加压力（"你上次没带回足够的货"）
- **老高**：情报和特殊装备的阀门。他有货就不推进剧情；他没货就推动玩家进灰区
- **守望者**：背景信息的主要来源。他们知道UEG干了什么，但不会一次全说出来
- **竞品公司小队**：当玩家安逸太久时，一队黑水远征队出现在同一区域可以制造紧张
- **异能军阀**：不是来被杀的。他们是故事角色。玩家可以和他们交易、合作、或者敌对——但不能用"我去刷Boss"的心态
- **灰币经济**：玩家灰币不足时，铁壁合同官会"善意地"提供贷款——附带更高的分成比例
