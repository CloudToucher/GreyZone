# 主线剧情框架：《灰区：撤离》

## 核心设定
- **时间**：2037年（灾变后10年）
- **地点**：新沪港灰区（原沿海工业区，半径约80km）
- **起点**：灰区南缘 — "围栏"前哨基地（回收者聚集地）
- **终点**：灰区核心 — 代号"零号井"的维度裂隙原点
- **目标**：逐层深入灰区，揭开"湮灭实验"真相，在各方势力之间决定灰区的命运

---

## 世界背景

故事设定在近未来的东亚沿海工业区。2027年，联合能源集团（UEG）在此进行代号"湮灭"的高能物理实验。实验失控，撕开了一道通往未知维度的裂隙——灰区由此诞生。灰区内的物理法则被扭曲：重力异常、时空折叠、有机体突变。最关键的副产品是"共振核"——一种完美的清洁能源晶体，在黑市上一克等价半座城市。

联合政府对外封锁灰区，对内却秘密支持私人武装公司(PMC)和独立回收者进入掠夺。灰区外缘已形成半合法化的"前哨围栏"——回收者的出发地、销赃点和修罗场。

**第一层（玩家已知）**：灰区外缘相对稳定，以工业废墟和废弃城镇为主，有变异生物和被抛弃的机器人守卫。

**第二层（游戏中揭示）**：灰区不是自然的——UEG故意维护裂隙，共振核是他们的产品而非副产品。灰区深处有未被撤离的研究人员和自动化系统仍在运行。

**第三层（DM专用）**：裂隙对面有一整个生态体系——"镜界"。它正在缓慢扩张。UEG高层中有一派人想利用它，另一派人想关闭它。玩家的选择决定灰区是被继续掠夺、被摧毁、还是被某种方式"共存"。

## 剧情章节

### 序章：围栏

- **位置**：灰区南缘前哨基地 + 工业区边缘
- **开场情境**：回收者在昏暗的改装仓库中醒来。墙上贴满了失踪者的照片——其中就有某个NPC对玩家重要的人。广播里循环播放PMC的招聘广告。有人在外面叫："十点出发，东工业区有人组队——缺一个能开门的技术——"
- **触发事件**：第一次突袭：入门任务"新手菜鸟必跑路线"——东工业区浅层搜索+撤离。让玩家熟悉搜索/战斗/撤离循环。
- **本章任务**：
  - [ ] 完成第一次突袭（搜索+撤离）
  - [ ] 在围栏基地认识至少2个NPC
  - [ ] 获取第一块共振核碎片（任务奖励或战利品）

### 第一章：铁锈地带

- **位置**：东部工业区 + 废弃港口
- **环境**：锈蚀的石化管道、倾斜的集装箱堆、盐雾和工业废料的味道。海风偶尔吹散雾气，露出远处若隐若现的起重机骨架。
- **关键场景**：
  - S1: `industrial/石化工厂.md` — 搜索任务：找到旧实验室残留样本
  - S2: `industrial/集装箱码头.md` — 战斗遭遇：拾荒者帮派占据
  - S3: `urban/沿海小镇.md` — NPC线索：前UEG研究员藏身处
- **本章任务**：
  - [ ] 在石化工厂找到UEG的旧实验记录
  - [ ] 消灭或绕过集装箱码头的拾荒者帮派
  - [ ] 找到研究员遗留的加密数据盘
  - [ ] 发现第一个异常信号源的位置

### 第二章：沉默之城

- **位置**：灰区中部城区 + 军事封锁线
- **环境**：被遗忘的城市。橱窗里的模特还穿着十年前的时装，但整个街区都是倾斜的——不是地震，是重力异常。某些区域的时间流逝速度慢了20%。
- **关键场景**：
  - S4: `urban/中央商业街.md` — 垂直空间探索，多楼层建筑，狙击点位
  - S5: `urban/警察总局.md` — 战斗+搜索：武装自动炮塔仍在运行
  - S6: `industrial/军事哨站.md` — Boss遭遇：失控军用无人机"守夜者"
- **本章任务**：
  - [ ] 穿过时间扭曲的商业街
  - [ ] 黑入警察总局的幸存服务器
  - [ ] 击败"守夜者"无人机Boss
  - [ ] 获取灰区中层安全通行代码
  - [ ] 发现地下设施的入口坐标

### 第三章：深渊之下

- **位置**：深层地下研究设施 + 维度裂隙临近区域
- **环境**：完全黑暗。应急灯每隔30秒闪烁一次——持续了十年，因为备用电源不知疲倦。走廊里回响着不属于人类的脚步声。墙壁上有时会出现不属于这个世界的影子。
- **关键场景**：
  - S7: `underground/地下实验室A区.md` — 被困研究员NPC，需要救援或审问
  - S8: `underground/维度裂隙观测站.md` — Boss遭遇："镜界行者"（跨维度生物）
  - S9: `underground/核心控制室.md` — 最终抉择点
- **本章任务**：
  - [ ] 深入地下实验室，避开或解决自动安保
  - [ ] 与被困十年的研究员对话，了解真相
  - [ ] 在观测站面对"镜界行者"
  - [ ] 到达核心控制室

### 终章：零号决策

- **位置**：核心控制室 + 维度裂隙室
- **Boss遭遇**：UEG CEO远程操控的武装平台"终末法庭" + 被裂隙能量强化的融合体
- **最终抉择**：
  - A. "关上它" — 关闭裂隙，灰区消失，所有共振核失去能量。数万回收者失业，UEG倒台。但镜界不会再扩张。
  - B. "驯服它" — 与研究团队合作，建立对裂隙的控制系统。共振核继续产出，灰区成为有管理的禁区。但控制可能失效。
  - C. "点燃它" — 过载裂隙引发链式反应，摧毁整个灰区。没有证据，没有后患。但数十平方公里化为焦土，镜界永远封闭。
  - D.（隐藏）"穿越它" — 如果你在第三层得到了足够的情报……裂隙的另一边是什么？没人知道。但有些人就是必须知道。

## 结局

### 结局A：封门人（条件：选择"关上它"，击败终末法庭）
灰区在48小时内收缩至零。围栏在一夜之间变成鬼城。回收者们散了，去下一个冒险、下一个绝境。铁鼠站在围栏的空旷广场上，看着地平线外第一缕没有颜色扭曲的晨光。他把弟弟的照片放回安全箱最里面——它不再需要放在随时能看到的地方了。

### 结局B：守门人（条件：选择"驯服它"，与研究员合作成功）
灰区成为人类历史上最危险、最富有的有管理禁区。"官方回收者"是新头衔。铁鼠有了自己的队伍，不再接别人的活。每个新人进来的时候，他都会说同一句话："灰区不欠你任何东西。你拿走的每一克，都是它施舍的。"

### 结局C：灰烬（条件：选择"点燃它"，击败融合体）
半径80公里的工业区在一夜间熔成了玻璃平原。没有人能解释为什么政府把这次爆炸叫做"必要的代价"。铁鼠在百里外的山脊上看着地平线燃烧了三天。他不知道的是，灰下曾经埋着弟弟的最后一个信号的位置——现在它和他弟弟一样，永远找不到了。

### 结局D：镜中人（条件：发现全部三层真相+特殊物品+选择穿越）
铁鼠走进裂隙的那一刻，感觉到一种从未体验过的温暖。裂隙没有吞噬他。它在等他。十年后，围栏的回收者之间流传着一个传说：如果你在灰区深处的某堵墙上看到一行刻字——"对面也没那么糟 / 铁鼠"——你就知道你离裂隙已经近到危险了。
