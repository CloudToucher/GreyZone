# 灰区地图

> 灰区是一个以核心向外逐层展开的不规则圆形。从外到内共六个区域。
> 所有区域存在"五花八门，稍弱偏向"的物品分布原则——不写死。

## Zone 0：围栏镇（安全区 🟢）

| 项目 | 内容 |
|------|------|
| **定位** | 灰区南缘外的回收者据点——走投无路的亡命之徒的最后一站 |
| **规模** | 常驻800-1200人。旺季（春季补给潮+秋季清算期）可达1500+。淡季（严冬/酷暑）回落至600。流动回收者占比约40%——他们签短期合同、赚一笔就跑（或死）。周围散落大量被占据的空建筑 |
| **安全等级** | 🟢 绿区（但偶有变异生物从隔离带溜进来，夜晚巷子不建议独走） |
| **主要设施** | 铁壁合同中心、工坊(Lv1-Lv3可升级)、医疗站、补给仓库 |
| **民间设施** | 酒馆"最后一杯"（情报）、骡子胡同黑市（老高）、龙盾秘密工作室、黑水名义会所 |
| **小队领地** | 可在镇周边空建筑划定安全屋/工作间。领地权益受铁壁默许保护 |
| **灰币流通** | 是。铁壁发行的内部结算币——出镇后兑换率约1灰币=0.03美元，几乎等于废纸。这确保了回收者只能回来 |
| **结晶交易** | 低级(D~E)在镇内常见流通。C级以上稀少——大多被UEG收走了 |
| **势力存在** | 铁壁(公开)、龙盾(隐蔽)、黑水(隐蔽)、各回收者小队 |
| **基调** | 这里没有英雄。只有欠债的、逃命的、和想再赌一把的 |

## Zone 1：工业外缘区（浅层 🟡）

| 项目 | 内容 |
|------|------|
| **定位** | 灾变前的新沪港临港工业带 |
| **危险等级** | 🟡 黄区——低至中风险。新手入门地，自由进出 |
| **结晶丰度** | D~C级为主。偶有B级在隐藏区域或旧设备核心中 |
| **常见敌人** | 拾荒者(人类)、变异犬(1d4+1只)、残旧安保机器人、流浪回收者(可敌可友) |
| **主要场景** | |

### 石化工厂
- 管道迷宫+化学污染+反应釜残渣
- 敌人：拾荒者(多)、变异犬、偶有镜界行者
- 特殊：化学泄漏区域(无防化服→每小时CON检定)
- 稍弱偏向：工业零件、化工制品、旧UEG设备

### 集装箱码头
- 堆积如山的集装箱塔
- 敌人：拾荒者、流浪回收者、残旧安保机器人
- 特殊：垂直空间——可以从集装箱顶部移动。部分集装箱未开箱(需要开锁或重型工具)
- 稍弱偏向：进口货物(随机)、海运工具、走私品

### 旧药厂
- UEG旗下旧制药厂，生物实验室残留
- 敌人：变异啮齿群、拾荒者、旧药厂安保
- 特殊：部分区域被废弃实验样本污染(偶然的异常生物)
- 稍弱偏向：医疗品、实验数据、化学材料

### 军事哨站
- 灾变后联合政府的旧军事哨站，已废弃但设施坚固
- 敌人：残旧安保机器人(多)、拾荒者、偶有PMC远征队巡逻
- 特殊：防空机枪(可修理使用)、弹药库(需开锁)、通讯设备(可联系外界)
- 稍弱偏向：军用装备、武器弹药、通讯器材

### 守望者出没
守望者在此区域没有固定据点，但会派出小队巡逻和采集。遇见守望者时：
- 他们通常不会主动开火
- 可能愿意交易信息或物资
- 但也可能要求你离开——"这是我们的采集区"

## Zone 2：城镇废墟区（中层 🟠）

| 项目 | 内容 |
|------|------|
| **定位** | 灾变前的沿海小镇和商业区 |
| **危险等级** | 🟠 橙区——中至高风险。建议Lv2+，标准回收者的主战场 |
| **结晶丰度** | C~B级为主。隐藏区域可能有A级 |
| **常见敌人** | PMC佣兵、重型安保机器人、镜界行者(偶发)、异能军阀(据守区域) |
| **主要场景** | |

### 沿海小镇
- 沿海岸线的小型居民镇。房屋密集，道路狭窄
- 敌人：拾荒者(镇内多)、流浪回收者、偶有镜界实体
- 特殊：海面异常区——水下有小型裂隙，周围散落高级结晶。潜水需要CON(极难)+PER(极难)
- 稍弱偏向：民用物资、渔船设备、走私品

### 中央商业街
- 灾变前镇中心的商业街：银行、商场、写字楼、餐厅
- 敌人：PMC佣兵(常驻巡逻)、重型安保机器人(银行金库)
- 特殊：银行金库(开锁噩梦+电子设备极难→A级结晶)、商场楼顶(狙击位)、写字楼高层(俯瞰全街道)
- 稍弱偏向：奢侈品、金融数据、商业设备

### 警察总局
- 旧镇警察局+拘留区+证物室+小型军械库
- 敌人：PMC佣兵(可能在此设立前哨)、残旧安保机器人
- 特殊：军械库(需开锁困难)、证物室(随机物品)、拘留区(可能有被困的NPC)
- 稍弱偏向：执法装备、武器弹药、案件档案

### 废弃通讯站
- 旧UEG内部通讯设施。守望者在此区域活跃——这里曾经是他们的通讯节点
- 敌人：守望者(可交涉)、PMC远征队(有时来搜刮)、镜界行者
- 特殊：旧档案地下室(证明UEG在灾变前就知道裂隙存在)、通讯设备(可修复用于联系外界)
- 守望者在这个区域有一个半永久性的据点——"前哨"。如果你想和他们深度接触，在这里。
- 稍弱偏向：通讯器材、电子设备、旧文档

## Zone 3：荒野异常区（内层 🔴）

| 项目 | 内容 |
|------|------|
| **定位** | 灾变前采石场+周边野地，灰区能量严重扭曲的开放地带 |
| **危险等级** | 🔴 红区——高风险。建议Lv4+。旧采石场矿脉是已知的最大地表结晶产地——但去的人有一半没回来 |
| **结晶丰度** | B~A级。旧采石场矿脉是已知的最大地表结晶产地 |
| **常见敌人** | 变异熊、精英镜界行者、高级异能军阀(此区域至少2个)、辐射风暴本身 |
| **主要场景** | |

### 旧采石场
- 废弃采石场+勘探坑道网络。灰区化后矿壁上大量异常结晶裸露
- 敌人：变异熊(巢穴)、异能军阀"铁心"(保护着一小群逃难平民)、镜界行者
- 特殊：坑道矿脉(A级结晶×1+少量B级)、紫色水底(潜水→S级结晶核心——取出触发辐射爆发)
- 稍弱偏向：矿物、异常结晶(全等级都有)、工业设备

### 辐射变异生态带
- 灰区能量最扭曲的地表区域之一。植物和动物异常生长但并非全部敌对
- 敌人：变异生物(不定)、镜界实体(比Zone 2更多)、异能军阀"静默"叶琳
- 特殊：异常药材(可制药)、异常样本(龙盾高价收)、发光植物(可作为夜路标识)
- 稍弱偏向：生物材料、异常样本、变异药材

### 开阔高地
- 采石场周边的丘陵地带。长视距——你能看到远处的敌人，远处的敌人也能看到你
- 敌人：PMC远征队(可能在此设立观察哨)、变异生物、UEG无人机(偶发)
- 特殊：多处旧军事观察点(有遗留装备)、无线电塔(可修复)。开阔：掩体少，需要烟雾弹或潜行
- 稍弱偏向：军用设备、通讯器材、侦查装备

## Zone 4：地下设施区（深层 🔴⚫）

| 项目 | 内容 |
|------|------|
| **定位** | 灾变前UEG的核心研究综合体，全部位于地下 |
| **危险等级** | 🔴 红区至 ⚫ 黑区。建议Lv6+。完全黑暗+狭窄通道+高密度镜界实体 |
| **结晶丰度** | A级为主。观测站裂隙旁可能产出S级 |
| **环境** | 完全黑暗(命中-4)。狭窄通道。回声放大噪音。部分区域缺氧 |
| **常见敌人** | 高级安保机器人、镜界行者Alpha、融合体、UEG自动防御系统 |
| **主要场景** | |

### 地下实验室A区
- UEG生物/医学实验区。培养室、样本冷藏库、手术室
- 敌人：残旧+重型安保机器人、变异实验体、镜界行者
- 特殊：旧实验数据(剧情线索)、医疗设备(可带出给老郑)、生物样本(守望者感兴趣)
- 稍弱偏向：医疗设备、实验数据、生物材料

### 地下实验室B区
- UEG物理/能源实验区。能源导管、粒子加速器残骸、控制终端
- 敌人：重型安保机器人(多)、融合体(初)、镜界实体(裂隙近距吸引)
- 特殊：可用的精炼终端(可在此精炼低级结晶，但需要破解电子设备极难)、能源导管(触碰→重创伤害)
- UEG的结晶精炼厂核心在此。但设备需要特定知识才能启动。
- 稍弱偏向：能源设备、电子部件、异常结晶(加工级)

### 维度交汇观测站
- 裂隙近距离观测设施。灰区能量密度最高的人类建筑
- 敌人：镜界行者Alpha(Boss)、镜界行者(多)、融合体
- 特殊：近距离裂隙暴露(辐射3+每轮1d4重创伤害于近距)、4个可激活的能量抑制器
- 隐藏：控制室天花板暗舱——UEG CEO个人档案(结局D线索)
- 稍弱偏向：异常结晶(全等级)、观测设备、维度相关物品

## Zone 5：核心控制区（原点 ⚫）

| 项目 | 内容 |
|------|------|
| **定位** | "零号井"——维度交汇原点。灰区的心脏 |
| **危险等级** | ⚫ 黑区——致命。不建议单人或低于Lv8进入。这是终局之地 |
| **结晶丰度** | S级。但能活着带走的人...不多 |
| **环境** | 维度交汇近距离暴露。时空流速偶尔变化。物理法则极度扭曲。重力异常 |
| **入口条件** | 仅限击败镜界行者Alpha后，通过观测站→核心控制室通道 |
| **Boss** | 终末法庭(UEG指挥平台+融合体)——150血槽 |
| **终局选择** | 关闭裂隙/驯服裂隙/继续掠夺/走进镜界 |

## 区域转移

| 方向 | 方式 | 耗时 | 安全度 |
|------|------|------|--------|
| 围栏镇→工业外缘 | 步行/车辆穿过隔离带 | 10-30分钟 | 较高(隔离带有巡逻) |
| 外缘→城镇废墟 | 沿旧公路/管道向北 | 30-60分钟 | 一般(路上有拾荒者+变异生物) |
| 城镇→荒野 | 沿旧公路继续向北/爬山 | 45-90分钟 | 较低(开阔地带+强敌) |
| 荒野→地下设施 | 找到电梯井/通风井/维修通道入口 | 15-30分钟(搜寻入口) | 极低(入口隐蔽+附近有镜界实体) |
| 地下→核心 | 观测站→核心控制室通道 | 仅限击败Alpha后 | 致命 |

## 结晶分级速查

> 异常结晶全部是同一种物质。区别仅在于体积/纯度/能量密度。
> 不能手动合并——必须有精炼设备。UEG地下有唯一已知的精炼厂。

| 等级 | 能量密度 | 典型出现 | 市场价(灰币) | 用途 |
|------|---------|---------|-------------|------|
| **S** | 极高 | Zone 5、Boss体内 | 市价无意义——已知不足一手之数 | T3突破、传说物品 |
| **A** | 很高 | Zone 3~4、精英军阀 | ~8000 | T2→T3突破 |
| **B** | 高 | Zone 2~3 | ~400 | T1→T2突破 |
| **C** | 中 | Zone 1~2 | ~20 | T0→T1突破、武器镀层 |
| **D** | 低 | Zone 1、普遍搜刮 | ~1 | 弹药调质、小加工 |
| **E** | 微弱 | 各处碎屑 | 批量 | 最低级加工、UEG精炼原料 |

**UEG精炼厂**（地下实验室B区）：约20:1的比例将低级结晶精炼为高级。这是UEG灰区经济的主要来源。
