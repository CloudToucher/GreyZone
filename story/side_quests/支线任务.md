# 支线任务：《灰区：撤离》

---

## 支线#1：老高的账本

**触发条件**：与围栏基地的军火商"老高"对话，好感度≥中立
**触发位置**：围栏基地 — 骡子胡同
**任务描述**：老高放出去一批武器给一个叫"水蛭"的商人——这位已经两个月没回基地了。老高说："你去找找。找到武器归你三成，找不到把他手指头带回来也行。"

**流程**：
1. 去城区唐人街一带找水蛭的行踪
2. 搜索唐人街的废弃店铺（见场景文件）
3. 发现水蛭已死，尸体旁有武器箱和警告信——信上说"别再往灰区深处运武器，否则下一个是你"
4. 选择：带武器回去给老高/追寻警告信的来源

**奖励**：信用点300 + 老高好感+3 + 任选一件武器(稀有★★★以下)

**失败后果**：老高好感-2，部分武器价格上涨，但不影响主线

**DM注意**：警告信关联到第二章的军事封锁线——有组织在阻止武器流入灰区深处。追寻警告信会解锁隐藏支线#6

**黑潮交互**：黑潮逼近后，老高的进货渠道被黑水截断——他更需要这笔武器。同时，拾荒者群大规模迁徙期间可能在唐人街出现更多武器交易（势力时钟：拾荒者群 第1格）

**势力关联**：老高（独立商人）/ 与黑水竞争武器渠道

## 支线#2：医生郑的紧缺物资

**触发条件**：与围栏基地的医生"老郑"对话，好感度≥中立
**触发位置**：围栏基地 — 医疗帐篷
**任务描述**：老郑急需一批抗生素和止痛针。"工业区的旧药厂库存里应该有——我去过，但那里现在住了一窝'土皮'（变异啮齿类生物群）。"

**流程**：
1. 前往工业区旧药厂（场景：`industrial/旧药厂.md`）
2. 在药厂搜索药品（侦察检定难度：困难）
3. 与"土皮"群战斗（普通敌人，带中毒攻击）
4. 拿到药后带回基地（陷阱：高价值药品在未消毒背包装着可能被污染）

**奖励**：全军用医疗包×1 + 急救包×2 + 老郑好感+4（后续治疗费用-30%）

**失败后果**：老郑好感-1，但仍有基础医疗服务

**DM注意**："土皮"数据见敌人图鉴§1.4。药品被污染的风险是DM裁量插曲——如果玩家不注意存储条件

**黑潮交互**：黑潮抵达Zone 1前，药厂的老鼠群被黑雾征兆激怒——地下室比平时多了1d3群。黑潮到来后，鼠群的行为模式改变——它们开始有组织地收集药品并运输到更深处（"为什么？"——给DM的未来伏笔）

**势力关联**：老郑（独立医生）/ 与守望者医疗站有潜在合作（如果好感7+）

## 支线#3：锯子的约定

**触发条件**：与工兵"锯子"对话（围栏基地工坊）
**触发位置**：围栏基地 — 工坊
**任务描述**：锯子要你在荒野区找一台老式推土机的柴油引擎控制模块。"别问为什么——我需要它修基地的备用发电机。坐标在荒野东侧旧采石场。"

**流程**：
1. 穿越荒野区（辐射风险+异常区）
2. 在旧采石场找到推土机（被异常植物缠绕）
3. 拆卸引擎控制模块（INT+维修检定，困难）
4. 带回基地

**奖励**：信用点200 + 工坊升级折扣20% + 锯子好感+3

**失败后果**：无特殊后果，只是基地发电机暂时修不好（偶尔断电，黑暗中的游戏）

**DM注意**：采石场附近有一个异常区，辐射等级2。这是考验玩家准备工作的地方

**黑潮交互**：第5周后黑潮抵达采石场——推土机被黑雾覆盖，拆卸更难（检定-10）。但黑雾在柴油引擎上留下的冷凝液可用于制作临时抗潮蚀涂层（IR+1, CR+1，持续1次战斗）

**势力关联**：锯子（独立工兵）/ 发电机修好后→围栏镇供电恢复→所有镇内NPC的时钟推进加速（有电了，大家能做更多事）

## 支线#4：唐人街哀歌

**触发条件**：进入城区唐人街，通过侦察发现某个店面内异常
**触发位置**：城区 — 废弃唐人街
**任务描述**：一家麻将馆的里间有一台仍在工作的老式录音机，播放着同一个女人的声音重复同一句话:"小林……小林你在哪……"。追踪信号源（INT+电子设备检定），找到发射器——在地下室，一具骸骨旁边，还有一封未寄出的信。

**流程**：
1. 搜索麻将馆（侦察+搜索）
2. 发现录音机→追踪信号源
3. 下到地下室（可能有变异动物）
4. 找到骸骨+信
5. 选择：埋葬骸骨/不管

**奖励**：（如埋葬）获得银戒指（贵重品，售价300信用点）+ 信中提到城区另一个地点——隐藏补给点坐标

**失败后果**：找不到地下室入口或被变异动物击退。可以下次再来。

**DM注意**：信的内容暗示范畴——灰区刚形成时的混乱撤离中，一对母女被分开。补给点有优质装备

**黑潮交互**：随着黑潮逼近Zone 2，该区域的拾荒者和幽灵信号增多——麻将馆的录音机可能会出现新的录音："小林...黑乎乎的东西来了...小林...它们在大街上。快躲起来。"（谜题升级，暗示黑潮不只是一种气候现象——它可以"记录"感知）

**势力关联**：无特定势力——这是一个纯世界描述的支线，增加灰区的人文厚度

## 支线#5：围栏角斗

**触发条件**：基地声望达到一定程度（完成2个以上任务或成功撤离3次）
**触发位置**：围栏基地 — 地下角斗场
**任务描述**：围栏基地有一个非法的地下角斗场——回收者之间可以打赌局。有人挑战你："敢不敢不带枪进去？指虎对指虎。" 

**流程**：
1. 接受挑战
2. 只带轻型近战武器（指虎/小刀）进入斗笼
3. 战斗处理（近战规则）+ 围观者下注
4. 连赢2场则解锁"围栏王"称号（全基地声望+5）

**奖励**：每场胜 信用点100 + 解锁购买稀有物品权限

**失败后果**：输掉不会死（规则限制），但输掉的赌注+一周内被部分NPC嘲笑（社交-2）

**DM注意**：对手数据需要即时生成（普通人类回收者，属性3-8浮动）

**黑潮交互**：黑潮逼近围栏镇后，地下角斗场的赌注从灰币变成了抗潮蚀装备、"潮蚀庇护所"的席位——变成了一种末日下的黑暗经济

**势力关联**：围栏镇地下文化 / 围栏王称号在铁壁撤离后变得有价值——回收者们需要一个非官方的组织者

## 支线#6：武器线的尽头（线索来自支线#1的警告信）

**触发条件**：追寻支线#1警告信的来源
**触发位置**：军事封锁线边缘的废弃通讯站
**任务描述**：警告信的来源指向灰区中层的一个通讯站，那里被一个自称"灰区守望者"的组织占据。他们不是掠夺者——他们是灾变后被困在灰区里没有出去的研究员和安保人员，自发组成的小团体。他们试图阻止异常结晶流出，因为他们知道UEG在做什么。

**流程**：
1. 前往废弃通讯站（场景：`urban/废弃通讯站.md`）
2. 与守望者首领对话（交涉/威吓/情报收集）
3. 获得关于UEG和裂隙的部分真相
4. 选择：加入守望者（获得灰区中层通行许可+特殊装备)/举报给PMC（获得大量信用点但锁死真结局路线）

**奖励**：（加入守望者）信用点500 + 稀有防具×1 + 主线第三章关键情报
（举报）信用点3000 + PMC好感+10 + 锁死结局D

**失败后果**：交涉失败→守望者成为敌人→失去内部情报来源

**DM注意**：此支线是主线第三章的铺垫。守望者的情报可以直接改变玩家对灰区的理解。举报路线是"简单模式"——更容易打通，但拿不到真结局

**黑潮交互**：黑潮到达Zone 3-4后，守望者的处境更加危急——通讯站可能会被黑雾迫使搬迁到地下档案室。此时触发此支线→守望者首领给的回报不再是"情报"，而是"撤离协助+可能的同盟"

**势力关联**：守望者（三派系都有利益涉入）\| 如果选择举报→铁壁安保好感+10，势力时钟加速→但守望者变为敌人

## 支线#7：地下室的钢琴

**触发条件**：在地下设施中探索时自然发现（侦察+搜索）
**触发位置**：地下研究设施 — 生活区C
**任务描述**：地下研究设施的生活区有一台被精心维护的立式钢琴。旁边有一本手写日志——研究员之间的秘密通信，用乐谱写的。如果玩家会读谱（或INT+电子设备破解），会发现隐藏信息：设施深处有一间被遗忘的"零号样本室"，存放着初始裂隙接触记录。

**流程**：
1. 在地下生活区发现钢琴+日志
2. 解密乐谱信息（INT+电子设备 困难）
3. 找到隐藏的零号样本室
4. 获得第一个接触记录（关键剧情道具）

**奖励**：关键剧情道具×1 + 经验值+30 + 解锁结局D的特殊条件之一

**失败后果**：解密失败不影响主线，只是错失真结局条件之一

**DM注意**：这是结局D的前置条件之一。结合主线剧情信息，是三个"隐藏真相碎片"中的第一个

**黑潮交互**：第3-4周黑潮进入Zone 4后，钢琴所在的音乐室被黑雾微弱渗透——琴弦的泛音延伸到更低频。如果玩家在雾中弹琴→琴声会在整个Zone 4的地下管道网络中共振传播→吸引In（她被迫提前现身）。如果玩家在林出现前先发现了钢琴且RSN足够高（5+），他们可能"听"到钢琴的回应——在另一头，有人在弹同样的旋律

**势力关联**：研究员·林 / 结局D前置条件

## 支线#8：空降物资

**触发条件**：随机事件或荒野区探索中发现坠毁的无人机
**触发位置**：荒野区任意区域
**任务描述**：一架标有UEG标志的货运无人机坠毁在荒野中。这不像灰区残骸——落点太新了。附近还有活着的拾荒者正在抢货。

**流程**：
1. 接近坠机点（可能被拾荒者伏击或谈判）
2. 击退/交涉解决拾荒者
3. 搜索坠毁无人机（掉落表+固定稀有物）
4. 数据记录仪揭示：UEG仍在向灰区深处空投物资（为什么？给谁？）

**奖励**：随机军用级物资×1d3 + 数据记录仪（剧情道具）+ 信用点200

**失败后果**：被拾荒者抢走物资

**DM注意**：无人机的数据记录仪是"三个隐藏真相碎片"中的第二个——UEG在给灰区深处的研究站供电和补充物资。暗示灰区深处仍有UEG活动

**黑潮交互**：黑潮抵达后，荒野中坠落的无人机不仅来自UEG——也有围栏镇外逃难者发出的救援信号。一架无人机带有黑潮影响后的传感器数据——"雾内温度-12°C，持续时间=未知，密度=流动性半固态。请在雾中佩戴抗潮蚀面罩——标准等级不够。"

**势力关联**：UEG / 结局D前置条件（碎片2）
