# 随机事件表：《灰区：撤离》"黑潮"战役

## 触发规则
- 每30分钟游戏内时间 → DM投1d100
- 进入新场景 → 额外投一次
- 使用当前所在区域对应的事件表
- **黑潮规则**：如果当前场景已被黑潮覆盖 → 除正常投表外，额外投一次黑潮事件表（10%概率触发）
