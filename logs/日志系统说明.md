# 日志系统说明：《灰区：撤离》

---

## 四维日志体系

| 日志 | 目录 | 内容 | 读者 |
|------|------|------|------|
| **会话日志** | logs/session/ | 完整的冒险故事——叙事体，像小说 | 玩家 + DM |
| **战斗日志** | logs/combat/ | 每轮检定、伤害、状态变化——数据表格化 | DM为主 |
| **探索日志** | logs/exploration/ | 已探索区域、发现物品、信息汇总——清单式 | 玩家 + DM |
| **系统日志** | logs/system/ | 所有投骰和数值变动——逐行记录 | DM专用 |

---

## 系统日志格式

逐行记录，使用标签前缀：

```
[游戏内时间] [标签] [内容]

标签类型：
[检定] [暗骰] [攻击] [防御] [HP变化] [SP变化]
[物品+] [物品-] [移动] [战斗开始] [战斗结束] [先攻]
[经验+] [升级] [专长] [状态变化] [饥饿] [口渴] [流血]
[辐射] [噪音] [事件] [NPC] [存档] [DM记录]
```

## 日志查看指令

| 指令 | 效果 |
|------|------|
| "查看冒险日志" | 显示最近会话日志摘要 |
| "查看战斗记录" | 显示最近战斗详情 |
| "查看探索笔记" | 显示已探索区域和发现 |
| "查看状态变化" | 显示最近系统日志摘要 |
