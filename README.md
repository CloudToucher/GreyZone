# 灰区：撤离 — Gray Zone: Extraction v3

> 一个以异能+装备战斗、开放探索、高风险撤离为核心的战术TRPG。
> AI DM 驱动的非线性世界。有真实后果的每次突袭。

---

## 这是什么

《灰区：撤离》是一款 AI DM 驱动的战术 TRPG。你扮演一名"回收者"——受雇于私人武装公司铁壁安保的自由佣兵，进入被维度交汇撕裂的封锁区"灰区"，搜刮一切有价值的东西，然后在敌人、异常生物和异能军阀杀死你之前活着撤回到围栏镇。

**每次突袭都是一场赌博**：带进去的是赌注，带出来的是回报。死在灰区里？安全箱里的东西保得住——其余的，包括你的枪和命，都留在那。

这个世界有枪、有异常能量、有觉醒的异能者，还有维度交汇对面投来的沉默目光。

---

## 核心特色

- **血槽制**：每个角色有若干个血槽（CON决定），每个槽有健康/轻伤/重伤三种状态。伤害填充方式决定你是否还能站着。
- **异能+装备战斗**：以近战和异能为核心，射击为辅。武器固伤+弹药决定伤害。被动异能始终生效，主动异能消耗能量池。
- **共鸣与风险**：RSN属性代表对异常能量的亲和度。高RSN带来强力异能——但意志不够会失控。
- **灰币经济**：围栏镇内部的结算货币。出镇无效——你只能继续回来。
- **开放探索**：工业区、城区、荒野、地下设施。四种区域各有特殊规则。
- **工坊试验**：没有预设配方——玩家和DM共同"发明"新物品。异常结晶镀层、相位蚀刻、自制探测器...想做就试试。
- **安全箱机制**：死亡可重生——但只有安全箱里的物品能带回来。
- **多个结局**：灰区的命运取决于你的选择——关上它、驯服它、榨干它，或者...走进去。

## v3 核心变更

与v2相比：
- HP数字→**血槽制**(H/L/S三态)
- AP点数→**1标准+1快速+自由**动作
- 新增**共鸣(RSN)**属性+**异能系统**(被动/主动)
- 新增**能量池**+**共鸣失控风险**
- 围栏镇**完整生态**：公司、黑市、情报网络、领地权益
- 所有物品改为**模板参考制**——DM可创建新物品
- **灰区三定律**：所有异常现象的统一物理法则

## 如何开始

### 1. 首次设置
```bash
python tools/dice_pool.py -o        # 生成骰池
```

### 2. 创建角色
- 打开 `characters/templates/角色生成指南.md` 按8步创建
- 或参考 `characters/templates/示例角色_铁鼠.md` 了解示例
- 将完成的角色卡放入 `characters/active/`

### 3. 启动AI DM
- 打开 `dm_guide/快速开始_DM提示词.md`
- 将里面的提示词复制发给新AI会话
- AI阅读规则后即可以DM身份开始游戏

### 4. 查看状态
```bash
python tools/char_scan.py              # 查看角色状态
```

## 规则摘要

| 系统 | 核心 |
|------|------|
| 属性 | 7属性(STR/AGI/CON/PER/INT/WIL/RES)，35点分配 |
| 技能 | 20技能，30点初始 |
| 检定 | d100 ≤ 属性×10+技能×5+难度修正+武器精度 |
| 伤害 | 子弹骰+AGI/3↓-护甲(最低1)。子弹决定伤害，枪械决定精度/射程 |
| 行动 | 主2AP/次1AP/反应1AP/自由移动(AGI×2m)。AP=3+RES/3↓ |
| 弹种 | FMJ基准/HP空尖/AP穿甲/亚音速。5种口径各有基准伤害骰 |
| 掩体 | 半掩体+15 / 全掩体+30 / 轻掩体+10。与基本闪避叠加 |
| 多元协作 | 1辅+5, 2辅+10, 3辅+15(上限)。掩护射击=队友+10闪避 |
| 濒死 | HP≤0→每轮CON检定→HP≤-10死亡 |
| 死亡 | 重生，仅安全箱物品保留 |
