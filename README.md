# 灰区：撤离

沿用原游戏的新沪港灰区、2027年“湮灭”事故、2037年黑潮战役、原有势力与五系异能。系统、界面与实现重新编写，主持接入使用 **dsh**。

核心设计见 [主持模型与系统的职责边界](docs/SYSTEM_DESIGN.md)。模型拥有查询、试算和受控世界编辑权限；服务器负责角色账本、骰子、行动权与原子提交。

## 运行

需要 Node.js 22.12+，已有可用模型配置的 `@deepseek-ai/dsh`。

```powershell
npm install
npm run build
npm start
```

打开 http://127.0.0.1:4317 ，直接告诉主持人想扮演什么人。可以只写一句概念，也可以贴完整设定，讨论身份、装备、自创异能、背景、关系和玩法偏好。主持人提供可修改的草案；采用后，在原作地图中开始适合这个角色的场景。没有必选职业、固定装备包、强制债务或固定开场。

游戏以交谈为主，角色表和地图按需打开。可以询问、扮演、行动，也能直接对裁定提出异议。普通讨论不耗世界时间；安静现场的短暂确定性交流直接继续。有检定、资源或显著风险的行动会展示条件，玩家可修改或确认。专长、能力和经历在开局后仍能通过讨论修订。

```powershell
npm install -g @deepseek-ai/dsh
# 在 dsh 自身界面配置模型及凭据
dsh web
npm run doctor -- --live
```

可在 `.env` 配置 `DSH_BIN`、`DSH_TIMEOUT_MS`、`PORT`、`DATA_DIR`。Windows 的 DSH_BIN 应指向安装包的 `lib/bin.js`。网页不接收模型密钥。

## 多人和保存

最多四人，各自与主持人讨论角色，采用草案后才进入世界。只有本人能采用角色修订、确认行动，房主只能撤回滞留裁定。共享时间会影响所有已入场角色的饥渴和出血，尚在创建的角色不参与结算。

默认监听本机。可信局域网可设置 `HOST=0.0.0.0` 和实际网页地址的 `ALLOWED_ORIGIN`。朋友通过六位房间码加入。当前席位与最近战役保存在浏览器；切换战役会保留回到原角色的入口。

`.data/<房间码>.json` 是完整存档，版本为2。新字段读取时补齐，旧角色资产与凭证保留。旧版规则演练房间仍可继续，新入口统一使用 dsh。网页导出的是**不含GM秘密或凭据的阅读记录**，不是可导入备份。完整备份请停服后复制 `.data`。版本1的中间试作存档移入 `.data/legacy-v1/` 保留。

```powershell
npm run check

npm run test:ui
# 实际调用配置好的模型：自由建角、修改、开局、交谈、使用自创异能

```

开发运行 `npm run dev`，前端5173、服务端4317。详见 [玩法规则](docs/GAME_DESIGN.md)、[原设定](docs/SETTING.md)、[架构](docs/ARCHITECTURE.md)、[dsh接入](docs/DSH.md)。

能力成长由主持人与玩家按经历和代价共同修订，没有自动升级树。战斗仍是按意图逐步结算的抽象交锋。叙事合理性依赖模型，数值校验不能证明一个创意是否可行；两者的边界见设计文档。浏览器测试使用确定性主持替身，真实 dsh 验证单独运行并记录在 `.data/verification/`。
