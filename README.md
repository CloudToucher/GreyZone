# 灰区 · 团桌

AI 主持的多人 TRPG 网页。玩家用自然语言提交意图，房主发起一批裁决；AI 理解情境、扮演人物、选择规则并决定后果。程序负责真骰子、批量记账、私密视图、长期资料和恢复。没有预写结果分支、逐句自动反击或固定任务线。

背景为 2037 年新沪港灰区。角色身份、关系和开场共同商定；默认轻规则为 `d20 + 属性 + 一个适用专长2`。完整规则在网页手册及 [content/rules](content/rules) 中。

## 启动

需要 Node.js 22.16+、npm，以及已经配置模型、可以正常对话的 dsh。实测 Node 22.23.2、dsh 0.1.1-rc.2。没有自带模型，也不使用 OpenCode。

```powershell
npm install
# 没有 dsh 时安装；已有配置继续沿用
npm install -g @deepseek-ai/dsh@0.1.1-rc.2
npm run doctor
npm run build
npm start
```

打开 `http://127.0.0.1:4317`。复制 `.env.example` 为 `.env` 可调整端口、数据目录和 `DSH_BIN`。保留已有 `.env` 时检查旧变量；新配置不再读取旧 OpenCode 项目配置。`npm run dev` 启动 Fastify 和 Vite 开发服务。

本机和可信局域网为首版部署范围。局域网将 `HOST` 改为 `0.0.0.0`，同伴访问这台机器的 IP 和端口。每桌最多六名玩家，每人最多四个角色。房间码用于加入，个人令牌用于恢复自己的席位；浏览器本地保存入口。不要将它作为公开互联网服务直接暴露。

## 开始跑团

1. 创建团桌，将六位团桌码交给同伴。
2. 点角色栏加号，写下姓名和设想，与主持人讨论档案、能力与初始装备。讨论完成后点“采用这份角色档案”。
3. 在行动板写下目标、做法、协作条件和备选办法。尚未冻结的行动可修改、撤回。
4. 房主点“发起本轮裁决”。本批冻结，之后的输入进入下一批。未提交的角色不会被默认托管。
5. 团录、检定、物品和角色表随阶段提交一起更新。只有新的选择、歧义或重大未知后果才暂停询问。场外讨论单独保存，不推进时间。

私密行动和分队信息通过角色视野投影；房主没有 GM 全知权限。同一席位能看自己控制角色的资料，主持仍需区分各角色知道什么。地图只展示已知地点与连接。

## 保存与恢复

- `.data/v3/table.sqlite`：权威世界、席位、行动、草稿、检定、幂等回执、账目和统计。
- `.data/v3/dsh-sessions/`：每桌一个原生持续 GM 会话，包含压缩与恢复记录。
- `.data/v3/runtime/`：生成的 GM profile 补丁与本地诊断。含内部 MCP 凭证，不应公开。
- 浏览器“导出我的记录”只导出本席位可见内容，不是完整存档备份。

正常刷新继续读取服务器状态。进程中断后，未完成裁决显示“继续本轮裁决”；恢复会重新提供权威状态、未决事项和已掷骰，保留已经发布的阶段。失败不重掷、重试不重复交易。更正通过有原因的新变更留痕。

完整备份请先关闭服务，复制整个数据目录；恢复时放回原处再启动。不要只复制运行中的主 SQLite 文件而漏掉 WAL。每个数据目录只允许一个服务进程。

本次重建保留 Git 历史、用户配置及无关未跟踪文件。旧存档在原 `.data` 和 `.backups/legacy-data`，旧设定提取在 `.backups/setting-sources`。新存档为格式 3，**不自动迁移旧存档**。

## 验证与实现资料

```powershell
npm run check              # 类型、生产构建、确定性测试
npx playwright install chromium
npm run test:ui            # 桌面和手机操作验证
# 也可使用已安装的 Chrome：$env:PLAYWRIGHT_CHANNEL='chrome'
npm run test:live          # 真实模型，20 轮；会消耗已配置模型额度
npm run test:live:multiplayer # 双人交易、能力、分队实测
```

真实验证记录位于 `.data/verification/`，每次独立建桌。`scripts/report-live.ts <验证目录>` 从原生事件生成逐轮统计和已发布叙述，排除模型思考与连接凭证。模型主持质量与确定性测试分别报告，详见 [验收记录](docs/VERIFICATION.md)。

中断验证可设置 `LIVE_DIRECTORY` 为原测试目录后重新运行 `test:live`；脚本依据已完成轮数继续。双人脚本使用 `MULTIPLAYER_DIRECTORY`。这些是开发验收入口，日常玩家直接在网页继续本轮即可。
