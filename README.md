# 灰区：撤离 — Gray Zone: Extraction

> 一个以射击、搜刮、撤离为核心的战术TRPG。
> 非线性开放世界。有真实后果的每次突袭。

---

## 这是什么

《灰区：撤离》是一款 AI DM 驱动的战术射击 TRPG。你扮演一名"回收者"——受雇于私人武装公司的亡命之徒，进入被维度裂隙撕裂的封锁区"灰区"，搜刮一切有价值的东西，然后在敌人和环境杀死你之前活着撤离。

**每次突袭都像一次赌局**：带进去的装备是你赌注，带出来的物资是你的回报。死在灰区里？安全箱里的东西能保住——其余的，包括你的枪和命，都留在那。

---

## 核心特色

- **战术射击**：部位瞄准、掩体系统、压制机制、弹种克制——每一发子弹的伤害取决于口径和弹种，而不是枪本身
- **搜刮三阶**：快速搜索 / 标准搜索 / 彻底搜索——每次搜索都有真的物品等着你
- **撤离压力**：到达撤离点后还要等2-4轮——这段时间里噪音会吸引敌人，你的心跳和倒计时一起加速
- **子弹即伤害**：武器决定精度和射程，子弹决定伤害。FMJ/HP/AP/亚音速各有取舍
- **开放世界**：工业区、城区、荒野、地下设施——四种区域各有特殊规则，非线性探索
- **基地建设**：医疗室、工坊、军械库、情报中心、生活区——五大设施三级升级
- **安全箱机制**：死亡可重生——但只有在安全箱里的物品能带回来

## 如何开始

### 1. 首次设置
```bash
python tools/dice_pool.py -o        # 生成骰池
```

### 2. 创建角色
- 打开 `characters/templates/角色生成指南.md` 按8步创建
- 或参考 `characters/templates/示例角色_铁鼠.md` 了解示例
- 将完成的角色卡放入 `characters/active/`

### 3. 启动AI DM
- 打开 `dm_guide/快速开始_DM提示词.md`
- 将里面的提示词复制发给新AI会话
- AI阅读规则后即可以DM身份开始游戏

### 4. 查看状态
```bash
python tools/char_scan.py              # 查看角色状态
```

## 规则摘要

| 系统 | 核心 |
|------|------|
| 属性 | 7属性(STR/AGI/CON/PER/INT/WIL/RES)，35点分配 |
| 技能 | 20技能，30点初始 |
| 检定 | d100 ≤ 属性×10+技能×5+难度修正+武器精度 |
| 伤害 | 子弹骰+AGI/3↓-护甲(最低1)。子弹决定伤害，枪械决定精度/射程 |
| 行动 | 主2AP/次1AP/反应1AP/自由移动(AGI×2m)。AP=3+RES/3↓ |
| 弹种 | FMJ基准/HP空尖/AP穿甲/亚音速。5种口径各有基准伤害骰 |
| 掩体 | 半掩体+15 / 全掩体+30 / 轻掩体+10。与基本闪避叠加 |
| 多元协作 | 1辅+5, 2辅+10, 3辅+15(上限)。掩护射击=队友+10闪避 |
| 濒死 | HP≤0→每轮CON检定→HP≤-10死亡 |
| 死亡 | 重生，仅安全箱物品保留 |
