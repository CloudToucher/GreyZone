## 玩家阅读标准

玩家游戏时只盯四处：

1. **DM 当前回复**：本轮主内容，直接给出场景、裁决、确认变化、新信息和下一步空间。
2. **共享看板**：公开且跨回合持续有效的局面。
3. **自己的角色卡**：个人状态权威，主要看血槽、能量、装备、安全箱、关系和当前处境。
4. **行动输入区**：写下一步意图的地方，不是状态来源。

当前模式不把历史日志当玩家入口；如果界面里出现执行记录，它只用于调试或审计。

## 这是什么

《灰区：撤离》是一款围绕“进入灰区、取得有价值的东西、活着撤离”的 TRPG。它不是严格自动化规则引擎，也不是只靠即兴的自由叙事。它的设计核心是：

- 规则提供少量公平锚点。
- AI DM 保留自主裁决、即兴和创造性。
- 文件系统保存运行状态、公开看板、DM 备忘和长期因果。
- 资料按需加载，避免 AI 在长局中被无关上下文淹没。

---

## 核心特色

- **柔性语义裁决**：玩家表达“想让世界发生什么”，DM 判断可行性、风险、代价和后果。
- **少量硬锚点**：检定公式、血槽填充、动作经济、灰区三定律、隐藏信息边界不可破坏。
- **血槽制**：角色用健康、轻伤、重伤槽运行；权威字段是 `blood.total/light/severe`。
- **安全箱保险**：死亡时安全箱内物品保留，包括高价值物品；这是游戏性妥协，用来保护少量关键收益。
- **异能与共鸣**：RSN 决定异常亲和和能量池，也会带来失控风险。
- **模板制物品与敌人**：表格是参考，DM 可在世界法则内创造变体。
- **公开/隐藏分层**：玩家看共享板；DM 内部钩子、伏笔和真相留在 DM 专用文件。
- **模块化按需加载**：战斗、场景、敌人、物品、势力和历史只在触发时读取。

## 如何开始

1. 玩家直接把 `先看这里.md` 里的那句话发给 AI。
2. AI 先判断是否已有角色：没有就创建角色，已有就直接开局，信息不足就只问一个最少问题。
3. DM/启动器如需手动开局，复制 `一句话开局.md` 或 `开始游戏.md` 中的启动段。
4. 每轮行动时，玩家只在行动输入区写自然语言：当前想做什么、想确认什么、想避免什么。

## 当前规则基线

| 系统 | 当前基线 |
|------|----------|
| 检定 | `d20 + 属性修正 + 技能修正 + 其他 >= DC` |
| 属性 | STR / AGI / CON / PER / INT / WIL / RSN |
| 技能 | v5 压缩为 14 项，等级 0-5 |
| 血槽 | `blood.total = CON * 2 + 4`，创伤 H→L→S，重创 H→S |
| 能量 | `energy.max = RSN * 3` |
| 动作 | 每轮 1 标准 + 1 快速 + 自由动作 |
| 护甲 | IR 抗创伤，CR 抗重创 |
| 成长 | v5 XP 里程碑，以 `rules/数值配置表.md` 为准 |

## 设计原则

- 规则服务语义体验。
- 工程服务 AI 稳定性。
- AI DM 的创造性不是漏洞，是核心能力。
- 公开事实、角色事实和 DM 内部事实必须分层。
- 没有触发就不加载，加载了也只读需要的模块。
