# 旧采石场

## 概况
| 项目 | 内容 |
|------|------|
| 区域类型 | 荒野 |
| 安全等级 | 极危险 |
| 光照条件 | 明亮（开阔室外） |
| 特殊环境 | 异常辐射区（等级2，50-150 mSv）。采石场坑底有异常重力阱——一旦进入坑底，移速减半，无法奔跑 |

## 环境描述

### 初次到达时的描述
采石场像一个被巨人掷出的石块砸出来的天坑——层层叠叠的灰色岩壁向下螺旋，最低处是一个静止的、反射着奇怪紫色光泽的水潭。那不是水的颜色——水本身是无色的，紫色来自水底散发出的微光，某种柔软的、脉动着的辐射。头顶的天空颜色在这里也和别处不一样：不是灰蓝，而是铅白，仿佛整个采石场被罩进了一个看不见的泡泡。

一台推土机侧翻在第一层岩阶上，半边埋在碎石里。它的铲斗高高翘起，像一个僵死的大型动物的下巴。藤蔓——变异过的，带着淡紫色的纹路——从推土机的驾驶舱里长出来，好像它在那停了足够久，大自然已经开始回收它。

### 区域结构
- 上层岩阶：入口→视野开阔，可俯瞰整个采石场
- 螺旋车道：原矿车道，沿岩壁盘旋向下，部分坍塌
- 中间平台：推土机所在，有旧工棚和油罐
- 坑底：异常辐射水源+重力阱区，植被异常茂盛
- 北面悬崖：有一个人工挖掘的侧洞——旧勘探坑道

## 特殊规则
- 辐射等级2：每30min辐射量+1。防辐射装备/药物可减缓
- 异常重力阱（坑底）：移速减半，无法奔跑，STR-3。WIL检定(标准)每轮对抗迷失感
- 螺旋车道部分坍塌：沿车道下行需AGI检定(标准)避免滑落。失败→坠落1d3×5米伤害
- 植被中的变异藤蔓：进入密集植被区域有20%概率触碰到针刺藤蔓（1d4伤害+中毒风险CON检定）

## 事件触发
| 条件 | 触发事件 |
|------|---------|
| 取出引擎控制模块时 | 推土机残骸松动——整个平台震动。如果不在3轮内离开推土机，滚落的推土机可能将玩家带到坑底（伤害+辐射） |
| 在坑底停留30分钟+ | 紫色水源开始微微发亮——越来越亮。有什么东西在水的另一头回应这个光（维度异常） |
| 取得矿壁上异常结晶后 | 整片矿脉的晶体同时闪烁一次——在40km外灰区核心的裂隙也同时闪烁，UEG观测站接收到信号 |

## DM笔记
- 柴油引擎控制模块是核心目标——让玩家至少需要一次维修检定来提取它
- 坑底的紫色水源是一个维度弱化点——和裂隙同源但非常稀薄。如果玩家有仪器或研究员NPC，可以检测到
- 变异熊不是必须战斗的——它基本上是来喝水的。如果玩家不惹它，它也不理玩家。但如果被攻击，它会变成可怕的敌人（攻击变异动物的部位规则同人类——见核心规则书§4.4）
- 古旧雕刻的存在是谁刻的、什么年代——DM不在此处给出答案。它是一个长期伏笔
