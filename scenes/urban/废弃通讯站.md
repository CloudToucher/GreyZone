# 废弃通讯站

## 概况
| 项目 | 内容 |
|------|------|
| 区域类型 | 城区 |
| 安全等级 | Zone 2（守望者控制区） |
| 推荐等级/人数 | Lv2-5 / 1-4人 |
| 光照条件 | 昏暗（室内灯光抑制在低亮度以节省能源） |

## 环境描述

### 初次到达时的描述
从外面看，这是通讯公司的大楼——不起眼的七层办公楼，被周围的建筑遮了大半。但靠近了就看出了异样：每层窗户都用沙袋堵住了，只留出窄缝做射击口。屋顶上有肉眼可见的细线——伪装网，人为地模糊了建筑的轮廓。这地方被故意改造成了不显眼的防御据点。

正门是关着的，但旁边的消防梯上去了一个穿灰衣的人影——他们看见你了。五秒钟后，门口的喇叭低低地传来一把女性的声音:"停下来。谁派你来的？"

### 区域结构
- 外部：被监视的入口区→围墙缺口
- 1F：检查站→前厅→无线电室
- 2F-4F：生活区（守望者成员宿舍/公共厨房/医疗室）
- 5F：指挥中心→少校办公室
- 6F-7F：瞭望点和狙击位→屋顶通讯阵列

## 特殊规则
- 全域屏蔽：电子设备在通讯站内自动减半范围
- 守望者报警：如果在内部开战，1d4轮内所有守望者哨兵就位
- 和平区：受守望者协议保护——只要不主动攻击，这里就是安全的

## 涌现引擎

### 场景的核心张力
通讯站是灰区中唯一的"安全点"——但安全不是免费的。守望者有自己的议程，而黑潮正在改变他们的议程。

### 即兴种子
- 无线电室截获到一个不该存在的信号：一个孩子的声音，反复播放同一条信息——但信息是十年前录制的，信号源却在地下80米
- 少校的办公室门口有一双旧军靴——崭新的，好像今天刚穿过。但她今天没出过门
- 厨房的水龙头深处偶尔能听到雾震——叮，叮，叮，水表在震颤。但这不是地震——是有人在"下面"敲水管

### 黑潮交互
- **雾到时机**：第6-7周（Zone 2 边缘），第8周接近
- **雾前征兆**：无线电截获越来越频繁且不规律——黑雾在干扰大气层。少校的RSN失控事件增加——她开始避开其他人。屋外的沙袋积水变成了灰色——不是脏水，是积了某种和环境不匹配的沉淀物
- **雾中变化**：黑雾抵达通讯站外围。守望者启动紧急防卫协议——所有出口被封锁，所有人进入地下档案室。少校在雾中失控了一次——这次她对自己人的伤害让她做出了最后一个决定

### 动态威胁池
| 投入 | 威胁组合 |
|------|---------|
| 低 | 守望者哨兵盘问(交涉)、电磁干扰(非战斗挑战)、流浪拾荒者接近(被哨兵驱赶) |
| 中 | 被守望者误解为仇敌(好感低)、PMC接近通讯站外围、外部丧尸动物冲击防线 |
| 高 | 直接攻击通讯站(多哨兵+增援)、黑雾迫使全员转移到地下 |

### 动态发现池
| 类型 | 示例 |
|------|------|
| 物资类 | 公共厨房食物/水(守望者分享)、医疗室(好感5+可领取)、武器维修台免费修一件武器 |
| 线索类 | 无线电室通讯日志、指挥中心档案柜系统记录各势力、少校的私人日记(好感8+可阅读——终结E的故事条件)、地下档案室UEG加密档案盒 |
| 怪诞类 | 通讯阵列收到的信号来源是未来的日期、某人私人物品中的一张照片——拍的是"外面"，但画面里有一座不该存在的建筑 |
| 黑潮相关 | 雾中失控的无线电捕获(黑雾的频率模式)、少校的RSN失控=黑雾共振效应的证据 |

### DM即兴备忘录
- 这里是玩家从"掠夺者"转变为"知情者"的转折点
- 根据好感度逐层解锁信息，不要一次性全盘托出
- 守望者三派系的人物（少校、老吕、烬）在这里和周边区域可找到
- 地下档案室的UEG加密档案是结局A/B的数据条件
- DM可以通过少校的对话埋下多个结局方向的线索
