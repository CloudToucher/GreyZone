# 维度裂隙观测站

## 概况
| 项目 | 内容 |
|------|------|
| 区域类型 | 地下设施 |
| 安全等级 | Zone 4（Boss战） |
| 推荐等级/人数 | Lv6-9 / 3-5人 |
| 光照条件 | 特殊：裂隙本身发出波动性银白色光芒——每轮在标准光照和昏暗间随机切换 |
| 特殊环境 | 辐射等级3。时空不稳——时间流速偶尔变化，可能有回声/幻影。重力局部扭曲 |

## 环境描述

### 初次到达时的描述
你从电梯井爬出来——然后就看见了。观测站是一个三层高的圆形大厅，天花板是透光的观测穹顶，但穹顶外面不是天空——是紫黑色的虚空。大厅的正中央是裂隙：一道大约五米高、两米宽的银色裂缝悬浮在半空中，没有依托任何东西。它不是像门一样挂在墙上——它就悬挂在空间中，像世界本身被撕开了一道口子。裂缝的边缘在缓缓流动，液态的银光不断地向内落入又向外弹回，发出一种听不到的震动——你的牙齿能感觉到，像低音炮的共鸣压在你全身的骨骼上。

大厅四周的仪器大多数停止了工作，但有几个仍在闪烁——它们在自动记录裂隙的数据，十年来从未间断，用着深埋地下的备用核电源。四周走道环绕中央的裂隙向上螺旋，每层的扶手都被小心地擦拭过——没有灰尘。这里显然还有人在维护——但你暂时看不到任何人。

### 区域结构
- 中央：悬浮裂隙 + 观测平台（宽阔开合地，少量控制台可提供掩体）
- 螺旋走道(1F-3F)：绕裂隙盘升，每层有不同的研究设备和观察窗口
- 1F环廊：样本采集设备 + 4个能量抑制器
- 2F环廊：数据记录仪 + 全天域投影设备
- 3F环廊：控制室入口 + 紧急撤离舱

## 特殊规则
- 辐射等级3（重度）：每30分钟CON检定→辐射+1
- 裂隙光波动：每轮随机光照（标准/昏暗/刺目），调整全检定
- 重力异常区(中央2m内)：移速减半，不能闪避。但攻击裂隙中心目标命中+15
- 镜界渗透：每次使用高能武器，裂隙自动产生一个镜界行者
- 靠近裂隙越近WIL检定越难（中央区-20）

## 涌现引擎

### 场景的核心张力
裂隙在这里是"可见"的——它不是抽象的概念，而是一道悬在空中的伤口。玩家要做的不是"击败裂隙"，而是决定如何对待它。而裂隙一直在"看"着他们。

### 即兴种子
- 靠近裂隙2m内时——不是听到声音，而是脑中闪现了一幅画面：一个银色的世界，河流在天空中流淌。那画面平静得让人害怕
- 某个能量抑制器的外壳上有人用手指划出的图案——不是电路图，是一个人的侧脸轮廓
- 记录仪的十一年数据中有一段缺失——不是删除了，而是"没有被记录"。设备开着，但传感器在那个时刻指向了同一频率：空白

### 黑潮交互
- **雾到时机**：第3-4周（Zone 4被黑潮覆盖）
- **雾前征兆**：裂隙颜色从银色转为铁灰色——不再波动。数据记录仪显示裂隙扩张速度在最近24小时加速了300%。维修人员在控制室看到了不认识的传感器读取——像是"对面的气压在变化"
- **雾中变化**：黑雾从电梯井涌入观测站。裂隙在黑雾中变成了漆黑的裂缝——不是银光，是墨黑色的光（光的颜色怎么可能是墨黑色？但它就是）。雾中的裂隙不再随机产生镜界行者——而是产生"黑潮行者"。Alpha被黑雾"染色"

### 动态威胁池
| 投入 | 威胁组合 |
|------|---------|
| 低 | 镜界行者 ×1(裂隙产生)、辐射/重力(环境挑战)、时空幻影 |
| 中 | 镜界行者 ×1d3+1(每5轮或高能武器)、重力紊乱 |
| 高 | Boss阶段——镜界行者Alpha(裂隙前)、黑雾中的Alpha变体(黑潮行者Alpha第4周+)、多镜界行者同时出现 |

| 类型 | 示例 |

| 怪诞类 | 镜界中的短视画面(银色世界/天空河流)、一名研究员的遗物(一副眼镜放在仪器上——镜片里反射的都是反着的人脸)、能量导管旁的地面刻痕("选择在你")——上一批来过这里的人留下的 |

### DM即兴备忘录
- 气氛比战斗轮更重要。裂隙的存在应该时刻被描述
- Alpha不一定非要战斗——4个抑制器+正确INT操作可暂时稳定裂隙而不用打Alpha
- 裂隙中的画面是伏笔——"镜界"不是单纯的敌对维度
- 第4周后黑潮到达——观测站是所有地点中最早被黑雾完全覆盖的。届时：黑雾从电梯井涌入 + Alpha被黑潮行者Alpha替换 + 裂隙颜色变为墨黑
