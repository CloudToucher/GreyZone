# 地下实验室A区

## 概况
| 项目 | 内容 |
|------|------|
| 区域类型 | 地下设施 |
| 安全等级 | 极危险 |
| 光照条件 | 完全黑暗（无光源检定-40，应急LED每30秒闪烁一次提供短暂可见） |
| 特殊环境 | 封闭空间：氧气含量偏低（CON检定，每1小时失败→疲劳-10全检定）。回声增强：噪音传播范围×2 |

## 环境描述

### 初次到达时的描述
液压门在你背后关闭，声音在走廊里分成几十个回音副本，层层叠叠地滚向黑暗深处。应急灯刚好在你的眼前闪了一次——那一瞬间，走廊的全貌被白光定格：白色瓷砖，几十年前的白色，被霉菌蚀成了暗灰色。左墙根有一排轮椅——空的。右墙的公告栏上还贴着十年前的通知："周五健身活动取消，全体员工参加维度能量稳定性培训。"

空气很薄——每次呼吸都要比地面多吸一口。不知道是氧气浓度问题还是单纯的压抑感，但你已经开始觉得头有些沉了。走廊的深处，应急灯下次闪烁的间隙里，有东西在地面上移动——脚部在地板瓷砖上摩擦的声音，拖沓、不规则。

### 区域结构
- A区入口：气密门→消毒前室→主走廊→生活区(左)/实验室(右)/储藏区(直走)
- 生活区：宿舍→公共厨房→A区核心——研究员·林的藏身处（改装的图书馆）
- 实验室区域：普通实验室×3→样本室→维度观测设备
- 储藏区：药品库→装备库→备用发电机室
- 深层通道：A区尽头→电梯井(失电)→通往维度裂隙观测站

## 特殊规则
- 完全黑暗：无光源时所有检定-40。手电/夜视仪可消除惩罚。紧急闪烁(每30秒一次)：在闪烁瞬间检定惩罚仅为-10
- 回声放大噪音：所有噪音范围×2。重型武器（狙击/爆炸）的噪音会触发1d3个镜界行者从就近墙中出现
- 氧气消耗：每1小时进行CON检定(标准)，失败→疲劳状态(-10全检定)
- 自动门的欺骗：部分门看起来是打开的但实际上被安保程序锁定了——需要通过时需电子设备检定

## DM笔记
- 研究员·林是本场景的剧情核心——DM应让她的出场自然但有分量。她是一个十年没见活人的幸存者，她的反应应该混合着恐惧、期待和不信任
- 钢琴（支线#7）放在A区音乐室——这是一个丰富场景细节的机会。描述琴键上的手指印（林偶尔弹）、琴凳下压着的手写笔记、琴调教得很好（林有很多时间）
- 如果玩家重启电力→全照明恢复→带来方便但也会激活更多自动安保。这是一个价值权衡
- 暗室中的"零号协议"文件是关键剧情揭示——提供终章的背景信息
