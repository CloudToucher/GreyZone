## 守夜者（失控军用无人机）

### 概况
| 项目 | 内容 |
|------|------|
| 区域类型 | 特殊 — Boss遭遇 |
| 安全等级 | Zone 1（军事哨站顶层甲板） |
| 光照条件 | 明亮（露天） |
| 特殊环境 | 暴风预警：每3轮可能发生一次雷击 |

### 战场描述

军事哨站原本是灰区边缘的防空据点——现在它成了守夜者的家。三层楼的混凝土堡垒被削去了顶，上面的直升机甲板现在是它悬停的地方——一个在空中来回漂移的暗色三角。它的引擎发出低频的嗡嗡声，不是很大，但震着你的胸骨。

甲板上有残留的军事物资——翻倒的弹药箱（可引爆）、生锈的防空机枪（可修理）、倾斜的铁架（半掩体）。守夜者不是静止的——它在甲板上空5-15米处来回漂移，传感器扫描全场。它的唯一弱点是背面的散热面板——但要让它的后背暴露在地上，必须有人把它的注意力拉走。

### 可利用地形
| 地形 | 利用方式 |
|------|---------|
| 东角防空机枪 | INT+维修 极难修理→4d10对空武器，需3轮连续操作 |
| 甲板掩体 | 半掩体(+2)。飞弹爆炸范围内——需要移动换掩体 |
| 弹药箱(西北角) | 1d4+2个——每个引爆造成5d8范围爆炸(5m) |
| 甲板下平台(东北) | 全掩体(+5)。适合救援濒死者 |
| 直升机升降台(中央) | 强磁场——电子设备-4。守夜者被引到此处传感器-2 |

### 黑潮交互
- **黑潮影响（第7-8周）**：守夜者被黑雾"污染"——阶段转换时增加20%几率触发异常行为（随机攻击友军、突然断电、以不自然的频率扫描）

### 战后变化

守夜者残骸坠落在甲板上。可提取核心处理器（STR标准）。甲板下方的武器库被砸开：稀有★★★武器×1 + 军用弹药箱（AP弹×5匣）+ UEG军用通信记录（剧情道具）。哨站北边可以看到通往地下设施的通风口。

### DM战斗管理
- 修理防空机枪者成为核心——其他人掩护
- Boss命中率约50-65%。连续3轮全空→降难度
- 过载模式给玩家倒计时决策
- 噪音传播——战斗后可能有额外小遭遇

## 黑潮行者Alpha（第4周后，Zone 4）

### 出现条件
- 第4周后，玩家进入Zone 4任意区域时，30%几率遇到Alpha
- 必定触发：在维度裂隙观测站停留30分钟以上

### Boss数据
| 属性 | 数值 |
|------|------|
| 血槽 | 总数 28 |
| 主要攻击 | 黑触须鞭 — 2d6+2 创伤，8m范围，命中所有附近目标 |
| 次要攻击 | 潮蚀吐息 — 1d8 重创 + 2层潮蚀，扇形30°，每3轮1次 |
| 护甲 | IR 4, CR 6（黑结晶外壳） |
| 先攻 | d20-2（慢） |
| 特殊 | 潮蚀光环 — 10m内每轮全员获得 1层潮蚀 / 濒死时释放雾震（全员 AGI DC 12）/ 死后爆炸——3m内 2d6 重创 |
| XP | 80 |

### 战利品

- Alpha核心 ×1（剧情道具——可在其中"读到"黑潮的性质）
- 镜界样本(罕见) ×1
