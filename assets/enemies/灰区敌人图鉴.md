## 三、Boss（Tier 3）

### 3.1 BOSS-01：守夜者（失控军用无人机）

| 属性 | 值 |
|------|-----|
| HP | 200 |
| AGI | 6 |
| CON | —（机械） |
| PER | 10（多频谱传感器） |
| 武器 | 主炮 (2d12 能量伤害, 基础65) / 小型导弹 (3d8 爆炸, 基础50, 每轮最多1发) / 近距机枪 (5.56 FMJ, 1d8, 基础70) |
| 护甲 | 10（军用装甲） |
| 先攻 | 6+1d10 |
| 经验值 | 100 |

**阶段机制：**

| 阶段 | HP | 行为变化 |
|------|-----|---------|
| 1：巡航模式 | 200-100 | 主炮每2轮1次+导弹每3轮1次。飞行高度中 |
| 2：受损模式 | 100-50 | 主炮每轮+导弹每2轮。装甲击穿→护甲6。引擎不稳→AGI-2 |
| 3：过载模式 | 50-0 | 所有武器同时可用，每次攻击10%自伤(-5HP)。引擎起火→每轮HP-5。最后必自毁 |

**特殊能力：**
- 扫描波：每3轮全频扫描，隐藏目标暴露→导弹锁定
- 干扰弹：释放电磁干扰，所有电子瞄准失效1轮
- 过热关机：散热面板被击毁→失去1轮行动

**战场环境**：军事哨站上层平台——钢架半掩体。角落弹药箱(引爆伤害双方)。远角防空机枪(可修理，4d10对空)。
**推荐策略**：一人修防空机枪，两人牵制，一人打散热面板。

**战利品**：
- 守夜者核心处理器(2000信用点)
- 军用电子零件×5
- 随机稀有武器×1
- 精准射手专长进度+5
