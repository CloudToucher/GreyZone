## 一、输出格式参考

### 对话输出（精简版，非强制模板）
```
📍 [位置名] | ⏰ [游戏内时间]
[当前局势概括]

📋 状态（仅在玩家状态有显著变化时展示）
> 📖 完整叙事已写入 logs/session/

❓ [自然的下一步行动空间]
```

完整叙事写入 `logs/session/{日期}_会话{N}.md`，覆盖≥3种感官，不出现在对话中。

## 二、日志协议

| 日志 | 目录 | 写入时机 |
|------|------|---------|
| 会话日志 | logs/session/ | 场景切换、重要对话、战斗结束、会话结束 |
| 战斗日志 | logs/combat/ | 战斗开始→每轮→结束 |
| 探索日志 | logs/exploration/ | 进入新区域、完成搜索、获取信息 |
| 系统日志 | logs/system/ | 每次检定/血槽变化/物品变动——标签行格式 |

### 系统日志标签
```
[检定] [暗骰] [攻击] [防御] [血槽变化] [能量变化]
[物品+] [物品-] [移动] [战斗开始] [战斗结束] [先攻]
[经验+] [升级] [专长] [状态变化] [饥饿] [口渴] [流血]
[辐射] [噪音] [事件] [NPC] [异能使用] [共鸣失控]
[存档] [DM记录]
```

### 玩家可见
```

```
**角色不知道的信息，玩家在任何可见文件中都不该看到。**

## 四、多人模式

- 每个玩家将行动写入 playground.md 对应区域
- DM 收集所有行动后统一执行
- 物理分离的队伍之间信息不互通
- DM托管角色同受信息限制

## 五、死亡处理

```
1. 血槽全部重伤(S = 总数) → 倒地濒死
2. 每轮 CON 检定：
   成功 → 稳定（仍倒地）
   失败 → 恶化标记+1
   连续2次失败 → 死亡
3. 队友急救（标准动作, INT+急救）：
   成功 → 1重伤→轻伤（S-1, L+1）；若S<总数则恢复意识
4. 确认死亡：
   - 安全箱物品保留 → 退回基地仓库
   - 其余物品全部丢失
   - 角色在基地重生（全血槽健康，能量全满）
   - 经验值保留
   - 记录在角色卡成长记录中
```
