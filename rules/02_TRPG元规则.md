# TRPG 元规则：《灰区：撤离》"黑潮"战役

> DM 工作流程和权限以 `../dm_guide/启动注入_AI_DM.md` 与 `../dm_guide/DM核心手册.md` 为准。
> 本文件只保留日志格式协议、信息层次、多人模式和死亡处理的具体规范。
> AI DM 在会话开始时先读启动注入；需要日志、信息隔离或多人细节时再查阅本文件。

---

## 一、输出格式参考

### 玩家可见回合输出（轻量护栏，非严格 schema）
```
## Scene Progression
[玩家可见叙事结果。只写角色能感知、能验证或已公开的信息。]

## Rulings
[必要裁决。只写检定目的、代价、结果和判例，不长篇讲规则。]

## Confirmed Changes
[血槽、能量、物品、位置、关系、任务进展等确认变化。]

## New Information
[新线索。区分确认事实与可疑迹象。]

## Next Directions
[自然行动空间，不给菜单式正确答案。]
```

`DM Notes` 只能写入 DM 专用位置，不进入玩家结果和 `table/shared_board.md`。

## 二、日志协议

| 日志 | 目录 | 写入时机 |
|------|------|---------|
当前模式不维护历史日志。重要摘要写入角色卡、共享板和 DM 速记。

### 系统日志标签
```
[检定] [暗骰] [攻击] [防御] [血槽变化] [能量变化]
[物品+] [物品-] [移动] [战斗开始] [战斗结束] [先攻]
[经验+] [升级] [专长] [状态变化] [饥饿] [口渴] [流血]
[辐射] [噪音] [事件] [NPC] [异能使用] [共鸣失控]
[存档] [DM记录]
```

## 四、多人模式

- 每个玩家将行动写入 playground.md 对应区域
- DM 收集所有行动后统一执行
- 物理分离的队伍之间信息不互通
- DM托管角色同受信息限制

## 五、死亡处理

```
1. 血槽全部重伤(S = 总数) → 倒地濒死
2. 每轮 CON 检定：
   成功 → 稳定（仍倒地）
   失败 → 恶化标记+1
   连续2次失败 → 死亡
3. 队友急救（标准动作, d20+INT修正+急救）：
   成功 → 1重伤→轻伤（S-1, L+1）；若S<总数则恢复意识
4. 确认死亡：
   - 安全箱物品保留 → 退回基地仓库
   - 其余物品全部丢失
   - 角色在基地重生（全血槽健康，能量全满）
   - 经验值保留
   - 记录在角色卡成长记录中
```
