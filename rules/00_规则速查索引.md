# 规则速查索引：《灰区：撤离》v2.0

> **AI DM 每次会话必读。** 所有核心公式浓缩于一页。

## 属性（7个，35点分配，1-10）
STR(力)/AGI(敏)/CON(体)/PER(感)/INT(智)/WIL(意)/RES(决)

## 衍生数值

| HP | CON×4+10 |
| SP | CON×2+5 |
| AP | 3+RES/3↓（每轮刷新）|
| 闪避 | AGI+PER/2↓（与掩体叠加）|
| 先攻 | AGI+1d10 |
| 负重 | STR×5+20 kg |
| 移速 | AGI×2 m/轮（免费）|
| 远程基准 | AGI×10+技能×5+武器精度 |
| 近战基准 | STR×10+技能×5 |
| 安全箱 | 基础2格(军械库Lv1→3, Lv2→4) |

## 检定公式

```
成功条件：1d100 ≤ 基础值 + 难度修正
基础值 = 属性×10 + 技能×5（未受训 = 属性×5）
双属性: 基础值 = (A+B)×5 + 技能×5（未受训 = (A+B)×2.5↓）
```

## 难度修正

| 轻松+40 | 普通+20 | 标准±0 | 困难-15 | 极难-30 | 噩梦-45 | 奇迹-60 |

## 特殊骰

| 大成功 01-05 | 大失败 96-00(基础>100则99-00) | 临界 =基础值 |

## 行动经济（每轮AP=3+RES/3↓）

| 类型 | 行动 | AP |
|------|------|-----|
| 主 | 射击(单发) / 近战 / 投掷 / 急救他人 / 全力防御(+15闪避) | 2 |
| 主 | 射击(连射2发) 第2发-10 | 3 |
| 主 | 射击(扫射3发) 每发-15 | 4 |
| 主 | 精确瞄准 +5命中 | +1 |
| 次 | 换弹匣 / 换武器 / 快速搜索 / 绷带 / 探头(从全掩体) | 1 |
| 反应 | 闪避(每次被攻击) | 1 |
| 免费 | 移动 AGI×2m/轮 | 0 |
| 快速 | 快速射击(仅手枪/SMG, -10命中) | 1 |

## 射击模式速查

```
单发 = 2AP, ±0
连射2发 = 3AP, 第2发-10
扫射3发 = 4AP, 每发-15
火力压制 = 3AP, 不检定, 自动触发范围内敌人压制
```

## 伤害计算

```
伤害 = 子弹伤害骰 + AGI/3↓ - 目标护甲(最低1)
近战伤害 = 武器骰 + STR/3↓ - 目标护甲(最低1)
暴击(大成功): 伤害×1.5
```

| .44 | 1d8 | 重型手枪、杠杆步枪 |

| 弹种 | 修正 | 特效 |
|------|------|------|
| FMJ | 基准 | 通用 |
| HP空尖弹 | +3 vs无甲 / -2 vs有甲 | 流血概率+20% |
| AP穿甲弹 | -1 | 无视5护甲 |
| 亚音速 | -2 | 噪音-2级 |

## 部位瞄准

| 头部 -20 ×1.8 | 躯干 ±0 ×1.0 | 手臂 -10 ×0.8 | 腿部 -10 ×0.8 |

## 掩体（与基本闪避值叠加）

| 半掩体 +15 | 全掩体 +30(需探头1AP) | 轻掩体 +10(10伤后毁) | 高台 攻击+5 |

## 多人协作

```
协作任务: 1辅助+5, 2辅助+10, 3辅助+15(上限)
掩护射击: 消耗2AP, 指定队友本轮闪避+10
```

## 压制

被射击后WIL检定 → 失败=压制(-15全检定1d3轮) | 大失败=恐慌(跑向掩体+失去本回合) | 成功=本轮免疫后续压制

## 护甲

| 轻型3(躯干) | 标准6(躯干,AGI-1) | 重型10(躯干,AGI-2) | 头盔2(头) | 重盔4(头+面,PER-1) | 臂甲1 | 腿甲1 | 防化服(化学全免) | 防辐射服(辐射全免) |

## 濒死规则

HP≤0→倒地→每轮CON检定(失败HP-2), HP≤-10→死亡
急救(2AP,INT+急救): 成功→HP=1+重伤 | 大成功→1d6+1

## 生存阈值

| 饥饿: 4h→STR/CON-1, 8h→STR/CON/AGI-2, 12h→全-3+HP/h-2 |
| 口渴: 2h→AGI/PER-1, 4h→AGI/PER/INT-2, 6h→全-3+HP/30min-3 |
| 流血: 每轮HP-2, 绷带止血 |
| 辐射Lv1→CON-1 | Lv2→CON-2/HP上限-5 | Lv3→CON-4/HP上限-10 | Lv4→每30min HP-2d4+每小时CON(困难)失败→器官衰竭 |

## 噪音系统

| 无(近战/消音手枪+亚音速): 0-10m | 低(消音AR+亚音速): 10-30m | 中(手枪/SMG): 30-60m | 大(AR/霰弹): 60-150m | 极大(狙击/爆炸/LMG): 150-300m |
警觉度累积 → 同区备战 → 邻区靠近 → 呼叫增援

## 存储规则

```
随身负重=STR×5+20kg(超重100-120%移速减半, >150%无法战斗)
安全箱=2-4格(独立于负重) — 死亡唯一保留
基地仓库=无限容量 — 仅安全区可存取
撤离成功→随身物品全入库 | 死亡→仅安全箱保留
```

## 基地升级

| 医疗室(500/2000/5000): 休息HP×1.5→治重伤→HP+100% |
| 工坊(800/2500/6000): 修武器→制作弹药→制作稀有配件 |
| 军械库(1000/3000/8000): 安全箱+1→+1→弹匣×1.5 |
| 情报中心(600/3000/7000): +1撤离点→敌情标注→提前预报 |
| 生活区(300/1500/4000): 饥渴恢复+50%→精力充沛→休息+1EXP |

## 经验与等级（含突袭结算）

成功撤离: 基础20 + 物资加成(每1000cr=+5,上限50) + 击杀×2 + 新区域×5 + 隐藏×10 + 成就
失败: 战斗经验50%保留, 安全箱保留
| Lv1→Lv2: 50 | Lv3: 120(+属性) | Lv4: 220 | Lv5: 350(+属性) | Lv6: 520(+第2专长) | Lv7: 730 | Lv8: 980(+属性) | Lv9: 1280 | Lv10: 1650(+属性+第3专长) |
武器专精: 10杀(熟练+5命中)→30(专家+1伤)→60(大师再+5)→100(传奇,暴击+5)

## 搜索系统速查

| 快速1AP: T1×1(保底)+50%T1+20%T2 | 标准2AP: T1×2+T2×1+30%T2+8%T3 | 彻底3AP: T1×3+T2×2+40%T2+18%T3+3%T4 |
每区域最多3次搜索(各一次)。连续3区→必须插入非搜索活动。
Tier: T0垃圾(灰,5-30cr)→T1常见(白)→T2少见(绿)→T3稀有(蓝)→T4传说(紫)→T5神话(金,不可售)

## 突袭节奏

潜入(慢)→探索(中)→高峰(快)→撤离(极快)→结算(慢)
撤离点等待2d4轮，每轮d6: 1-3氛围/4-5普通敌人/6精英

## 区域特殊规则

| 工业区: 化学泄漏, 大量掩体 | 城区: 垂直空间, 狙击位 | 荒野: 异常区, 长视距 | 地下: 完全黑暗(-40), 回声放噪 |

## 时间

战斗每轮=6秒 | 搜索=5-30min | 相邻移动=5-15min | 长距=15-60min | 休息=1-8h
白天06-18(正常) | 黄昏18-20(-10) | 夜晚20-06(-25,无光-50)
