## 快速记忆卡（DM用，不替代查表）

```
检定: d20 + 属性修正 + 技能修正 + 其他 ≥ DC

属性修正 = 属性值 - 5（范围 -4 ~ +5）
技能修正 = 技能等级 0~5（受等级上限：Lv3解Lv3, Lv5解Lv4, Lv8解Lv5）

**命中对抗**: 
  远程: d20+AGI修正+技能+精度 ≥ 10+目标AGI修正+掩体
  近战: d20+STR修正+技能 ≥ 10+目标AGI修正
  未察觉目标: DC=8+掩体 (不计AGI)
  闪避(快速): d20+AGI+PER/2↓+掩体 vs 攻击方

难度: 轻松(8) / 普通(10) / 标准(12) / 困难(15)
       极难(18) / 噩梦(21) / 奇迹(24)

自然20 = 暴击（自动成功 + 1d6额外伤害，保持原伤害类型）
自然1 = 大失败

血槽: 总数=CON×2+4, 创伤 H→L→S, 重创 H→S
重伤惩罚: S=1→-2, S≥2→-5, S>半→昏迷, S=全→濒死

**v5 伤害**: 远程=固伤+弹骰-护甲IR(最低1), 近战=武骰+STR修正-IR(最低1)
**v5 重创**: 仅来自重创弹药(极稀有)/爆炸/环境。重创减免用护甲CR。
**v5 护甲**: 冲击减免(IR)抗创伤 + 重创减免(CR)抗重创。两维独立。

能量: 上限=RSN×3, 恢复=RSN/3↓+1/轮
异能: 连续使用每2次+1能(停3轮重置) + 每次RSN+1(战完清除)
**v5 失控**: RSN-WIL≥1~2→轻度, ≥3~4→中度, ≥5→重度

行动: 1标准 + 1快速 + 自由/轮
射击模式: 单发(±0), 连射2发(第2发-3), 扫射3发(每发-5)

掩体: 半掩体(+2), 全掩体(+5), 轻掩体(+1)

濒死觉醒: 任何区域 S=总数 可尝试觉醒新体系(DC15)
死亡: 队友可拖曳撤离 → 装备保留

**v5 武器**: 六类(手枪/SMG/步枪/霰弹枪/重型武器/近战)。改装决定个性。
**v5 M4改装**: 工坊可切换上机匣/枪管/供弹/骨架/异常套件。
**v5 技能**: 14项，初始25点。交涉合并说服/欺骗/威吓/情报收集。
**v5 专长**: Lv2需Lv4+30XP, Lv3需Lv7+60XP+剧情事件。
**v5 战场指挥**: 单人全检定+1(始终有效)，单人先攻+3(Lv3)。
```
