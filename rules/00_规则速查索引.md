## 属性（7个，35点分配，1-10）

STR(力) / AGI(敏) / CON(体) / PER(感) / INT(智) / WIL(意) / RSN(共鸣)

## 衍生数值

| 数值 | 公式 |
|------|------|
| 血槽总数 | CON × 2 + 4 |
| 能量上限 | CON + RSN × 2 |
| 能量恢复 | RSN/3↓ + 1（每轮专注/休息） |
| 闪避值 | AGI + PER/2↓（与掩体叠加） |
| 先攻 | AGI + 1d10 |
| 负重 | STR × 5 + 20 kg |
| 移速 | AGI × 2 m/轮（免费） |
| 远程命中基准 | AGI × 10 + 技能 × 5 + 武器精度 |
| 近战命中基准 | STR × 10 + 技能 × 5 |

## 血槽系统（核心变化）

```
血槽总数 = CON × 2 + 4
每个槽三个状态：健康(H) / 轻伤(L) / 重伤(S)
H + L + S = 总数
```

### 伤害应用

| 伤害类型 | 规则 | 来源 |
|----------|------|------|
| **创伤伤害** | H→L→S 递进填充 | 常规射击/近战/投掷 |
| **重创伤害** | H→S 跳过轻伤直击 | 暴击/爆炸/重型武器 |

### 重伤惩罚（只看S槽数）

| S | 状态 | 效果 |
|---|------|------|
| 0 | 正常 | 无 |
| 1 | 挂彩 | 全检定-5 |
| ≥2 | 力竭 | 全检定-20，无法复杂行动 |
| >总/2 | 昏迷 | 失去意识 |
| =总 | 濒死 | 倒地，每轮CON检定，连续2败→死 |

### 急救

濒死急救（标准动作, INT+急救）：成功→1重伤→轻伤
急救包（标准动作）：1d3轻→健 + 1重→轻
绷带（快速动作）：1轻→健

## 行动经济（每轮）

```
1 标准动作：攻击 / 投掷 / 急救他人 / 大型物品 / 精细操作
1 快速动作：换弹 / 切武器 / 快速搜索 / 绷带 / 探头 / 闪避
自由动作：移动(AGI×2m) / 对话 / 丢弃 / 观察
```

异能可额外提供标准或快速动作。

---

## 检定公式

```
成功：1d100 ≤ 基础值 + 难度修正
基础值 = 属性×10 + 技能×5（未受训 = 属性×5）
双属性: (A+B)×5 + 技能×5（未受训 = (A+B)×2.5↓）
```

## 难度

| 轻松+40 | 普通+20 | 标准±0 | 困难-15 | 极难-30 | 噩梦-45 | 奇迹-60 |

## 特殊骰

| 大成功 01-05 → 重创伤害 ×1.5 | 大失败 96-00(基础>100则99-00) | 临界 = 基础值 |

---

## 射击模式

```
单发 = 标准动作, ±0
连射2发 = 标准动作, 第2发-10
扫射3发 = 标准动作, 每发-15
火力压制 = 标准动作, 不检定, 自动压制
精确瞄准 = 叠加射击, +5命中, 需额外消耗快速动作
快速射击 = 快速动作, 仅手枪/SMG, -10
```

## 伤害计算

```
远程伤害 = 武器固伤 + 弹药伤害骰 - 目标护甲（最低1）
近战伤害 = 武器伤害骰 + STR/3↓ - 目标护甲（最低1）
暴击(大成功): 伤害×1.5, 转为重创伤害
护甲对重创伤害: 减免减半（向下取整）
```

## 弹药速查（FMJ基准）

| 9mm=1d6 | 5.56mm=1d8 | 7.62mm=1d10 | 12号鹿弹=2d6/1d4 | 12号独头=1d10+2 | .44=1d8 |

弹种: FMJ(基准) | HP(+3无甲/-2有甲+流血) | AP(-1伤+无视5甲) | 亚音速(-2伤+噪音-2)

## 异能系统（5体系树，最多2体系，无冷却仅耗能）

### 能量池

```
上限 = CON + RSN×2    恢复 = RSN/3↓+1 每轮    全恢复 = 安全休息1小时
```

### 核心机制

- 每人最多2体系。创建选1主修→T0·觉醒。
- 体系内若干子系(如元素→冲击/火/冰/电/爆裂)，每个子系独立Lv1~3。
- **子系成长消耗XP**：解锁30XP，Lv1→Lv2=40XP，Lv2→Lv3=60XP。上限由体系Tier决定。
- **晶体突破上限**：C×3→T0→T1，B×2→T1→T2，A×1→T2→T3。
- **B×3解锁第二体系**：揉碎涂抹，沉睡8h，CON+RSN(困难)，~1/3成功率。
- **濒死觉醒**：S=总+Zone3+深层灰区→整轮动作尝试觉醒任意体系T0(CON+RSN困难)。成功→觉醒+恢复意识。失败→加速死亡。
- 无冷却——仅耗能。进阶后同技能耗能降低。

### 五大体系（选1主修，T0→T3结晶进阶）

| 体系 | 主题 | T0主动(耗能) | T3新增 |
|------|------|------------|--------|
| 身体强化 | 近战·肉搏·生存 | 加速代谢(2能) | 能量过载**3d6重创**(1能) |
| 元素共鸣 | 远程能量·AOE | 共振冲击(3能) | **维度爆裂**(4能)20m范围重创 |
| 感知扩张 | 信息·探测 | 脉冲探测(2能) | 精神威压(2能)+危机预感 |
| 空间干涉 | 机动·闪避 | 空间折叠(4能) | 裂隙步(3能)全队可穿过 |
| 精神支配 | 团队·控制 | 意志共鸣(4能) | 恐惧光环(3能)范围压制 |

### 进阶规则

| 阶位 | 结晶需求 | 检定 | 失败 |
|------|---------|------|------|
| T0→T1 | C级×3 | 制作标准 | 材料损失 |
| T1→T2 | B级×2 | 制作困难 | 损失+RSN临时-1 |
| T2→T3 | A级×1 | 制作极难 | 损失+RSN永久-1+1d4重伤 |

**无冷却**——仅消耗能量。进阶后同技能耗能降低。

### 异常结晶（同一种物质，仅能量密度不同）

| 等级 | 密度 | 典型区域 | ~市价(灰币) | 用途 |
|------|------|---------|------------|------|
| S | 极高 | Zone5、Boss体内 | 不可购 | T3突破、传说物品 |
| A | 很高 | Zone3~4 | ~8000 | T2→T3突破 |
| B | 高 | Zone2~3 | ~400 | T1→T2突破 |
| C | 中 | Zone1~2 | ~20 | T0→T1突破、镀层 |
| D | 低 | Zone1 | ~1 | 弹药调质 |
| E | 微弱 | 各处 | 批量 | 基础加工、UEG精炼原料 |

不能手动合并——需精炼设备(UEG地下实验室B区，约20:1转化)。市价不稳定。

### 凭证（高级货币，3合1升级）

S→A→B→C→D→E。不可兑换灰币。发放方：铁壁(C~E)、守望者(B~C)、龙盾(A~B)、灰区(S)。

### 共鸣失控

RSN > WIL 时：差值2-3→偶尔幻觉 | 4-5→INT/PER-10+误判 | ≥6→每次异能WIL(困难)否则失控

## 存储

```
负重 = STR×5+20kg (100-120%移速减半, >150%无法战斗)
安全箱 = 2-4格(独立于负重) — 死亡唯一保留
基地仓库 = 无限 — 仅安全区可存取
撤离成功 → 随身全入库 | 死亡 → 仅安全箱保留
```

## 搜索

| 快速(快速动作): T1×1+50%T1+20%T2 | 标准(标准动作): T1×2+T2×1+30%T2+8%T3 | 彻底(标准动作): T1×3+T2×2+40%T2+18%T3+3%T4 |
每区域最多3次。连续3区→插入非搜索活动。

Tier: T0垃圾(灰)→T1常见(白)→T2少见(绿)→T3稀有(蓝)→T4传说(紫)→T5神话(金)

## XP系统

```
成功撤离: 基础20 + 物资(每1000cr=+5,上限50) + 击杀×2 + 新区域×5 + 隐藏×10 + 成就
失败: 战斗经验50%保留, 安全箱保留
XP消耗(安全区休息时):
  解锁新子系Lv1: 30XP | 子系Lv1→2: 40XP | Lv2→3: 60XP
  技能+1: 25XP | 属性+1: 100XP(每2级1次,最高10)
等级里程碑(自动,含额外XP):
  Lv1(0) | Lv2(50+30XP) | Lv3(120+40XP) | Lv4(220+50XP) | Lv5(350+50XP+专长2)
  Lv6(520+60XP) | Lv7(730+70XP) | Lv8(980+80XP) | Lv9(1280+90XP) | Lv10(1650+100XP+专长3)
武器专精: 10杀(熟练+5命中)→30(专家+1伤)→60(大师再+5)→100(传奇+暴击)
```

## 突袭节奏

潜入(慢)→探索(中)→高峰(快)→撤离(极快)→结算(慢)
撤离点等待2d4轮，每轮d6: 1-3氛围 / 4-5普通敌人 / 6精英

## 时间

战斗每轮=6秒 | 搜索=5-30min | 移动=5-60min | 休息=1-8h
白天06-18(正常) | 黄昏18-20(-10) | 夜晚20-06(-25,无光-50)

## 区域规则

| 工业区: 化学泄漏, 大量掩体 | 城区: 垂直空间, 狙击位 | 荒野: 异常区, 长视距 | 地下: 完全黑暗(-40), 回声放噪 |
