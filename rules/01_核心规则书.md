## 第一章：属性与衍生数值

### 1.1 七大基础属性

角色由7个基础属性定义，初始35点自由分配，每项1-10。

| 属性 | 缩写 | 含义 |
|------|------|------|
| 力量 | STR | 负重、近战伤害修正、后坐力控制 |

| 体质 | CON | 生命值上限、抗中毒/辐射、体力 |
| 感知 | PER | 搜索、侦察、聆听、威胁察觉 |

| 决断 | RES | 行动点、战术指挥、临场反应 |

### 1.2 衍生数值公式

## 第二章：检定系统

### 2.1 d100目标数判定

```
成功条件：投 1d100 ≤ 基础值 + 难度修正
基础值 = 关联属性×10 + 技能等级×5（未受训 = 关联属性×5）
复合属性：基础值 = (属性A+属性B)×5 + 技能等级×5
```

**示例1**：AGI6, 步枪Lv3, M4A1精度+5 → 基础值=(6×10)+(3×5)+5=60+15+5=**80**。标准射击(±0) → 需投≤80。

**示例2**：INT4, 开锁未受训 → 基础值=(4+AGI)×2.5（复合未受训）。若AGI=5，则=(4+5)×2.5=**22**。困难难度(-15) → 需投≤7。几乎不可能。

### 2.2 七级难度

| 难度 | 修正 | 场景举例 |
|------|------|---------|
| 轻松 | +40 | 白天百米外认出熟人 |
| 普通 | +20 | 安静室内听到隔壁脚步 |
| 标准 | ±0 | 靶场射击、普通房间搜索 |
| 困难 | -15 | 交火中爆头、黄昏远射 |
| 极难 | -30 | 黑暗撬锁、移动中狙击 |
| 噩梦 | -45 | 重伤状态下攀爬、暴风雨中射击 |
| 奇迹 | -60 | 无工具拆弹、千米盲狙 |

### 2.3 特殊骰结果

| 结果 | d100范围 | 效果 |
|------|---------|------|
| 大成功 | 01-05 | 最佳效果+额外收益（暴击：伤害×1.5） |
| 大失败 | 96-00（基础>100则99-00） | 灾难+负面后果 |
| 临界成功 | =基础值 | 成功但有瑕疵 |

### 2.4 对抗检定

双方各投d100，比较"基础值-投出值"（成功余量），余量大者胜。双方都失败则僵持。

**示例**：玩家潜行(AGI6+潜行Lv3=75) vs 敌人感知(PER5+侦察Lv1=60)。玩家投45(余量30)，敌人投35(余量25)。玩家30>25，潜行成功。

## 第四章：战斗系统

### 4.1 战斗流程

1. **遭遇**：伏击判定（双方侦察对抗），决定谁先手
2. **先攻投骰**：AGI+1d10，从高到低排列顺序
3. **轮循环**：每轮每角色有主行动(2AP)+次行动(1AP)+反应(闪避1AP)+自由移动(AGI×2m)
4. **结束**：一方全灭/投降→经验+战利品

### 4.2 行动点(AP)系统

| 行动 | AP消耗 | 类型 |
|------|--------|------|
| 射击（单发） | 2 | 主行动 |
| 射击（连射2发） | 3 | 主行动。第2发-10命中 |
| 射击（扫射3发） | 4 | 主行动。每发-15命中 |
| 精确瞄准（+5命中） | +1 | 叠加于射击 |
| 快速射击（-10命中） | 1 | 仅手枪/SMG |
| 近战攻击 | 2 | 主行动 |
| 投掷 | 2 | 主行动 |
| 换弹匣 | 1 | 次行动 |
| 换武器 | 1 | 次行动 |
| 使用医疗品 | 1-2 | 绷带=1, 急救包=2 |
| 搜索 | 1 | 快速搜索(次行动) |
| 急救他人 | 2 | 主行动 |
| 探头(从全掩体) | 1 | 次行动 |
| 全力防御 | 2 | 主行动, 闪避+15 |
| 闪避（每次被攻击时） | 1 | 反应 |
| 移动（超出免费部分） | 1/2m | 额外移动 |

**AP池**：每轮AP=3+RES/3↓，用尽不可透支。每轮刷新，不保留。

**示例**：RES4 → AP=4。可执行：2AP射击+1AP换弹+留1AP闪避，或2AP投掷+2AP急救队友。

### 4.3 攻防流程

```
攻击方：
  声明目标+部位 → 投d100 ≤ 攻击基准+武器精度+难度+部位修正
  成功 → 进入伤害计算
  失败 → 未命中
  大成功(01-05) → 暴击：伤害×1.5
  大失败(96-00) → 卡壳/误伤/暴露

防御方（受到攻击时）：
  消耗1AP → 投d100 ≤ 闪避值+掩体修正+难度修正
  闪避成功 → 完全免伤
  闪避失败 → 承受伤害
  无闪避机会(偷袭/范围攻击/AP耗尽) → 直接承受

伤害计算：
  伤害 = 子弹伤害骰 + 属性修正 - 目标护甲（最低1）
  属性修正（远程）= AGI/3↓
  属性修正（近战）= STR/3↓
```

**示例**：AGI6突击手用M4A1(5.56mm FMJ)，基础值80，标准难度。投42→命中。子弹伤害1d8=5，AGI修正=6/3=2，总伤=7。目标护甲6→实际伤害=**1点**。若换HP弹(对无甲+3)=5+3+2-6=**4点**。

### 4.4 身体部位瞄准

| 部位 | 命中修正 | 伤害倍率 | 特殊 |
|------|----------|----------|------|
| 头部 | -20 | ×1.8 | 有头盔护甲参与计算 |
| 躯干 | ±0 | ×1.0 | 标准 |
| 手臂 | -10 | ×0.8 | 命中后目标下次攻击-10 |
| 腿部 | -10 | ×0.8 | 命中后速度减半1轮 |

### 4.5 掩体与地形

掩体闪避加成与角色基本闪避值**叠加**。

| 掩体 | 闪避加成 | 限制 |
|------|----------|------|
| 半掩体（车后/矮墙） | +15 | 上半身可被瞄准(头/手臂) |
| 全掩体（墙角/碉堡） | +30 | 无法攻击，需先探头(次行动1AP) |
| 轻掩体（木板/家具） | +10 | 承受10伤害后被摧毁 |
| 高台 | 攻击+5 | 对低位目标 |

### 4.6 多人协作规则

```
协作任务（同一任务多角色参与）：
  选主执行者，辅助者提供加成：
  1人辅助 = +5 | 2人辅助 = +10 | 3人辅助 = +15（上限）

协作战斗：
  掩护射击 → 消耗2AP，指定队友本轮闪避+10
  协同推进 → 两人相邻移动，互不遮挡射界，各获+5移动距离
  协同攻击 → 各自独立攻击同一目标

时序竞争：
  多人声明冲突行动 → 投AGI+RES/2对抗，胜者先执行
  战斗中按先攻顺序
```

### 4.7 压制规则

```
被射击（无论命中与否）→ 立即投 WIL 检定
  WIL成功 → 不受影响，本轮免疫后续压制
  WIL失败 → 被压制：所有检定-15，持续1d3轮
  WIL大失败 → 恐慌：必须立即移动到最近掩体，失去本轮剩余行动
```

### 4.8 伤害类型

| 类型 | 护甲减免比例 | 典型来源 |
|------|------------|----------|
| 物理-弹道 | 100% | FMJ/HP子弹 |
| 物理-切割 | 50% | 刀伤、碎片、鹿弹 |
| 物理-爆炸 | 30% | 手雷、地雷 |
| 物理-穿透 | 0% | AP弹（无视5护甲）|
| 化学 | 0%(需防化装备) | 毒气、酸液 |
| 辐射 | 0%(需防辐射装备) | 异常区域 |
| 电击 | 50% | 电击棒、EMP |
| 纯伤害 | 无法减免 | 坠落、维度撕裂 |

### 4.9 濒死与死亡

```
HP ≤ 0 → 倒地濒死
  每轮投CON检定：
    成功 → 稳定(仍倒地，无法行动)
    失败 → 恶化，HP-2
    HP ≤ -10 → 死亡

队友急救（2AP）：投INT+急救检定
  成功 → 目标HP=1，状态为"重伤"
  大成功 → HP=1d6+1，无重伤

重伤状态：所有检定-10，移速减半，需外科手术或军用医疗包
死亡 → 除安全箱内物品外全部丢失，在基地重生，HP=最大HP×0.7
```

### 6.1 随身携带

负重上限=STR×5+20(kg)。超重惩罚：

| 状态 | 负重% | 惩罚 |
|------|-------|------|
| 正常 | ≤100% | 无 |
| 超重 | 100-120% | 移速减半, AGI-2 |
| 严重超重 | 120-150% | 无法奔跑, AGI-5 |
| 极限 | >150% | 只能缓慢步行, 无法战斗 |

**安全箱**（独立于负重）：
- 基础2格，每格1件物品
- 军械库Lv1→3格，Lv2→4格
- **死亡时安全箱内物品保留**

### 6.2 基地库存

- 基地仓库无限容量，仅在安全区可存取
- 撤离成功→随身物品全部入库
- 共享库存(多人)：标记"共享"的物品队友可见

```

  基础经验：20 XP
  物资加成：每1000信用点带出物资 = +5 XP（上限+50）
  战斗表现：每个击杀 = +2 XP
  探索表现：每个新发现区域 = +5 XP
  隐藏发现：每个 = +10 XP
  特殊成就：
    首次击杀Boss +30 | 全员存活(多人) +20
    速通(3h内) +10 | 无伤撤离 +15
    完全搜刮 +20

死亡/未撤离：
  战斗经验保留50%
  安全箱物品保留，其余丢失
```
