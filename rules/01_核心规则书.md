## 第一章：属性与衍生数值

### 1.1 七大基础属性

角色由7个基础属性定义，初始35点自由分配，每项1-10。

| 属性 | 缩写 | 含义 |
|------|------|------|
| 力量 | STR | 负重、近战伤害修正、后坐力控制 |
| 敏捷 | AGI | 射击精度、闪避、先攻、移动速度 |
| 体质 | CON | 血槽总数、能量池、抗中毒/辐射 |
| 感知 | PER | 搜索、侦察、聆听、威胁察觉 |
| 智力 | INT | 急救、黑客、维修、制作 |
| 意志 | WIL | 恐惧抗性、压制抗性、共鸣失控抗性 |
| 共鸣 | RSN | 异能亲和、能量池加成、异能伤害 |

### 1.2 属性修正（v4新增）

每个属性对应一个**修正值**，用于所有检定。公式：**属性修正 = 属性值 - 5**。范围 -4（属性1）到 +5（属性10）。平均人类（属性5）= 修正0。

### 1.3 衍生数值公式

| 衍生数值 | 公式 | 示例(CON=7,AGI=6,STR=8,RSN=2) |
|----------|------|--------------------------------|
| 血槽总数 | CON × 2 + 4 | 7×2+4 = **18槽** |
| 能量上限 | RSN × 3 | 2×3 = **6能** |
| 闪避加值 | d20 + AGI修正 + PER修正/2↓ | d20+1 |
| 先攻 | d20 + AGI修正 | d20+1 |
| 负重上限 | STR × 5 + 20 kg | 60kg |
| 移动速度 | AGI × 2 m/轮 | 12m/轮 |
| 远程命中 | d20 + AGI修正 + 技能修正 + 武器精度 | 见战斗章 |
| 近战命中 | d20 + STR修正 + 技能修正 | STR修正+3, Lv2: d20+5 |

## 第二章：血槽与伤害

### 2.1 血槽制

这是本作最核心的变化。不再使用传统HP数字，而是**血槽制**：

```
每个角色有 N 个血槽，N = CON × 2 + 4
每个血槽有三种状态：健康(H) → 轻伤(L) → 重伤(S)
关系：H + L + S = N
```

例：CON=5 → 14个血槽，初始全部健康（14H, 0L, 0S）。

### 2.2 两种伤害

**创伤伤害**（常规攻击：射击、斩击、钝击、投掷）：
```
逐点递进，H→L→S
每点先找健康槽→转为轻伤（H-1, L+1）
健康槽耗尽→轻伤槽转为重伤（L-1, S+1）
全部重伤→溢出浪费
```

**重创伤害**（暴击、爆炸、重型武器、精确要害命中）：
```
跳过轻伤，直击重伤
每点：优先健康直转重伤（H-1, S+1）
健康槽耗尽→轻伤转重伤（L-1, S+1）
全部重伤→溢出浪费
```

**计算示例**：14槽角色被击中：
- 受到8点创伤伤害 → 6H+8L+0S（8个H→L）
- 再受10点创伤伤害 → 0H+4L+10S（6个H→L, 4个L→S）
- 再受2点重创伤害 → 0H+2L+12S（2个L→S）
- 再受3点重创伤害 → 0H+0L+14S → 濒死！（2个L→S, 剩下1点溢出）

### 2.3 伤害来源

| 来源 | 类型 | 公式 |
|------|------|------|
| 近战攻击 | 创伤 | 武器伤害骰 + STR修正 - 目标护甲IR（最低1） |
| 远程射击（常规弹） | 创伤 | 武器固伤 + 弹药伤害骰 - 目标护甲IR（最低1） |
| 远程射击（重创弹） | **重创** | 武器固伤 + 重创弹药伤害骰 - 目标护甲CR（最低1） |
| 暴击（自然20） | 同武器/弹药 | 以上公式 + 1d6（保持原伤害类型） |
| 爆炸/环境 | 重创 | 见具体武器 |
| 坠落 | 重创 | 每3m = 1重创伤害（护甲CR减半） |

> **v5变化：所有常规武器均为创伤伤害。重创来源仅限重创弹药（极稀有）、爆炸物、环境/坠落。**

### 2.4 重伤惩罚

注意：**轻伤槽数(L)本身无惩罚**，但L越多越危险——下一次攻击更容易将你拖入重伤。

| 重伤槽(S) | 状态 | 检定修正 | 行动限制 |
|-----------|------|---------|---------|
| S = 0 | 正常 | 无 | 无 |
| S = 1 | 挂彩 | 全检定 -2 | 无 |
| S ≥ 2 | 力竭 | 全检定 -5 | 无法复杂行动（连射/扫射/精密操作/破解） |
| S > N/2 | 昏迷 | 无法检定 | 失去意识，无法行动 |
| S = N | 濒死 | 无法检定 | 倒地。每轮CON检定(DC 12)，连续2次失败→死亡 |

### 2.5 肾上腺素激增（v4新增）

当角色重伤槽首次达到 S ≥ N/2（整场战斗仅1次）：
- 全检定惩罚**临时移除1轮**
- 移动速度翻倍
- 叙事："你突然感觉不到痛了——快跑！"

### 2.6 濒死、拖曳与急救

```
S = N → 角色倒地濒死
每轮结束时 CON 检定 (DC 12)：
  成功 → 稳定，本轮不恶化
  失败 → 恶化标记+1
  连续2次失败 → 死亡

**队友拖曳（v4新增）**：
  标准动作，以半速拖曳濒死角色向撤离点移动
  成功撤离 → 重伤保留但全部装备保留，基地恢复
  全队阵亡 → 装备丢失，重生在基地

队友急救（标准动作, INT修正 + 急救技能 ≥ DC 15）：
  成功 → 1重伤→轻伤（S-1, L+1）；若S<N则恢复意识
  大成功（≥ DC 25）→ 1d3重伤→轻伤
  需求：绷带 或 急救包
```

### 2.6 恢复

| 方式 | 效果 | 动作 |
|------|------|------|
| 绷带 | 1轻伤→健康 | 快速动作 |
| 急救包 | 1d3轻伤→健康 + 1重伤→轻伤（需急救检定） | 标准动作 |
| 军用医疗包 | 2d3轻伤→健康 + 1d2重伤→轻伤（需急救检定） | 标准动作 |
| 止痛针(吗啡) | 2轮内无视重伤惩罚 | 快速动作 |
| 安全区休息(8h) | 1d3重伤→轻伤 + CON/2↓轻伤→健康 | 休息 |

## 第三章：行动系统

### 3.1 每轮动作

每轮（6秒）固定获得：**1标准 + 1快速 + 自由动作**。

不再有AP池的复杂管理——只有"你能做一个重要的事，一个次要的事，和若干不费劲的事"。

| 动作类型 | 数量 | 含义 |
|----------|------|------|
| 标准动作 | 1 | 攻击、使用大型物品、急救他人、精细操作 |
| 快速动作 | 1 | 换弹、切换武器、快速搜索、使用小物品、探头、闪避 |
| 自由动作 | 若干 | 移动(AGI×2m)、对话、丢弃、观察 |

**异能可以额外提供标准或快速动作。**

### 3.2 标准动作详表

| 行动 | 说明 |
|------|------|
| 单发射击 | d20 + AGI修正 + 技能修正 + 武器精度 ≥ DC |
| 连射(2发) | 第2发命中 -3 |
| 扫射(3发) | 每发命中 -5 |
| 火力压制 | 不检定，目标区域内敌人自动触发 WIL 压制检定 |
| 精确瞄准 | 消耗快速动作，命中 +2 |
| 近战攻击 | d20 + STR修正 + 技能修正 ≥ DC |
| 投掷 | 投掷技能检定 |
| 急救他人 | INT修正 + 急救技能 ≥ DC 15 |
| 精细操作 | 开锁、黑客、拆除、修理 |
| 全力防御 | 本轮闪避 +3 |
| **拖曳队友（v4新增）** | 拖曳濒死角色，半速移动 |

### 3.3 快速动作详表

| 行动 | 说明 |
|------|------|
| 换弹匣 | — |
| 切换武器 | — |
| 快速搜索 | 快速搜刮 |
| 使用绷带/打针 | 止血、止痛针、解毒剂等 |
| 探头（全掩体） | 从全掩体后探头，可以攻击 |
| 闪避 | 每次被攻击时可声明。投 d20 + AGI修正 + PER修正/2↓ + 掩体修正。≥ 攻击方命中 → 闪避成功 |
| 快速射击 | 仅手枪/SMG，命中 -2 |

### 3.4 自由动作

移动(AGI×2m/轮)、简短对话、丢弃物品、环顾四周、切换射击模式。

## 第四章：检定系统（v4 D20引擎）

### 4.1 核心公式

```
成功条件：投 d20 + 属性修正 + 技能修正 + 其他修正 ≥ DC

属性修正 = 属性值 - 5（范围 -4 ~ +5）
技能修正 = 技能等级（范围 0 ~ +5）
未受训 = 无技能修正（仅属性修正）
双属性 = (属性A修正 + 属性B修正) / 2↓ + 技能修正
```

**示例1**：AGI=6（修正+1），步枪Lv3（修正+3），M4A1精度+1 → d20 + 1 + 3 + 1 = d20 + 5。标准射击(DC 12) → 需投7+，即70%成功率。

**示例2**：INT=3（修正-2），急救未受训，复合急救(INT-2+PER=修正0)/2↓= -1 → d20 - 1。困难急救(DC 15) → 需投16+，即25%成功率。

### 4.2 七级难度

| 难度 | DC | 场景 |
|------|-----|------|
| 轻松 | 8 | 白天百米认出熟人 |
| 普通 | 10 | 安静室内听到隔壁脚步 |
| 标准 | 12 | 靶场射击、普通房间搜索 |
| 困难 | 15 | 交火中爆头、黄昏远射 |
| 极难 | 18 | 黑暗撬锁、移动中狙击 |
| 噩梦 | 21 | 重伤状态下攀爬、暴风雨中射击 |
| 奇迹 | 24 | 无工具拆弹、千米盲狙 |

### 4.3 特殊骰结果

| 结果 | d20 | 效果 |
|------|-----|------|
| **暴击** | 自然 20 | 自动成功 + 额外 1d6 伤害（保持原伤害类型） |
| **大失败** | 自然 1 | 自动失败 + DM裁定负面后果 |
| **卓越成功** | 超过 DC ≥ 10 | 额外收益或事半功倍 |

### 4.4 对抗检定

双方投 d20 + 各自修正，高者胜。平局→僵持（防御方有利）。

## 第五章：战斗系统

### 5.1 战斗流程

1. **遭遇**：伏击判定（双方侦察对抗），决定先手
2. **先攻**：各角色投 d20 + AGI修正，从高到低
3. **轮循环**：每轮每人 1标准+1快速+自由
4. **结束**：一方全灭/投降→经验+战利品

### 5.2 攻击与闪避

```
攻击方（远程）：
  声明目标 → d20 + AGI修正 + 技能修正 + 武器精度
  目标被动防御 = 10 + 目标AGI修正 + 掩体修正
  未察觉目标：不计AGI修正（DC = 8 + 掩体）

攻击方（近战）：
  d20 + STR修正 + 技能修正
  目标被动防御 = 10 + 目标AGI修正

防御方（被攻击时可声明闪避）：
  消耗快速动作 → d20 + AGI修正 + PER修正/2↓ + 掩体修正
  闪避投值 ≥ 攻击方投值 → 完全免伤
  闪避失败/无快速动作可用 → 按被动防御判定命中
```

### 5.3 部位瞄准

| 部位 | 命中修正 | 伤害倍率 | 特殊 |
|------|----------|----------|------|
| 头部 | -8 | ×2 | 有头盔则护甲IR参与计算 |
| 躯干 | ±0 | ×1 | 标准 |
| 手臂 | -2 | ×0.5 | 暴击时目标掉落手持物 |
| 腿部 | -2 | ×0.5 | 暴击时目标移速减半1轮 |

### 5.4 掩体（与闪避叠加）

| 掩体类型 | 闪避加值 | 限制 |
|----------|----------|------|
| 半掩体 | +2 | 上半身仍可被瞄准 |
| 全掩体 | +5 | 无法攻击，需先探头（快速动作） |
| 轻掩体 | +1 | 承受10点伤害后被摧毁 |
| 高台 | 攻击+1 | 对低位目标 |

### 5.5 压制规则

```
被射击后（无论命中与否）→ WIL检定 DC 12 + 射击者数量：
  成功 → 不受影响，本轮免疫后续压制
  失败 → 被压制：全检定-2，持续1d3轮
  大失败 → 恐慌：立即移动到最近掩体，失去本轮剩余动作
```

### 5.6 多人协作

```
协作任务：1辅助+1，2辅助+2，3辅助+3（上限）
掩护射击：消耗标准动作，指定队友本轮闪避+2
协同推进：两人相邻移动时不遮挡射界
```

## 第六章：异能系统

### 6.1 核心概念

灰区的维度交汇产生了异常能量场。部分回收者体内积累了"共鸣"——一种与异常能量产生互动的生理禀赋。这不是魔法，而是现代物理学尚未完全解释的客观现象。

共鸣值(RSN)代表角色对异常能量的亲和度。异能按性质分为**五大体系**。每个角色在创建时选择一个主修体系，随着收集结晶进行突破进阶。

**异能不设冷却**——仅消耗能量。能量池耗尽则无法使用。这迫使你在战斗中合理分配能量，而不是等冷却转好。

### 6.2 能量池（v4更新）

```
能量上限 = RSN × 3
能量恢复 = RSN/3↓ + 1（每轮专注/休息）
全恢复 = 1小时安全休息
```

| RSN | 能量上限 | 每轮恢复 |
|-----|---------|---------|
| 2 | 6 | 1 |
| 5 | 15 | 2 |
| 8 | 24 | 3 |
| 10 | 30 | 4 |

### 6.3 核心机制（v4更新）

- **每人最多2个体系**：初始创建时选1个主修，获得该体系T0·觉醒。
- **子系消耗XP**：解锁新子系30XP，Lv1→2=40XP，Lv2→3=60XP。上限由体系Tier决定。
- **连续使用惩罚（v5更新）**：同一主动异能连续每2次后能耗+1（停用该技能3轮重置）。**全场计数器**：累计任意主动异能每4次后全局能耗+1（不因切换/停用降低，战斗结束重置）。
- **共鸣攀升（v5更新）**：每次使用主动异能后 RSN临时+1（战斗结束后清除）。临时RSN影响失控风险。
- **无冷却，仅耗能+连续惩罚限制**。
- **晶体解锁第二体系**：B级异常结晶×3，CON+RSN ≥ DC 18（极难）。
- **濒死觉醒（v4更新）**：**任何区域**濒死(S=N)均可尝试觉醒新体系T0。CON+RSN ≥ DC 15。成功=觉醒+恢复意识，失败=加速死亡。

### 6.4 五大体系概览

| 体系 | 核心主题 | 适合角色 |
|------|---------|---------|
| 身体强化系 | 近战·肉搏·生存 | 近战型回收者、前线突入者 |
| 元素共鸣系 | 远程能量·AOE·破坏 | 远程火力型、异能攻击型 |
| 感知扩张系 | 信息·探测·预警 | 侦察型、团队信息核心 |
| 空间干涉系 | 机动·闪避·位移 | 高机动型、生存型 |
| 精神支配系 | 团队·控制·交涉 | 团队辅助、社交核心 |

**体系互斥**：选择主修体系后，其他体系的技能无法解锁。极少数情况下，DM可根据剧情、NPC训练或异常事件允许跨体系学习——但这是例外，不是规则。

### 6.4 进阶与突破

异能不能仅靠练习成长——必须在灰区中收集异常结晶，用结晶的能量来突破生理瓶颈。

| 阶位 | 结晶需求 | 突破DC | 失败后果 |
|------|---------|---------|---------|
| T0→T1 | C级异常结晶×3 | DC 12（标准） | 结晶损失 |
| T1→T2 | B级异常结晶×2 | DC 15（困难） | 损失+RSN临时-1 |
| T2→T3 | A级异常结晶×1 | DC 18（极难） | 损失+RSN永久-1+1d4重伤 |

**进阶意味着更多能力+能耗降低**。T3的异能使用者面对T0使用者具有明显的资源优势——但在灰区里，一颗子弹永远能让任何异能者倒地。

### 6.5 身体强化系

近战与肉体极限的突破。适合贴身战斗和承受伤害的角色。

- **T0·觉醒**: 硬化皮肤(物理减免+1)、加速代谢(2能,恢复血槽)
- **T1·引导**: +残影步(移速+2m)、+能量过载(3能,近战+1d6)
- **T2·掌控**: T1技能强化+T2级数值
- **T3·巅峰**: 能量过载→**3d6重创伤害**, 快速愈合(战后自动恢复)

### 6.6 元素共鸣系

将异常能量转化为直接破坏力。适合远程能量攻击角色。

- **T0·觉醒**: 共振护盾(共鸣伤害减免+2)、共振冲击(3能,锥形创伤+击退)
- **T3·巅峰**: +**维度爆裂**: 4能, 20m范围3d8+RSN重创伤害

### 6.7 感知扩张系

信息不对称就是战斗力。适合侦察和情报角色。

- **T0·觉醒**: 鹰眼(侦察+10)、脉冲探测(2能,生命感知30m)
- **T3·巅峰**: +精神威压(2能,眩晕+压制)
- **独有**: 危机预感——每场战斗首次被偷袭自动闪避

### 6.8 空间干涉系

对灰区空间扭曲的主动利用。适合高机动和生存角色。

### 6.9 精神支配系

对意志力的外化——影响他人、凝聚队友。

### 6.10 共鸣失控风险 v5

当 **RSN > WIL** 时（含临时攀升）：

| 差值 | 效果 |
|------|------|
| 0 | 安全 |
| 1~2 | 轻度：PER/INT-1，偶尔感知偏差 |
| 3~4 | 中度：PER/INT-3，频繁幻觉，可能误判目标 |
| ≥5 | 重度：每次用主动异能需WIL(DC15)，失败→失控（随机目标/效果反转/自伤1d6） |

> **v5变化：WIL门槛全面提高。** RSN=5需要WIL=5才能保安全（需投入10属性点）。RSN=8需要WIL=8（14点）——高共鸣异能者必须在意志力上做出牺牲。

## 第八章：装备系统 v5

### 8.1 核心原则

**弹药决定伤害维度。武器提供命中框架与改装潜力。**

- 远程伤害 = 武器固伤 + 弹药伤害骰 - 目标护甲IR（最低1）
- 近战伤害 = 武器伤害骰 + STR修正 - 目标护甲IR（最低1）
- 暴击（自然20）→ 额外 +1d6 伤害，保持原伤害类型
- **重创仅来自重创弹药、爆炸、环境**——常规武器一律创伤

### 8.2 弹药体系 v5

弹药是远程伤害的决定性因素。口径决定基础伤害骰，弹种提供修正。

| 口径 | 基础伤害骰 | 兼容武器类型 |
|------|-----------|------------|
| 9mm | 1d6 | 手枪、SMG |
| 5.56mm | 1d8 | 突击步枪、LMG |
| 7.62mm | 1d10 | 步枪(战斗/DMR/狙击)、通用机枪 |
| 12号(鹿弹) | 2d4(近0-15m)/1d4(远15-30m) | 霰弹枪 |
| 12号(独头) | 1d10 | 霰弹枪 |
| .44 | 1d8 | 重型手枪 |

弹种修正：
- **FMJ**：基准。
- **HP空尖弹**：vs无甲+1伤害，vs有甲-1伤害，流血概率+20%。
- **AP穿甲弹**：伤害-1，无视2护甲IR。
- **亚音速**：伤害-1，噪音-2级。

**重创弹药 v5新增**：

| 口径 | 伤害骰 | 类型 | 稀有度 |
|------|--------|------|--------|
| 9mm 重创弹 | 1d4 | 重创 | T4 |
| 5.56mm 重创弹 | 1d6 | 重创 | T4 |
| 7.62mm 重创弹 | 1d8 | 重创 | T4 |
| 12号 重创独头 | 1d8 | 重创 | T4 |
| .44 重创弹 | 1d6 | 重创 | T4 |

> 重创弹药极为稀有。工坊Lv2可用异常结晶碎片制作。它不改变武器——只改变击中的结果。

### 8.3 武器体系 v5

武器按**类型**分类，不按具体型号。用**改装**区分个性。

**近战武器三档**：轻型(1d4) / 标准(1d6) / 重型(1d8)。可选特质：锋利、沉重、破甲、轻巧、电击、链锯、相位镀层、共鸣蚀刻。

**远程武器六类**：手枪 / SMG / 步枪(AR+DMR+栓狙合并) / 霰弹枪 / 重型武器(LMG+反器材)。

**改装槽**：每把武器有瞄具/枪口/握把/弹匣/脚架槽位。高级瞄具可跨枪使用（卸下1快速+装上1标准）。

### 8.4 M4平台独特改装 v5新增

M4（模块化步枪平台）可通过工坊改装切换配置：
- 上机匣更换·DMR/CQB（固伤/精度互换）
- 枪管更换·长管/短管（伤害vs便携）
- 双通道供弹（预装两种弹药，自由动作切换）
- 轻量化骨架（减重）
- 异常谐振套件（附加共鸣创伤）

> 完整改装参数见数值配置表。M4改装不需要检定——支付材料和灰币即可。

### 8.5 护甲（v5 IR/CR双维制）

护甲分为**冲击减免（IR，抗创伤）**和**重创减免（CR，抗重创）**。

| 防具 | IR | CR | 部位 | 惩罚 |
|------|-----|-----|------|------|
| 轻便背心 | 1 | 0 | 躯干 | 无 |
| 警用防弹衣 | 2 | 0 | 躯干 | 无 |
| 标准战术背心 | 3 | 0 | 躯干 | AGI-1 |
| 重型突入甲 | 4 | 1 | 躯干 | AGI-2 |
| 异常镀层甲 | 3 | 2 | 躯干 | 无 (T4) |
| 军用头盔 | 2 | 0 | 头部 | 无 |
| 全罩头盔 | 3 | 1 | 头部+面部 | PER-1 |

护甲劣化：取消。护甲在战斗中不会因承受伤害而衰减——战后修复是叙事节拍，不是机械追踪。

## 第九章：存储与经济

### 9.1 随身携带

负重上限 = STR × 5 + 20 (kg)。超重惩罚：
- 100-120%：移速减半，AGI-2
- 120-150%：无法奔跑，AGI-5
- \>150%：只能缓慢步行，无法战斗

安全箱（独立于负重）：基础2格，可扩展至4格。**死亡时仅安全箱内物品保留。**

### 9.2 基地

基地仓库无限容量，仅安全区可存取。撤离成功→随身物品全部入库。死亡→仅安全箱保留，其余全部丢失。

### 9.3 货币

信用点(Credits)。通过卖出贵重品、完成任务获取。常见品20-50买入/5-15卖出，稀有品500-1500买入/150-400卖出。
