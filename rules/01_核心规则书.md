## 第一章：属性与衍生数值

### 1.1 七大基础属性

角色由7个基础属性定义，初始35点自由分配，每项1-10。

| 属性 | 缩写 | 含义 |
|------|------|------|
| 力量 | STR | 负重、近战伤害修正、后坐力控制 |
| 敏捷 | AGI | 射击精度、闪避、先攻、移动速度 |
| 体质 | CON | 血槽总数、能量池、抗中毒/辐射 |
| 感知 | PER | 搜索、侦察、聆听、威胁察觉 |
| 智力 | INT | 急救、黑客、维修、制作 |
| 意志 | WIL | 恐惧抗性、压制抗性、共鸣失控抗性 |
| 共鸣 | RSN | 异能亲和、能量池加成、异能伤害 |

### 1.2 衍生数值公式

| 衍生数值 | 公式 | 示例(CON=5,RSN=3,AGI=6,STR=5) |
|----------|------|--------------------------------|
| 血槽总数 | CON × 2 + 4 | 5×2+4 = **14槽** |
| 能量上限 | CON + RSN × 2 | 5+3×2 = **11能** |
| 闪避值 | AGI + PER/2 ↓ | 6+3=**9** |
| 先攻 | AGI + 1d10 | 6+1d10 |
| 负重上限 | STR × 5 + 20 kg | 45kg |
| 移动速度 | AGI × 2 m/轮 | 12m/轮 |
| 远程命中基准 | AGI×10 + 技能×5 + 武器精度 | 见战斗章 |
| 近战命中基准 | STR×10 + 近战技能×5 | STR=5, Lv3: 50+15=**65** |

## 第二章：血槽与伤害

### 2.1 血槽制

这是本作最核心的变化。不再使用传统HP数字，而是**血槽制**：

```
每个角色有 N 个血槽，N = CON × 2 + 4
每个血槽有三种状态：健康(H) → 轻伤(L) → 重伤(S)
关系：H + L + S = N
```

例：CON=5 → 14个血槽，初始全部健康（14H, 0L, 0S）。

### 2.2 两种伤害

**创伤伤害**（常规攻击：射击、斩击、钝击、投掷）：
```
逐点递进，H→L→S
每点先找健康槽→转为轻伤（H-1, L+1）
健康槽耗尽→轻伤槽转为重伤（L-1, S+1）
全部重伤→溢出浪费
```

**重创伤害**（暴击、爆炸、重型武器、精确要害命中）：
```
跳过轻伤，直击重伤
每点：优先健康直转重伤（H-1, S+1）
健康槽耗尽→轻伤转重伤（L-1, S+1）
全部重伤→溢出浪费
```

**计算示例**：14槽角色被击中：
- 受到8点创伤伤害 → 6H+8L+0S（8个H→L）
- 再受10点创伤伤害 → 0H+4L+10S（6个H→L, 4个L→S）
- 再受2点重创伤害 → 0H+2L+12S（2个L→S）
- 再受3点重创伤害 → 0H+0L+14S → 濒死！（2个L→S, 剩下1点溢出）

### 2.3 伤害来源

| 来源 | 类型 | 公式 |
|------|------|------|
| 近战攻击 | 创伤 | 武器伤害骰 + STR/3↓ - 护甲（最低1） |
| 远程射击 | 创伤 | 武器固伤 + 弹药伤害骰 - 护甲（最低1） |
| 暴击（大成功） | **重创** | 以上公式 ×1.5 |
| 爆炸/重型 | **重创** | 见具体武器 |
| 环境/坠落 | **重创** | 坠落: 每3m=1重创伤害 |

### 2.4 重伤惩罚

注意：**轻伤槽数(L)本身无惩罚**，但L越多越危险——下一次攻击更容易将你拖入重伤。

| 重伤槽(S) | 状态 | 惩罚 |
|-----------|------|------|
| S = 0 | 正常 | 无 |
| S = 1 | 挂彩 | 全检定 -5 |
| S ≥ 2 | 力竭 | 全检定 -20，无法执行复杂行动（连射/扫射/精密操作/破解） |
| S > N/2 | 昏迷 | 失去意识，无法行动 |
| S = N | 濒死 | 倒地。每轮CON检定(标准)，连续2次失败→死亡 |

### 2.5 濒死与急救

```
S = N → 角色倒地濒死
每轮结束时CON检定（标准难度±0）：
  成功 → 稳定，本轮不恶化
  失败 → 恶化标记+1
  连续2次失败 → 死亡

队友急救（标准动作，INT + 急救技能）：
  成功 → 1重伤→轻伤（S-1, L+1）；若S<N则恢复意识
  大成功 → 1d3重伤→轻伤
  需求：绷带 或 急救包
```

### 2.6 恢复

| 方式 | 效果 | 动作 |
|------|------|------|
| 绷带 | 1轻伤→健康 | 快速动作 |
| 急救包 | 1d3轻伤→健康 + 1重伤→轻伤（需急救检定） | 标准动作 |
| 军用医疗包 | 2d3轻伤→健康 + 1d2重伤→轻伤（需急救检定） | 标准动作 |
| 止痛针(吗啡) | 2轮内无视重伤惩罚 | 快速动作 |
| 安全区休息(8h) | 1d3重伤→轻伤 + CON/2↓轻伤→健康 | 休息 |

## 第三章：行动系统

### 3.1 每轮动作

每轮（6秒）固定获得：**1标准 + 1快速 + 自由动作**。

不再有AP池的复杂管理——只有"你能做一个重要的事，一个次要的事，和若干不费劲的事"。

| 动作类型 | 数量 | 含义 |
|----------|------|------|
| 标准动作 | 1 | 攻击、使用大型物品、急救他人、精细操作 |
| 快速动作 | 1 | 换弹、切换武器、快速搜索、使用小物品、探头、闪避 |
| 自由动作 | 若干 | 移动(AGI×2m)、对话、丢弃、观察 |

**异能可以额外提供标准或快速动作。**

### 3.2 标准动作详表

| 行动 | 说明 |
|------|------|
| 单发射击 | 命中按远程基准 |
| 连射(2发) | 第2发命中-10 |
| 扫射(3发) | 每发命中-15 |
| 火力压制 | 不检定，目标区域内敌人自动触发压制判定 |
| 精确瞄准 | 叠加于射击，命中+5，需消耗本轮的快速动作 |
| 近战攻击 | 命中按近战基准 |
| 投掷 | 投掷技能检定 |
| 使用大型医疗品 | 急救包、军用医疗包 |
| 急救他人 | INT + 急救技能检定 |
| 精细操作 | 开锁、黑客、拆除、修理 |
| 全力防御 | 本轮闪避+15 |

### 3.3 快速动作详表

| 行动 | 说明 |
|------|------|
| 换弹匣 | — |
| 切换武器 | — |
| 快速搜索 | 快速搜刮 |
| 使用绷带/打针 | 止血、止痛针、解毒剂等 |
| 探头（全掩体） | 从全掩体后探头，可以攻击 |
| 闪避 | 每次被攻击时可用。投d100 ≤ 闪避值+掩体修正，成功则完全免伤 |
| 快速射击 | 仅手枪/SMG，命中-10 |

### 3.4 自由动作

移动(AGI×2m/轮)、简短对话、丢弃物品、环顾四周、切换射击模式。

## 第四章：检定系统

### 4.1 d100目标数判定

```
成功条件：投 1d100 ≤ 基础值 + 难度修正
基础值 = 关联属性 × 10 + 技能等级 × 5
未受训 = 关联属性 × 5（复合属性取(A+B)×2.5↓）
```

**示例1**：AGI=6，步枪技能Lv3，M4A1精度+5 → 基础值 = 60+15+5=80。标准射击(±0) → 需投≤80。

**示例2**：INT=4，急救未受训，复合急救(INT+PER未受训=(4+5)×2.5=22)。困难难度(-15) → 需投≤7。几乎不可能。

### 4.2 七级难度

| 难度 | 修正 | 场景 |
|------|------|------|
| 轻松 | +40 | 白天百米认出熟人 |
| 普通 | +20 | 安静室内听到隔壁脚步 |
| 标准 | ±0 | 靶场射击、普通房间搜索 |
| 困难 | -15 | 交火中爆头、黄昏远射 |
| 极难 | -30 | 黑暗撬锁、移动中狙击 |
| 噩梦 | -45 | 重伤状态下攀爬、暴风雨中射击 |
| 奇迹 | -60 | 无工具拆弹、千米盲狙 |

### 4.3 特殊骰结果

| 结果 | 范围 | 效果 |
|------|------|------|
| 大成功 | 01-05 | 最佳效果。战斗中转为**重创伤害**，伤害×1.5 |
| 大失败 | 96-00（基础>100→99-00） | 灾难性后果 |
| 临界成功 | = 基础值 | 成功但有代价/瑕疵 |

### 4.4 对抗检定

双方投d100，比较"基础值-投出值"（成功余量），余量大者胜。双方都失败→僵持。

## 第五章：战斗系统

### 5.1 战斗流程

1. **遭遇**：伏击判定（双方侦察对抗），决定先手
2. **先攻**：各角色投 AGI + 1d10，从高到低
3. **轮循环**：每轮每人 1标准+1快速+自由
4. **结束**：一方全灭/投降→经验+战利品

### 5.2 攻击与闪避

```
攻击方：
  声明目标 → 投d100 ≤ 远程/近战基准 + 难度修正 ± 部位修正
  成功 → 计算伤害
  大成功 → 重创伤害 ×1.5

防御方（被攻击时可用闪避）：
  消耗快速动作 → 投d100 ≤ 闪避值 + 掩体修正
  闪避成功 → 完全免伤
  闪避失败/无快速动作可用 → 承受伤害
```

### 5.3 部位瞄准

| 部位 | 命中修正 | 伤害倍率 | 特殊 |
|------|----------|----------|------|
| 头部 | -20 | ×1.8 | 有头盔则护甲参与计算 |
| 躯干 | ±0 | ×1.0 | 标准 |
| 手臂 | -10 | ×0.8 | 命中后目标下次攻击-10 |
| 腿部 | -10 | ×0.8 | 命中后目标移速减半1轮 |

### 5.4 掩体（与闪避值叠加）

| 掩体类型 | 闪避加成 | 限制 |
|----------|----------|------|
| 半掩体 | +15 | 上半身仍可被瞄准 |
| 全掩体 | +30 | 无法攻击，需先探头（快速动作） |
| 轻掩体 | +10 | 承受10点伤害后被摧毁 |
| 高台 | 攻击+5 | 对低位目标 |

### 5.5 压制规则

```
被射击后（无论命中与否）→ 投WIL检定：
  成功 → 不受影响，本轮免疫后续压制
  失败 → 被压制：全检定-15，持续1d3轮
  大失败 → 恐慌：立即移动到最近掩体，失去本轮剩余动作
```

### 5.6 多人协作

```
协作任务：1辅助+5，2辅助+10，3辅助+15（上限）
掩护射击：消耗标准动作，指定队友本轮闪避+10
协同推进：两人相邻移动时不遮挡射界，各获+5移动距离
```

## 第六章：异能系统

### 6.1 核心概念

灰区的维度交汇产生了异常能量场。部分回收者体内积累了"共鸣"——一种与异常能量产生互动的生理禀赋。这不是魔法，而是现代物理学尚未完全解释的客观现象。

共鸣值(RSN)代表角色对异常能量的亲和度。异能按性质分为**五大体系**。每个角色在创建时选择一个主修体系，随着收集结晶进行突破进阶。

**异能不设冷却**——仅消耗能量。能量池耗尽则无法使用。这迫使你在战斗中合理分配能量，而不是等冷却转好。

### 6.2 能量池

```
能量上限 = CON + RSN × 2
能量恢复 = RSN/3↓ + 1（每轮专注/休息）
全恢复 = 1小时安全休息
```

### 6.3 核心机制

- **每人最多2个体系**：初始创建时选1个主修，获得该体系T0·觉醒（被动+主动各1个子系Lv1）。
- **子系树状成长**：每个体系下分若干子系（如元素共鸣系→冲击/火/冰/电/爆裂）。每个子系是独立Lv1~3的技能树。
- **子系消耗XP**：解锁新子系、升级已有子系消耗经验值。上限由体系Tier决定（T0→Lv1，T1→Lv2，T2→Lv3）。
- **晶体解锁第二体系**：B级异常结晶×3，揉碎涂抹于身体，沉睡8小时。CON+RSN检定(困难-15)，约1/3成功率。
- **濒死觉醒**：血槽全重伤+Zone3+深层灰区→消耗一整轮(标准+快速)尝试觉醒任意体系T0。高风险：成功=觉醒+恢复意识，失败=加速死亡。
- **无冷却，仅耗能**。

### 6.4 五大体系概览

| 体系 | 核心主题 | 适合角色 |
|------|---------|---------|
| 身体强化系 | 近战·肉搏·生存 | 近战型回收者、前线突入者 |
| 元素共鸣系 | 远程能量·AOE·破坏 | 远程火力型、异能攻击型 |
| 感知扩张系 | 信息·探测·预警 | 侦察型、团队信息核心 |
| 空间干涉系 | 机动·闪避·位移 | 高机动型、生存型 |
| 精神支配系 | 团队·控制·交涉 | 团队辅助、社交核心 |

**体系互斥**：选择主修体系后，其他体系的技能无法解锁。极少数情况下，DM可根据剧情、NPC训练或异常事件允许跨体系学习——但这是例外，不是规则。

### 6.4 进阶与突破

异能不能仅靠练习成长——必须在灰区中收集异常结晶，用结晶的能量来突破生理瓶颈。

| 阶位 | 结晶需求 | 突破检定 | 失败后果 |
|------|---------|---------|---------|
| T0→T1 | C级异常结晶×3 | 制作(标准±0) | 结晶损失 |
| T1→T2 | B级异常结晶×2 | 制作(困难-15) | 结晶损失+RSN临时-1(下休息恢复) |
| T2→T3 | A级异常结晶×1 | 制作(极难-30) | 结晶损失+RSN永久-1+1d4重伤 |

**进阶意味着更多能力+能耗降低**。T3的异能使用者面对T0使用者具有明显的资源优势——但在灰区里，一颗子弹永远能让任何异能者倒地。

### 6.5 身体强化系

近战与肉体极限的突破。适合贴身战斗和承受伤害的角色。

- **T0·觉醒**: 硬化皮肤(物理减免+1)、加速代谢(2能,恢复血槽)
- **T1·引导**: +残影步(移速+2m)、+能量过载(3能,近战+1d6)
- **T2·掌控**: T1技能强化+T2级数值
- **T3·巅峰**: 能量过载→**3d6重创伤害**, 快速愈合(战后自动恢复)

### 6.6 元素共鸣系

将异常能量转化为直接破坏力。适合远程能量攻击角色。

- **T0·觉醒**: 共振护盾(共鸣伤害减免+2)、共振冲击(3能,锥形创伤+击退)
- **T3·巅峰**: +**维度爆裂**: 4能, 20m范围3d8+RSN重创伤害

### 6.7 感知扩张系

信息不对称就是战斗力。适合侦察和情报角色。

- **T0·觉醒**: 鹰眼(侦察+10)、脉冲探测(2能,生命感知30m)
- **T3·巅峰**: +精神威压(2能,眩晕+压制)
- **独有**: 危机预感——每场战斗首次被偷袭自动闪避

### 6.8 空间干涉系

对灰区空间扭曲的主动利用。适合高机动和生存角色。

- **T0·觉醒**: 空间感知(伏击察觉+5)、空间折叠(4能,15m瞬移)
- **T3·巅峰**: +裂隙步(3能,制造临时空间裂隙供全队穿过)

### 6.9 精神支配系

对意志力的外化——影响他人、凝聚队友。

- **T0·觉醒**: 钢铁神经(压制抗性+20)、意志共鸣(4能,全队命中+10)
- **T3·巅峰**: +恐惧光环(3能,范围压制敌人)

### 6.10 共鸣失控风险

当 **RSN > WIL** 时：

| 差值 | 效果 |
|------|------|
| 0~1 | 安全 |
| 2~3 | 高压环境中可能幻觉/感知偏差 |
| 4~5 | 全INT/PER检定-10，战斗中可能误判 |
| ≥6 | 每次用主动异能需投WIL(困难)，失败→失控（随机目标/效果反转） |

## 第七章：技能与专长

### 7.1 技能系统（20项）

保留了完整的技能体系，与异能并行。

**战斗技能**：步枪/冲锋枪(AGI)、手枪(AGI)、霰弹枪(AGI)、精准射击(AGI+PER)、重型武器(STR)、近战武器(STR)、投掷(AGI)

**生存技能**：潜行(AGI)、侦察(PER)、追踪(PER)、急救(INT)、野外生存(CON+PER)

**技术技能**：开锁(INT+AGI)、维修(INT)、电子设备(INT)、制作(INT)

**社交技能**：交涉(WIL)、威吓(STR+WIL)、欺骗(WIL)、情报收集(PER+INT)

### 7.2 技能等级

| 等级 | 名称 | 基础值 | 花费 |
|------|------|--------|------|
| 0 | 未受训 | 属性×5 / 复合(A+B)×2.5↓ | — |
| 1 | 入门 | +5 | 1点 |
| 2 | 熟练 | +10 | 2点 |
| 3 | 专精 | +15 | 3点 |
| 4 | 大师 | +20 | 5点 |
| 5 | 传说 | +25 | 8点 |

初始技能点：30点。

### 7.3 专长系统（11项）

## 第八章：装备系统

### 8.1 核心原则

**弹药决定伤害。武器提供固伤和命中框架。两者独立。**

- 远程伤害 = 武器固伤 + 弹药伤害骰 - 目标护甲（最低1）
- 近战伤害 = 武器伤害骰 + STR/3↓ - 目标护甲（最低1）
- 所有常规伤害为创伤伤害
- 暴击(大成功) → 伤害×1.5，且转为**重创伤害**

射击不细化——武器自身有固定伤害值（固伤），弹药提供伤害骰，两者相加即最终伤害。

### 8.2 弹药体系

弹药是远程伤害的决定性因素。口径决定基础伤害骰，弹种提供修正和特效。

| 口径 | 基础伤害骰 | 兼容武器类型 |
|------|-----------|------------|
| 9mm | 1d6 | 手枪、SMG |
| 5.56mm | 1d8 | 突击步枪、LMG |
| 7.62mm | 1d10 | DMR、狙击、通用机枪 |
| 12号(鹿弹) | 2d6(近0-15m)/1d4(远15-30m) | 霰弹枪 |
| 12号(独头) | 1d10+2 | 霰弹枪 |
| .44 | 1d8 | 重型手枪、杠杆步枪 |

弹种修正：
- **FMJ**：基准。
- **HP空尖弹**：vs无甲+3伤害，vs有甲-2伤害，流血概率+20%。
- **AP穿甲弹**：伤害-1，无视5点护甲。
- **亚音速**：伤害-2，噪音-2级。

### 8.3 武器体系

武器分**远程**和**近战**两大类。远程武器的核心参数是固伤和精度；近战武器的核心参数是伤害骰和特效。

远程武器按固伤档次大致分为：手枪(固伤1~3)、SMG(1~2)、突击步枪(3~4)、DMR(4~5)、栓狙(5~7)、霰弹枪(3)、LMG(3~4)。

**完整武器数据见 `rules/数值配置表.md` 第九章。物品掉落、稀有度、价格见 `assets/items/物品与掉落表.md`。**

### 8.4 近战武器与强化

近战武器是异能体系的物理搭档。它们有自己的阶梯——从随手捡的钢管到异常结晶镀层的传说刃具。

近战武器分三等：**轻型**(1d4)、**标准**(1d6)、**重型**(1d8~2d6)。重型武器的暴击或某些特殊武器（链锯）的普通攻击即为重创伤害。

近战武器可通过基地工坊进行改造强化：
- **加重配重**：伤害骰+1，重量+1kg。工坊Lv1即可。
- **锯齿刃**：命中后附加流血（目标每轮健康→轻伤），需要急救检定(困难)止血。
- **减震握把**：命中+5。
- **异常结晶镀层**（工坊Lv3+异常结晶碎片）：武器额外附带RSN/3↓的共鸣创伤伤害，对镜界生物伤害×1.5。

完整的近战武器清单、稀有版本和改造配方见 `assets/items/物品与掉落表.md`。

## 第九章：存储与经济

### 9.1 随身携带

负重上限 = STR × 5 + 20 (kg)。超重惩罚：
- 100-120%：移速减半，AGI-2
- 120-150%：无法奔跑，AGI-5
- \>150%：只能缓慢步行，无法战斗

安全箱（独立于负重）：基础2格，可扩展至4格。**死亡时仅安全箱内物品保留。**

### 9.2 基地

基地仓库无限容量，仅安全区可存取。撤离成功→随身物品全部入库。死亡→仅安全箱保留，其余全部丢失。

### 9.3 货币

信用点(Credits)。通过卖出贵重品、完成任务获取。常见品20-50买入/5-15卖出，稀有品500-1500买入/150-400卖出。

### 10.2 XP：经验就是你的成长货币

XP不只是等级进度条——它是你可以主动消耗的资源。在围栏镇或安全的修整点，你可以把XP花在以下方面：

| 消耗项 | XP花费 |
|--------|--------|
| 解锁已有体系内的新子系Lv1 | 30 XP |
