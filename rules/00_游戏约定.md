# 游戏约定：《灰区：撤离》v5

> 本文件不是规则——是约定。它定义了这是一个什么样的游戏、谁有什么权利、DM可以怎样裁决。
> 所有玩家（包括DM）应在开始前阅读本章。

---

## 一、这是一个什么游戏

《灰区：撤离》是一款 AI DM 驱动的 TRPG。它的核心体验不是"配Build→打怪→掉装备"，而是：

> **你扮演一个走投无路的亡命之徒，在异常封锁区里签了卖命合同。你做出选择。世界回应你。你不知道下一次进入灰区还能不能活着出来。但你知道——就算活着出来，你赚的灰币在外面几乎等于废纸。你只能回来。**

这个游戏建立在三个支柱上：
- **风险与决策**：绿区→黄区→橙区→红区→黑区。越深入回报越丰厚，代价越致命。**你自由选择去不去。**
- **选择与后果**：没有预设的"正确"路径。你的盟友、敌人、债务和承诺都在动态变化。
- **即兴与涌现**：最有趣的故事往往在规则书上没有——是DM和玩家一起发现的。

## 二、规则的本质

**规则是框架，不是牢笼。**

规则书告诉你：什么事情可以尝试，为什么可以，大概有多难。它不应该告诉你"你只能做这些"。

核心规则书和数值配置表提供的是**已知可靠的操作方式**——比如射击的计算公式、异能的能量消耗。但真正的游戏乐趣往往来自规则边缘：

- "我能把异常结晶碎片磨成粉，混进子弹弹头里吗？"
- "我能不能用相位偏移穿越那堵看起来不太对的墙？"
- "工坊里有没有可能用捡来的零件组装一个简易EMP？"

**这些不是破坏规则——这正是这个游戏存在的原因。**

DM的职责不是拒绝这些尝试，而是判断可行性，设定难度和代价，然后让骰子决定。

## 三、玩家权利与边界

### 你拥有的权利
- **你的角色你决定**。DM不能替你决定你角色的行动、想法或信念。
- **你的行动你来声明**。DM只能裁定声明的结果，不能修改你声明的内容。
- **你可以质疑裁决**。如果你觉得DM的裁定不合理，可以提出。如果无法达成共识，DM的裁定暂时有效——记入裁决记录，后续可以讨论。
- **你可以推动故事**。你不是在等待DM喂剧情。你可以主动提出方向："我想去查那个无线电信号的来源。"

### 你的边界
- **不替其他玩家做决定**。你可以建议、可以提供信息，但不能替别人声明行动。
- **不滥用信息**。你的角色不知道的事情，你不应该用它们来做决策。如果你不确定某条信息你的角色是否知道，问DM。
- **不破坏他人体验**。包括：不故意破坏团队目标、不在别人探索时抢跑、不在非冲突情况下对其他玩家角色动手。
- **尊重DM的隐藏信息**。DM的速记文件、故事文件、暗骰结果——这些不该被翻阅。

## 四、DM裁决原则

### 核心原则：可以什么，为什么可以

当玩家提出规则书未覆盖的行动时，DM按以下流程裁决：

```
1. 可行性判断
   - 在灰区的物理法则下，这件事可能吗？
   - 参考灰区异常三定律（见第七节）
   - 如果物理上可能 → 进入2
   - 如果不可能 → 解释为什么，但暗示可行方向

2. 难度设定
   - 这需要什么技能？什么属性？
   - 有工具/材料/有利条件吗？
   - 设定难度等级（轻松+40 ~ 奇迹-60）

3. 消耗与代价
   - 需要消耗什么？（能量/材料/时间/信用点）
   - 失败有什么后果？
   - 成功有额外收益吗？

4. 执行
   - 投骰 → 判定结果 → 给出叙事反馈
   - 成功：清楚描述发生了什么
   - 失败：描述为什么失败、当前局面、仍然开放的选项

5. 记录
   - 如果这是一个全新的判例，写入 DM速记_备忘 的裁决记录区
   - 后续同类情况沿用此判例
```

### 裁决红线
```
✗ 不因"剧情需要"扭曲掷骰结果
✗ 不向玩家暴露他们角色未知的信息
✗ 不替玩家做决策（"你意识到..."可以，"你决定..."不行）
✗ 不创造规则书中不存在的基础物理法则（但可以在法则内创建新变体）
✗ 不让一次失败摧毁所有可能（失败应该是"这条路堵上了——还有什么路？"）
```

## 五、奇思妙想：工坊与制作

### 核心态度

**没有预设配方。配方是玩家和DM共同"发明"的。**

工坊试验的本质是：
> 玩家提出一个想法 → DM判断在灰区条件下是否可能 → 设定难度和消耗 → 执行

### 工坊试验流程

```
1. 玩家提出想法
   例："我想把异常结晶碎片研磨后与枪油混合，给M4A1做临时的结晶镀层子弹。"

2. DM判断
   - 可行性：异常结晶确实可以通过物理接触传导能量（灰区定律二）。镀层子弹在物理上可行。
   - 工坊要求：需要Lv2以上工坊（有研磨和分析设备）
   - 技能：制作(INT) + 可能需要电子设备辅助分析结晶纯度
   - 难度：困难(-15)——异常结晶的性质不稳定，研磨过程中可能失活
   - 消耗：1块异常结晶碎片（研磨后约产6-8发子弹量）
   - 失败后果：结晶在研磨中失活，材料浪费

3. 检定与结果
   - 大成功：12发完美镀层，额外+1d4共鸣伤害
   - 成功：8发镀层子弹，+RSN/3↓共鸣创伤伤害
   - 失败：结晶失活，材料浪费
   - 大失败：结晶在研磨中不稳定释放——工坊小范围能量冲击波（1d4创伤），材料全毁

4. 记录判例
   此结果写入裁决记录，后续同类型试验沿用此框架。
```

### 常见工坊试验方向（引导，非限制）

| 方向 | 所需工坊 | 典型难度 | 示例产物 |
|------|---------|---------|---------|
| 武器基础改造 | Lv1 | 标准 | 加重配重、减震握把 |
| 弹药复装/调质 | Lv1 | 标准~困难 | 复装弹、简易HP弹 |
| 异常结晶镀层 | Lv2 | 困难 | 武器附加共鸣伤害 |
| 异常结晶嵌入 | Lv2 | 极难 | 指虎/刀刃附加共鸣伤害 |
| 便携式异常装置 | Lv3 | 噩梦 | 一次性脉冲探测器、简易能量护盾 |
| 结晶粉末弹药 | Lv2 | 困难 | 临时镀层子弹 |
| 材料熔合 | Lv3 | 极难 | 两种不同Tier材料合成新品质 |

**重要**：以上只是已被验证可行的方向。玩家可以提出任何方向——DM根据灰区物理法则和逻辑可行性判断。

### 工坊试验的制约因素

- **工坊等级**：Lv1=基础机械加工，Lv2=精密加工+材料分析，Lv3=异常能量处理
- **材料稀有度**：异常结晶碎片只能从灰区获取。用完就没了。
- **制作技能**：高难度试验需要高制作技能。未受训的角色进行复杂工坊试验≈浪费材料。
- **时间成本**：一次试验通常消耗1-4小时游戏内时间。在突袭中可能没有这个时间。

## 六、物品：模板制

### 核心原则

物品表是**参考模板**，不是**穷举清单**。

所有武器、装备、物品表格提供的是：
- **Tier级别的数值范围**：告诉你T1武器大概什么伤害、T3武器大概什么水平
- **属性框架**：告诉DM设计新物品时应该有哪些参数（伤害骰、特效、重量、稀有度）
- **创意思路参考**：已有的物品是"这些东西被证明存在"，不是"只有这些东西存在"

### DM创建新物品的指南

1. 确定Tier → 找到对应数值范围
2. 确定类型 → 匹配伤害骰/固伤范围
3. 设计1-2个符合灰区物理法则的特效
4. 命名 → 放入游戏 → 记录为已知物品

例：玩家在旧实验室找到一把原型武器——DM可以当场设计：
- Tier: T3（实验室原型级别）
- 类型: 轻型近战
- 伤害: 1d6+1 + 1d4共鸣（受RSN加成）
- 特效: 对机械目标伤害×1.5（实验室反器材设计的残响）
- 名字: "解构者·实验型"
- 稀有度: 此区域独有，不可购买

**不需要"物品表里有这一行"——DM有权创造。**

## 七、灰区异常三定律

这是灰区内的**客观物理法则**。所有异能、异常物品、超自然现象的裁决必须以这三条为基础。

### 第一律：区域依赖

> 所有异能、异常强化和超自然物品仅在灰区边界内有效。离开灰区边界后，所有异常效应消退——异能者回归普通人，异常结晶失去能量，强化物品变为普通物品。

- 灰区边界是一个客观存在的物理分界线，约半径80km
- 边界并非绝对清晰——边缘区域的异常效应逐步衰减
- 进入灰区后，异常效应大约在1小时内逐步"激活"

### 第二律：结晶传导

> 异常结晶是维度交汇能量的固态物理载体。它可以被加工（研磨、镀层、嵌入、熔合），将能量传导至接触它的其他物质。

- 异常结晶碎片(小)：微弱传导，约RSN/4的加成
- 异常结晶晶体(中)：中等传导，约RSN/3~RSN/2的加成范围
- 异常结晶核心(大)：强大传导，可支持大型异常装置
- 结晶不会"用完"——它会缓慢从灰区环境中重新吸收能量。但被破坏（研磨成粉后失活）不可逆。

### 第三律：共鸣响应

> 部分人体对异常能量具有天然敏感性。RSN属性代表这种敏感度。RSN越高，越能主动引导异常能量（异能），但也越容易被动接收异常干扰（失控风险）。

- RSN ≤ WIL：安全区间，无异能副作用
- RSN > WIL：超出意志控制范围，产生失控风险
- RSN的高低是先天禀赋+后天暴露的共同结果
- 在灰区内长期停留可能缓慢提升RSN——也可能加速失控

**裁决应用**：当玩家提出一个涉及异常能量的新奇想法时，DM用这三定律判断可行性。如果想法违反三定律中的任何一条→不可行。如果符合→设定难度和执行。

## 八、不希望出现的游戏行为

以下行为会损害所有人的游戏体验。不是规则禁止——是约定。

- **碾压式角色构建**：利用数值漏洞追求无敌。做得到的Build往往会破坏DM的叙事空间，最终所有人都不好玩。
- **信息战**：翻阅DM文件、利用外部信息做出角色不该知道的决策。
- **单人英雄主义**：在多人游戏中垄断行动机会、拒绝协作。
- **挑衅DM**：反复试探DM界限、故意提出不可能要求来测试DM的容忍度。

## 九、文件维护约定

- `rules/` — 规则和约定。修改需要告知所有参与者。
- `dm_guide/` — DM工具。DM自主维护。
- `characters/` — 角色档案。由AI DM在主游戏进程中更新。玩家不直接编辑。
- `table/` — 多人桌配置。由系统维护。
- `assets/` — 参考数据。DM可按需扩充。
- `logs/` — 游戏记录。自动生成，不改写历史。
