# 骰池协议：《灰区：撤离》v3.0

> 定义骰池的使用规则，保证游戏公平性。

---

## 核心规则

1. 骰池由玩家使用 `python tools/dice_pool.py -o` 预生成
2. AI DM 严格按**从上到下逐行**消耗每个骰子
3. 每消耗一个骰子，立即从 `tools/dice_pool.md` 中**删除该行**
4. 不允许跳过、挑选、重投（除非规则明确允许，如专长效果）
5. 不同类型的骰子独立消耗（d100和d10各有自己的列表）

## 消耗示例

```
需要投 d100 → 取 d100 章节下最上面一行的数字，使用后删除该行
需要投 2d6 → 取 d6 章节下最上面两行的数字，使用后删除该两行
```

## 骰子用途

| 骰子 | 主要用途 |
|------|---------|
| d100 | 所有技能/属性检定、命中判定、闪避判定 |
| d10 | 先攻投骰、随机事件判定、伤害基数（部分武器） |
| d8 | 伤害骰（突击步枪/近战等） |
| d6 | 伤害骰（手枪/SMG）、多数恢复量 |
| d4 | 流血伤害、持续伤害、小型效果 |

## 补充机制

```
当某类骰子剩余不足 3 个时，DM 在回复末尾提醒：
"⚠ [骰子类型] 骰池即将耗尽，请运行 python tools/dice_pool.py -o 补充。"

骰池完全耗尽时的临时方案：
- d100耗尽 → 使用简化判定（属性×10直接对比难度值）
- 伤害骰耗尽 → 取武器伤害骰的中值（如d8取4）
```

## 暗骰规则

```
DM暗中进行的检定同样消耗骰池中的骰子
暗骰结果写入 logs/system/ 但不向玩家展示
暗骰消耗在系统日志中标注[暗骰]
```

## 骰池审计

```
玩家可在任意时刻运行 python tools/dice_pool.py（不带 -o）查看当前骰池
也可直接打开 tools/dice_pool.md 查看
骰池中的数字序列可作为公平性审计依据
```
