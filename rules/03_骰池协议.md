# 骰池协议：《灰区：撤离》v5

> 当前基线：D20 检定引擎。骰池只负责公平审计；AI DM 负责声明检定与解释结果。

---

## 核心规则

1. 骰池由玩家或工具使用 `python tools/dice_pool.py -o` 预生成。
2. 优先由工具层消耗骰子并写入审计记录；AI DM 负责声明检定目的、DC、修正、骰型和叙事解释。
3. 如果没有可用工具，AI DM 严格按**从上到下逐行**消耗每个骰子。
4. 每消耗一个骰子，立即从 `tools/dice_pool.md` 中**删除该行**，并在系统日志或 Rulings 中记录。
5. 不允许跳过、挑选、重投（除非规则明确允许，如专长效果）。
6. 不同类型的骰子独立消耗。

## 骰子用途

| 骰子 | 数量 | 主要用途 |
|------|------|---------|
| d20 | 50 | **所有技能/属性检定、命中判定、先攻、闪避判定** |
| d12 | 10 | 重型武器伤害、反器材伤害 |
| d10 | 15 | 7.62mm弹药伤害、栓狙伤害 |
| d8 | 15 | 5.56mm弹药伤害、突击步枪/近战伤害 |
| d6 | 20 | 9mm/手枪弹药伤害、多数恢复量、暴击额外伤害 |
| d4 | 15 | 轻型近战伤害、持续伤害、流血伤害 |

## 消耗示例

```
需要投 d20 → 取 d20 章节下最上面一行的数字，使用后删除该行
需要投 2d6 → 取 d6 章节下最上面两行的数字，使用后删除该两行
需要投 d20+d8 → 分别取 d20 和 d8 最上面一行
```

## 补充机制

```
当某类骰子剩余不足 3 个时，DM 在回复末尾提醒：
"⚠ [骰子类型] 骰池即将耗尽，请运行 python tools/dice_pool.py -o 补充。"

骰池完全耗尽时的临时方案：
- d20耗尽 → 使用固定值10（标准DC12下约42%成功率）
- 伤害骰耗尽 → 取伤害骰中值（如d8取4.5→4或5由DM裁定）
```

## 暗骰规则

```
DM暗中进行的检定同样消耗骰池中的骰子
暗骰结果只写入 DM 专用记录，不向玩家展示
当前模式不维护历史日志；如需审计，在 `dm_guide/DM速记_备忘.md` 的裁决记录区标注[暗骰]
```

## 骰池审计

```
玩家可在任意时刻运行 python tools/dice_pool.py（不带 -o）查看当前骰池
也可直接打开 tools/dice_pool.md 查看
骰池中的数字序列可作为公平性审计依据
```
