## 一、基础属性

| 序号 | 属性 | 缩写 | 描述 | 影响领域 |
|------|------|------|------|----------|
| 1 | 力量 | STR | 肉体力量 | 负重上限、近战伤害修正、后坐力控制 |
| 2 | 敏捷 | AGI | 速度与协调 | 闪避、先攻、移动速度、远程武器操作 |

## 四、检定系统

### 4.1 核心机制 — d100 目标数判定

```
投 1d100 ≤ 基础值 + 难度修正 → 成功
基础值 = 关联属性 × 10 + 技能等级 × 5
未受训：基础值 = 关联属性 × 5（复合属性取(A+B)×2.5）
```

### 4.2 复合检定（双属性）

```
基础值 = (属性A + 属性B) × 5 + 技能等级 × 5
```

### 4.3 难度修正表（7级）

| 难度 | 修正值 | 典型场景 |
|------|--------|----------|
| 轻松 | +40 | 在光天化日下看远处的建筑 |
| 普通 | +20 | 在安静环境中聆听隔壁房间 |
| 标准 | ±0 | 常规射击、常规搜索 |
| 困难 | -15 | 在交火中精准爆头、雾天远距离 |
| 极难 | -30 | 黑暗中撬锁、移动中狙击 |
| 噩梦 | -45 | 重伤状态下近战、暴风雨中长距离射击 |
| 奇迹 | -60 | 盲狙千米外目标、无工具徒手拆弹 |

### 4.4 特殊骰结果

| 结果 | d100范围（常规） | d100范围（基础值>100时） | 效果 |
|------|-----------------|------------------------|------|
| 大成功 | 01-05 | 01-05 | 最佳效果 + 额外收益 |
| 大失败 | 96-00 | 99-00 | 灾难性后果 |
| 临界成功 | = 基础值 | = 基础值 | 成功但有代价/瑕疵 |

## 五、战斗系统

### 5.1 AP系统（每轮）

| 行动类型 | 消耗 | 说明 |
|----------|------|------|
| 主要行动 | 2 AP | 射击(单发)、近战、投掷、急救他人、使用大型道具 |
| 次要行动 | 1 AP | 换弹匣、换武器、快速搜索、使用小型医疗品、探头(从全掩体) |
| 反应 | 1 AP | 闪避(每次)、格挡(有盾) |
| 移动 | 0 AP | 每轮AGI×2米免费移动。超出部分1AP/2米 |

**AP池**：每轮AP = 3 + RES/3↓，用尽不可透支。
**AP不可预支**：每轮开始时刷新，剩余AP不保留到下一轮。

### 5.2 射击模式与AP

| 模式 | AP | 命中修正 | 说明 |
|------|-----|---------|------|
| 单发 | 2 | ±0 | 标准射击 |
| 连射(2发) | 3 | 第2发-10 | 需武器支持连发 |
| 扫射(3发) | 4 | 每发-15 | 需武器支持扫射，压制范围 |
| 精确瞄准 | +1 AP | +5 | 叠加于射击之上 |
| 快速射击 | 1 AP | -10 | 仅手枪/SMG，近距离 |
| 火力压制 | 3 AP | 不检定 | 目标区域敌人自动触发压制判定 |

### 5.3 攻防流程

```
攻击方：投 d100 ≤ 远程攻击基准 + 难度修正 ± 部位修正
闪避方：消耗 1AP → 投 d100 ≤ 闪避值 + 掩体修正 + 难度修正
  闪避成功 → 完全免伤（除非范围伤害）
  闪避失败 → 承受伤害

伤害 = 子弹伤害骰 + 属性修正 - 护甲值（最低1）
  属性修正（远程）= AGI/3（向下取整）
  属性修正（近战）= STR/3（向下取整）
```

### 5.4 身体部位瞄准

| 部位 | 命中修正 | 伤害倍率 | 特殊效果 |
|------|----------|----------|----------|
| 头部 | -20 | ×1.8 | 有头盔则穿透前不减倍率 |
| 躯干 | ±0 | ×1.0 | 标准 |
| 手臂 | -10 | ×0.8 | 命中后目标下次攻击-10 |
| 腿部 | -10 | ×0.8 | 命中后目标移动速度减半1轮 |

### 5.5 掩体系统

掩体闪避加成与角色基础闪避值**叠加**。

| 掩体类型 | 闪避加成 | 限制 |
|----------|----------|------|
| 半掩体 | +15 | 暴露上半身，仍可被爆头 |
| 全掩体 | +30 | 无法攻击，必须先探头（消耗次要行动1AP） |
| 轻掩体 | +10 | 木头/铁皮等，每轮承受10伤害后摧毁 |
| 高台优势 | 攻击+5 | 对低位目标 |

### 5.6 压制机制

```
被射击后（无论命中与否），投 WIL 检定：
  成功 → 不受影响，本轮免疫后续压制
  失败 → 处于"被压制"状态：所有检定 -15，持续 1d3 轮
  大失败 → 恐慌：必须移动到最近掩体，失去本轮剩余行动

连续被压制 → 效果不叠加但刷新持续时间
```

### 5.7 伤害类型与护甲减免

| 类型 | 护甲减免比例 | 典型来源 |
|------|------------|---------|
| 物理-弹道 | 100% | 子弹（FMJ/HP） |
| 物理-切割 | 50% | 刀、碎片、鹿弹 |
| 物理-爆炸 | 30% | 手雷、地雷、榴弹 |
| 物理-穿透 | 0% | AP弹（直接无视护甲5点，不参与本表）|
| 化学 | 0%（需防化装备）| 毒气、酸液 |
| 辐射 | 0%（需防辐射装备）| 异常区域 |
| 电击 | 50% | 电击棒、EMP |
| 纯伤害 | 无法减免 | 坠落、维度撕裂 |

### 5.8 协作行动（多人）

```
多人协作同一任务：
  选主执行者，辅助者提供加成
  1辅助 = +5 | 2辅助 = +10 | 3辅助 = +15（上限）

多人协作战斗：
  同时攻击同一目标 → 各自独立检定，伤害独立计算
  掩护射击 → 消耗2AP，指定队友本轮闪避+10
  协同推进 → 两人相邻移动时互不遮挡射界，各获得+5移动距离

多人时序竞争：
  同时声明冲突行动 → 全部投 AGI+RES/2 对抗，胜者先执行
  战斗中按先攻顺序执行
```

### 5.9 濒死与急救

```
HP ≤ 0：倒地濒死，每轮投 CON 检定
  CON 成功 → 稳定（但仍倒地）
  CON 失败 → 恶化，HP-2
  HP ≤ -10 → 死亡

队友急救（消耗主要行动2AP）：INT+急救技能检定
  成功 → 目标恢复到 HP=1，状态"重伤"
  大成功 → 目标恢复到 HP=1d6+1，无重伤
  失败 → 无效果，可重试
```

```

```
进入突袭：只能在基地调配装备

丢弃物品：在原地可被后续访问捡回

## 十九、突袭节奏控制

### 19.1 突袭五阶段

每个突袭应经历五个阶段。DM用此控制节奏。

| 阶段 | 时长(min) | 节奏 | DM重点 | 玩家行动 |
|------|-----------|------|--------|---------|
| **1. 潜入 Entry** | 10-15 | 慢 | 氛围描写、路线选择、初始侦察 | 选路线、侦察、制定计划 |
| **2. 探索 Explore** | 20-40 | 中 | 每2-3个搜索点给"选择点" | 搜索、轻度战斗、发现线索 |
| **3. 高峰 Climax** | 15-25 | 快 | 推动至Boss/重大遭遇/剧情揭示 | Boss战、重大决策 |
| **4. 撤离 Extract** | 10-15 | 极快 | 倒计时压力、追兵、路线抉择 | 跑/战斗抉择 |
| **5. 结算 Settle** | 5-10 | 慢 | 战果统计、经验、物资入库 | 放松、看收获 |

### 19.2 DM节拍规则

```
□ 每搜索2-3个区域 → 必须插入一次非搜索活动（战斗/事件/发现/NPC遭遇）
□ 每场战斗后 → 给玩家喘息时间（搜索/治疗/决策路线）
□ 连续3轮战斗 → 打破节奏（敌人换战术/环境变化/弹药警告）
□ 玩家表现出疲态 → 推动至撤离
□ 玩家弹药/医疗品告急 → 暗示撤离点的位置
□ 高峰阶段开始条件：玩家到达区域核心 或 3次探索+战斗交替后
```

### 19.3 撤离压力机制

```
激活撤离点 → 等待2d4轮 → 噪音吸引敌人
每轮：DM投d6
  1-3: 无事发生（但描写紧张氛围——远处的脚步声/引擎声/警报）
  4-5: 普通敌人1d3个出现
  6: 精英敌人1个出现
撤离成功：撤离点的门/载具/直升机接通
```

## 二十、结局D线索机制

**结局D（"镜中人"）**需要玩家在游戏过程中自然收集三个隐藏真相碎片。DM应在以下关键时刻给予提示：

| 碎片 | 位置 | 触发条件 | 内容暗示 |
|------|------|----------|----------|
| 碎片1 | 地下生活区C（支线#7） | 钢琴解密成功后 | 首次裂隙接触记录——镜界并非敌对，有人在等待 |
| 碎片2 | 荒野区（支线#8） | 无人机数据记录仪 | UEG仍在秘密补给灰区深处——暗示"合作"存在 |
| 碎片3 | 维度裂隙观测站 | 裂隙近距+WIL检定成功 | 直接感知镜界——获得"对面也没那么糟"的直觉 |

**DM标记规则**：
- 每个碎片获取时，在`DM速记_备忘.md`的剧情位置中标注「结局D碎片 N/3」
- 终章核心控制室中，如果3/3碎片齐全 + 击败终末法庭 → 解锁选项D
