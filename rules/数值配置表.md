## 三、血槽系统

### 3.1 血槽总览

```
血槽总数 = CON × 2 + 4
每个血槽有三种状态：健康(H)、轻伤(L)、重伤(S)
关系：H + L + S = 总数
```

| CON | 血槽总数 | 示例角色 |
|-----|---------|---------|
| 1 | 6 | 极度脆弱 |
| 3 | 10 | 普通人 |
| 5 | 14 | 标准回收者 |
| 7 | 18 | 强悍老兵 |
| 10 | 24 | 体质巅峰 |

### 3.2 伤害类型与填充规则

**创伤伤害**（常规攻击：射击、斩击、钝击、投掷）：
```
逐点填充，顺序为 H→L→S
  每点伤害：若 H>0 → H-1, L+1
            否则若 L>0 → L-1, S+1
            否则溢出浪费
```

**重创伤害**（暴击、爆炸、重型武器、精确要害命中）：
```
逐点填充，跳过轻伤，直击重伤
  每点伤害：若 H>0 → H-1, S+1
            否则若 L>0 → L-1, S+1
            否则溢出浪费
```

**伤害计算**：
| 来源 | 类型 | 公式 |
|------|------|------|
| 近战攻击 | 创伤伤害 | 武器伤害骰 + STR/3↓ - 目标护甲（最低1） |
| 远程射击 | 创伤伤害 | 武器固伤 + 弹药伤害骰 - 目标护甲（最低1） |
| 暴击（大成功） | 重创伤害 | 以上公式，伤害×1.5，且转为重创伤害 |
| 爆炸/重型 | 重创伤害 | 见具体武器数值 |
| 环境/坠落 | 重创伤害 | 见具体数值 |

### 3.3 重伤惩罚阶梯

| 重伤槽数(S) | 状态 | 检定惩罚 | 行动限制 |
|------------|------|---------|---------|
| S = 0 | 正常 | 无 | 无 |
| S = 1 | 挂彩 | 全检定 -5 | 无 |
| S ≥ 2 | 力竭 | 全检定 -20 | 无法执行复杂行动（连射、扫射、精密操作、破解） |
| S > 总数/2 | 昏迷 | 无法检定 | 失去意识，无法行动 |
| S = 总数 | 濒死 | 无法检定 | 倒地，每轮CON检定决定生死 |

> 注意：轻伤槽(L)本身不产生惩罚，但轻伤槽越多，承受下一次攻击时越容易转入重伤。

### 3.4 濒死规则

```
S = 总数 → 角色倒地濒死
每轮结束时投 CON 检定（标准难度）：
  成功 → 稳定（仍倒地，不恶化）
  失败 → 恶化，S状态不变但身体机能下降，累计恶化标记+1
  连续2次失败 → 死亡

队友急救（标准动作，INT + 急救技能检定）：
  成功 → 1重伤槽转为轻伤槽（S-1, L+1）；若S<总数则恢复意识
  大成功 → 1d3重伤槽转为轻伤槽
  失败 → 无效果，可重试
  需求：绷带 或 急救包
```

### 3.5 恢复

| 方式 | 效果 | 条件 |
|------|------|------|
| 绷带（快速动作） | 1轻伤槽转为健康（L-1, H+1） | 需持有绷带 |
| 急救包（标准动作） | 1d3轻伤→健康，1重伤→轻伤 | 需急救检定 |
| 军用医疗包（标准动作） | 2d3轻伤→健康，1d2重伤→轻伤 | 需急救检定 |
| 安全区休息（8小时） | 1d3重伤→轻伤，CON/2↓轻伤→健康 | 安全环境 |
| 医疗室Lv2休息 | 额外1重伤→轻伤 | 基地升级 |
| 医疗室Lv3休息 | 全部轻伤→健康 | 基地升级 |

## 五、检定系统

### 5.1 核心机制 — d100 目标数判定

```
投 1d100 ≤ 基础值 + 难度修正 → 成功
基础值 = 关联属性 × 10 + 技能等级 × 5
未受训 = 关联属性 × 5（复合属性取(A+B)×2.5↓）
```

### 5.2 复合检定（双属性）

```
基础值 = (属性A + 属性B) × 5 + 技能等级 × 5
```

### 5.3 难度修正（7级）

| 难度 | 修正值 | 典型场景 |
|------|--------|----------|
| 轻松 | +40 | 白天百米外认出熟人 |
| 普通 | +20 | 安静室内听到隔壁脚步 |
| 标准 | ±0 | 靶场射击、普通房间搜索 |
| 困难 | -15 | 交火中爆头、黄昏远射 |
| 极难 | -30 | 黑暗撬锁、移动中狙击 |
| 噩梦 | -45 | 重伤状态下攀爬、暴风雨中射击 |
| 奇迹 | -60 | 无工具拆弹、千米盲狙 |

### 5.4 特殊骰结果

| 结果 | d100范围（常规） | d100范围（基础值>100时） | 效果 |
|------|-----------------|------------------------|------|
| 大成功 | 01-05 | 01-05 | 最佳效果 + 额外收益。战斗中转为**重创伤害**，伤害×1.5 |
| 大失败 | 96-00 | 99-00 | 灾难性后果 |
| 临界成功 | = 基础值 | = 基础值 | 成功但有代价或瑕疵 |

### 5.5 对抗检定

双方各投d100，比较"基础值 - 投出值"（成功余量），余量大者胜。双方都失败则僵持。

## 六、异能系统

### 6.1 能量池

```
能量池上限 = CON + RSN × 2
能量恢复 = RSN/3↓ + 1（每轮专注/休息时）
能量全恢复 = 1小时安全休息
```

| RSN | CON示例 | 能量上限示例 | 每轮恢复 |
|-----|---------|------------|---------|
| 1 | 3 | 5 | 1 |
| 3 | 5 | 11 | 2 |
| 5 | 7 | 17 | 2 |
| 8 | 8 | 24 | 3 |
| 10 | 10 | 30 | 4 |

### 6.2 核心规则

- **每人最多2个体系**。初始创建时选择1个主修体系，获得其T0·觉醒（被动×1+主动×1）。
- **体系内子系树状成长**：每个体系下有若干子系（如元素共鸣系→火/冰/电/风/爆裂），每个子系是独立的技能树，分Lv1~Lv3。
- **子系成长消耗XP**：解锁新子系、升级已有子系消耗经验值。上限由体系Tier决定。
- **晶体用于突破上限和解锁体系**：
  - C×3 → 体系T0→T1（子系Lv上限提高到2）
  - B×2 → 体系T1→T2（子系Lv上限提高到3）
  - A×1 → 体系T2→T3（子系Lv上限提高到3+部分解锁Lv4终极技）
  - **B×3** → 解锁第二体系T0·觉醒（66%失败率——见§6.9）
- **濒死觉醒**：角色血槽全重伤(S=总)且在Zone3+深层灰区→可消耗一整轮动作(标准+快速)尝试觉醒任意其他体系的T0。CON+RSN检定(困难-15)。成功→立即觉醒(T0·觉醒,血槽恢复1重伤→轻伤)。失败→恶化标记+1(濒死状态加速死亡)。
- **无冷却**——所有主动异能仅消耗能量。进阶后同技能耗能降低。
- **异能伤害加成**：所有攻击型异能附带+RSN/3↓修正。

### 6.8 子系成长（XP消耗）

在已解锁体系内：

| 操作 | XP消耗 |
|------|--------|
| 解锁新子系Lv1 | 30 XP |
| 子系Lv1→Lv2 | 40 XP |
| 子系Lv2→Lv3 | 60 XP |

**体系Tier决定子系Lv上限**：T0→最高Lv1，T1→最高Lv2，T2→最高Lv3，T3→子系Lv3+部分子系解锁终极Lv4(数值表中以Lv3标注，名称变化)。

### 6.9 解锁新体系

**晶体解锁**（围栏镇或安全环境）：
- 消耗：**B级异常结晶×3**
- 操作：将结晶揉碎为粉末，涂抹于身体。入睡8小时。
- 检定：CON+RSN（困难-15）
- 成功率：约33%（1/3）
- 成功：觉醒新体系T0·觉醒（该体系的被动×1+主动×1各Lv1）
- 失败：
  - 投1d6: 1-2→1d4重伤槽+材料损失
  - 3-4→RSN临时-1(1d3次安全休息恢复)+材料损失
  - 5-6→失控反噬：1d6重伤+24h无法使用任何异能+材料损失

**濒死觉醒**（深层灰区）：
- 条件：血槽全重伤(S=总) 且 在Zone3+深层灰区
- 操作：消耗一整轮动作（标准+快速），在濒死边缘引导灰区能量
- 检定：CON+RSN（困难-15）
- 成功：立即觉醒新体系T0·觉醒 + 1重伤→轻伤（恢复意识）
- 失败：濒死恶化标记+1（加速死亡）

### 6.10 共鸣失控风险

当 RSN > WIL 时：

| RSN - WIL | 风险 | 效果 |
|-----------|------|------|

## 九、武器系统

### 核心原则

**弹药提供主要伤害骰。武器提供固伤和命中框架。两者独立。**

- 远程伤害 = 武器固伤 + 弹药伤害骰 - 目标护甲
- 近战伤害 = 武器伤害骰 + STR/3↓ - 目标护甲
- 暴击（大成功）→ 伤害×1.5 且转为**重创伤害**
- 所有常规伤害为**创伤伤害**。爆炸和重型武器部分为**重创伤害**。
