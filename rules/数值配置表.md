# 数值配置表：《灰区：撤离》v4

> **本文件是游戏中所有数值的唯一来源。**
> 所有规则文件、角色卡、DM工具中的数值必须与本表一致。

## 一、核心检定引擎 — d20 + 修正 ≥ DC

```
投 d20 + 属性修正 + 技能修正 + 其他修正 ≥ 目标DC → 成功
```

### 1.1 属性修正

属性范围 1-10，初始 35 点自由分配。

| 属性值 | 修正值 | 属性值 | 修正值 |
|--------|--------|--------|--------|
| 1 | -4 | 6 | +1 |
| 2 | -3 | 7 | +2 |
| 3 | -2 | 8 | +3 |
| 4 | -1 | 9 | +4 |
| 5 | 0 | 10 | +5 |

### 1.2 技能修正

| 技能等级 | 名称 | 修正值 | 升级花费 | 所需角色等级 |
|---------|------|--------|---------|------------|
| 0 | 未受训 | 0 | — | — |
| 1 | 入门 | +1 | 1 技能点 | Lv1 |
| 2 | 熟练 | +2 | 2 技能点 | Lv1 |
| 3 | 专精 | +3 | 3 技能点 | Lv3 |
| 4 | 大师 | +4 | 5 技能点 | Lv5 |
| 5 | 传说 | +5 | 8 技能点 | Lv8 |

初始技能点：25 点

### 1.3 难度等级（DC）

| 难度 | DC | 典型场景 |
|------|-----|----------|
| 轻松 | 8 | 白天认出熟人、安静室内听脚步 |
| 普通 | 10 | 翻越围栏、跟踪明显足迹 |
| 标准 | 12 | 靶场射击、普通房间搜索、撬简易锁 |
| 困难 | 15 | 交火中精确射击、黑暗潜行、复杂装置破解 |
| 极难 | 18 | 移动中狙击、无工具拆弹、重伤急救 |
| 噩梦 | 21 | 暴风雨中远程射击、千米狙击、无麻醉手术 |
| 奇迹 | 24 | 几乎不可能的任务 |

### 1.4 特殊骰结果

| 结果 | d20 | 效果 |
|------|-----|------|
| **暴击** | 自然 20 | 自动成功 + **额外 1d6 伤害**（保持原伤害类型） |
| **大失败** | 自然 1 | 自动失败 + DM裁定负面后果 |
| **卓越成功** | 超过 DC ≥ 10 | 额外收益或事半功倍 |

> 暴击不再转换伤害类型。伤害类型由武器本身决定。

### 1.5 复合检定（双属性）

```
修正值 = (属性A修正 + 属性B修正) / 2（向下取整）+ 技能修正
```

## 四、血槽系统

### 4.1 血槽总览

```
血槽总数 = CON × 2 + 4
每个血槽有三种状态：健康(H)、轻伤(L)、重伤(S)
关系：H + L + S = 总数
```

| CON | 血槽总数 | 示例角色 |
|-----|---------|---------|
| 1 | 6 | 极度脆弱 |
| 3 | 10 | 普通人 |
| 5 | 14 | 标准回收者 |
| 7 | 18 | 强悍老兵 |
| 10 | 24 | 体质巅峰 |

### 4.2 伤害类型与填充规则

**创伤伤害**（常规射击、斩击、钝击、投掷、暴击额外骰）：
```
逐点填充，顺序为 H→L→S
  每点伤害：若 H>0 → H-1, L+1
           否则若 L>0 → L-1, S+1
           否则溢出浪费
```

**重创伤害**（重创弹药、爆炸、环境/坠落）：
```
逐点填充，跳过轻伤，直击重伤
  每点伤害：若 H>0 → H-1, S+1
           否则若 L>0 → L-1, S+1
           否则溢出浪费
```

> **v5 变化：重创不再绑定武器。** 常规武器一律造成创伤伤害。重创伤害来源仅限：**重创弹药**（极稀有）、爆炸物、环境/坠落。

### 4.3 伤害计算

| 来源 | 类型 | 公式 |
|------|------|------|
| 近战攻击 | 创伤 | 武器伤害骰 + STR修正 - 目标护甲IR（最低1） |
| 远程射击（常规弹） | 创伤 | 武器固伤 + 弹药伤害骰 - 目标护甲IR（最低1） |
| 远程射击（重创弹） | **重创** | 武器固伤 + 重创弹药伤害骰 - 目标护甲CR（最低1） |
| 暴击（自然20） | 同武器/弹药 | 以上公式 + 1d6（保持原伤害类型） |
| 爆炸/环境 | 重创 | 见具体数值 |
| 坠落 | 重创 | 每3m = 1重创伤害（护甲CR减半↓） |

### 4.4 重伤惩罚阶梯

| 重伤槽数(S) | 状态 | 检定修正 | 行动限制 |
|------------|------|---------|---------|
| S = 0 | 正常 | 无 | 无 |
| S = 1 | 挂彩 | 全检定 -2 | 无 |
| S ≥ 2 | 力竭 | 全检定 -5 | 无法执行复杂行动（连射、扫射、精密操作、破解） |
| S > 总数/2 | 昏迷 | 无法检定 | 失去意识，无法行动 |
| S = 总数 | 濒死 | 无法检定 | 倒地，每轮CON检定决定生死 |

> 轻伤槽(L)本身不产生惩罚，但会为后续攻击"铺路"。

### 4.5 肾上腺素激增

```
触发：角色重伤槽首次达到 S ≥ 总数/2（整场战斗仅1次）
效果：全检定惩罚临时移除1轮 + 移动速度翻倍
叙事：在绝境中爆发最后的战斗力
```

### 4.6 濒死规则

```
S = 总数 → 角色倒地濒死
每轮结束时投 CON 检定（DC 12）：
  成功 → 稳定（仍倒地，不恶化）
  失败 → 恶化标记 +1
  连续2次失败 → 死亡

**队友拖曳撤离**：
  队友可消耗标准动作拖曳濒死角色，以半速移动
  成功撤离 → 重伤保留但装备保留，在基地恢复
  全队阵亡 → 装备丢失，重生在基地

队友急救（标准动作, INT修正 + 急救技能 ≥ DC 15）：
  成功 → 1重伤→轻伤（S-1, L+1）；若S<总数则恢复意识
  大成功（≥ DC 25）→ 1d3重伤→轻伤
  失败 → 无效果，可重试
  需求：绷带 或 急救包
```

### 4.7 恢复

| 方式 | 效果 | 条件 |
|------|------|------|
| 绷带（快速动作） | 1轻→健（L-1, H+1） | 需持有绷带 |
| 急救包（标准动作） | 1d3轻→健 + 1重→轻 | 需急救检定 ≥ DC 12 |
| 军用医疗包（标准动作） | 2d3轻→健 + 1d2重→轻 | 需急救检定 ≥ DC 15 |
| 安全区休息（8小时） | 1d3重→轻 + CON修正↓轻→健 | 安全环境 |
| 医疗室Lv2休息 | 额外1重→轻 | 基地升级 |
| 医疗室Lv3休息 | 全部轻→健 | 基地升级 |

## 六、射击与命中

### 6.1 远程命中

```
攻击方：d20 + AGI修正 + 武器技能修正 + 武器精度
目标被动防御：10 + 目标AGI修正 + 掩体修正

未察觉目标：AGI修正不计入（DC = 8 + 掩体）
```

**对抗闪避**（目标消耗快速动作主动闪避）：
```
攻击方 d20 + mods  vs  防御方 d20 + AGI修正 + PER修正/2↓ + 掩体修正
攻击方 ≥ 防御方 → 命中
```

### 6.2 近战命中

```
d20 + STR修正 + 近战技能修正
对抗目标被动防御：10 + 目标AGI修正
闪避目标：与闪避检定对抗
```

### 6.3 防御速查

|---------|------------|
| AGI=5(修正0), 开阔 | 10 |

| AGI=5, 半掩体(+2) | 12 |

### 6.3 射击模式

| 模式 | 动作 | 修正 | 弹药消耗 | 骰数 |
|------|------|------|----------|------|

| 连射(2发) | 标准 | 第1发-2, 第2发-4 | 2发 | 2d20独立 |
| 扫射(3发) | 标准 | 第1发-2, 第2发-4, 第3发-6 | 3发 | 3d20独立 |

### 6.3.1 后坐力与力量修正

**连射/扫射**中，每发独立掷d20判定命中，修正值（属性+技能+精度）在所有弹丸间共享。

```
连射(2发) = 2d20 + 共享修正 + 后坐力惩罚
扫射(3发) = 3d20 + 共享修正 + 后坐力惩罚
```

**后坐力惩罚**：第1发-2, 第2发-4, 第3发-6。

**STR减后坐力**：
- STR修正 ≥ +2 → 后坐力惩罚逐发-1（最低至各发0）
- STR修正 ≥ +3 → 后坐力惩罚逐发-2（最低至各发0）
- STR修正为负 → 后坐力惩罚额外+N（N = |STR修正|）

> 例：铁手(STR8,修正+3) M4A1扫射 → 后坐力惩罚 -0/-2/-4。乌鸫(STR4,修正-1) 若不满足武器门槛则额外-2。

**武器力量门槛（见 §7B）**：角色STR低于武器需求时，所有射击（含单发）命中-2。

### 6.6 压制

```
被射击时 → WIL检定（DC 12 + 射击者数量）
  失败 → 全检定 -2（1d3轮）
  大失败 → 恐慌（失去1轮行动 + 随机移动）
  成功 → 本轮免疫压制
```

掩护射击：标准动作，指定队友闪避 +2（多人掩护不同目标各算各的）
```

## 七、武器系统 v5

### 核心原则

远程伤害 = 武器固伤 + 弹药伤害骰 - 护甲IR（最低 1）
近战伤害 = 武器伤害骰 + STR修正 - 护甲IR（最低 1）
暴击（自然20）= 以上 + 1d6（保持原伤害类型）

> **v5 变化：所有武器均为创伤伤害。重创仅来自弹药、爆炸、环境。**
> **弹药决定伤害维度，武器决定命中框架与改装潜力。**
> 武器类型大幅简化，不细分到具体型号——用**改装**区分个性。

### 7A. 近战武器

分三档，具体造型由玩家/DM叙事定义：

| 档位 | 伤害骰 | 重量(kg) | 典型例子 |
|------|--------|----------|---------|
| 轻型 | 1d4 | 0.5~1 | 匕首、指虎、战术刀 |
| 标准 | 1d6 | 1.5~3 | 砍刀、斧头、棒球棍、撬棍 |
| 重型 | 1d8 | 4~7 | 大锤、巨斧、动力锤 |

**近战武器特质（每把武器可选1-2个，在获取时由DM确定或工坊改装）**：

| 特质 | 效果 |
|------|------|
| 锋利 | 对无甲目标伤害+1 |
| 沉重 | 暴击时追加1d4创伤 |
| 破甲 | 无视1护甲IR |
| 轻巧 | 重量减半，命中+1 |
| 电击 | CON DC15 → 眩晕1轮（需充能，10次） |
| 链锯 | 伤害骰升一档（1d6→1d8, 1d8→1d10），噪音极大 |

### 7B.7 武器力量门槛

所有远程武器设有最低STR需求（见上表）。角色STR低于需求时，所有射击命中-2。

> 设计意图：重型步枪和霰弹枪的后坐力/重量需要上半身力量来稳定控制。AGI决定射击精度的上限，STR决定你是否能驾驭这把武器。

STR对射击的双重作用：
- **门槛**：低于武器需求 → 命中-2
- **后坐力**：STR修正≥+2/≥+3 → 逐发减少扫射/连射惩罚（见 §6.3.1）

## 九、护甲系统 v5 重做

### 9.1 核心机制：复合防护

```
护甲不再使用单一DR值。改为「冲击减免」+「重创减免」双维：

冲击减免（Impact Reduction, IR）：减免创伤伤害
重创减免（Critical Reduction, CR）：减免重创伤害

每次命中：
  创伤伤害 - IR = 实际创伤（最低1）
  重创伤害 - CR = 实际重创（最低1）

## 十二、异能系统 v5

### 12.1 能量池

```
能量上限 = RSN × 3
能量恢复 = RSN/3↓ + 1（每轮专注/休息时）
能量全恢复 = 安全休息 1 小时
```

| RSN | 能量上限 | 每轮恢复 |
|-----|---------|---------|
| 1 | 3 | 1 |
| 3 | 9 | 2 |
| 5 | 15 | 2 |
| 8 | 24 | 3 |
| 10 | 30 | 4 |

### 12.2 核心规则

- 每人最多 2 个体系。创建时选择 1 个主修体系 → T0·觉醒。
- **连续使用惩罚 v5**：
  - **单个技能惩罚**：同一主动异能在本场战斗中**连续使用每2次后**，该技能能量消耗追加 +1。停用该技能 3 轮后重置。
    例：使用2次冲击 → 第3次冲击 +1能。再使用第4次 → 仍 +1能。再使用第5-6次 → +2能。
  - **全场计数器**（独立于以上）：本场战斗中累计使用任意主动异能每 **4 次**后，之后**所有**主动异能能量消耗全局 +1，此计数器**不因切换技能或停用而降低**，仅战斗结束后重置。
    例：冲击→火→冲击→冰（累计4次）→ 第5次冲击原耗3能 → 实际耗 3+1 = 4 能。再第9次 → 全局 +2。
  - 切换使用不同技能可规避单个技能惩罚，但无法规避全场计数器。
- **共鸣攀升**：每次使用主动异能后 RSN 临时 +1（战斗结束后清除）。
  - 临时 RSN 也会影响失控风险：战斗中 RSN 不断攀升 → 风险递增。
- **无冷却**——仅耗能。进阶后同技能耗能降低。
- 异能伤害加成：攻击型异能附带 +RSN修正。

### 12.5 解锁新体系

**晶体解锁**（围栏镇或安全环境）：
- 消耗：B级异常结晶 ×3
- 检定：d20 + CON修正 + RSN修正 ≥ DC 18（极难）
- 成功：觉醒新体系 T0·觉醒
- 失败：投 1d6 → 1-2: 1d4重创+材料损失 / 3-4: RSN临时-1(1d3次休息恢复) / 5-6: 失控反噬(1d6重创+24h无法使用异能)

**濒死觉醒**（任何区域）：
- 条件：血槽全重伤(S = 总数)
- 操作：消耗整轮动作（标准+快速）
- 检定：d20 + CON修正 + RSN修正 ≥ DC 15（困难）
- 成功：觉醒新体系 T0·觉醒 + 1重伤→轻伤（恢复意识）
- 失败：濒死恶化标记 +1

### 12.6 共鸣失控风险 v5

> **v5 变化：WIL门槛全面提高。** 共鸣是危险的——意志薄弱者无法承受。

当 RSN > WIL 时（含临时攀升）：

| RSN - WIL | 风险等级 | 效果 |
|-----------|---------|------|
| 0 | 安全 | 无异能副作用 |
| 1~2 | 轻度 | PER/INT检定 -1，偶尔感知偏差（声音/光影错位） |
| 3~4 | 中度 | PER/INT检定 -3，频繁幻觉，战斗中可能误判目标 |
| ≥5 | 重度 | 每次使用主动异能 → WIL检定(DC 15)，失败→失控（随机目标/效果反转/自伤1d6） |

> 与v4对比：原v4门槛为0~1安全/2~3轻度/4~5中度/≥6重度。v5将门槛收紧——RSN比WIL高2就会开始有感知影响。

| 5 | 5 | 需投入10初始属性点保安全 |
| 7 | 7 | 需投入14属性点——开始出现build取舍 |
| 8 | 8 | 需要同等WIL，无法兼顾其他属性 |

## 二十二、搜索系统

搜索由**场景地图**驱动。每个场景的「可搜索区域」表定义了具体位置、搜索 DC、预设物品及可选的区域掉落表。DM 优先根据场景内列出的位置裁决搜索结果。

### 搜索方式

| 搜索方式 | 动作 | 耗时 | 说明 |
|----------|------|------|------|
| 快速搜索 | 快速 | 1 min | 扫一眼。PER + 侦察 ≥ DC + 2，成功获预设物品，无额外掉落。 |
| 标准搜索 | 标准 | 5 min | 仔细翻找。PER + 侦察 ≥ DC，成功获预设物品 + 区域掉落表 1 次。 |
| 彻底搜索 | 标准(多轮) | 15 min | 翻遍每一寸。PER + 侦察 ≥ DC + 2，成功获预设物品 + 区域掉落表 2 次。失败则一无所获——时间白费。

> **地图优先**：场景列出的位置已定义了搜索 DC 与预设物品。DM 优先使用场景数据。
> **即兴兜底**：玩家搜索未列出的位置时，DM 自由裁定 DC，使用区域掉落表兜底。
> **不可重复搜索**：同一位置只能被搜索一次（任何方式）。翻过的抽屉不会再长出东西。

### 搜索约束

搜索不设次数上限，由以下三项自然条件限制无限搜刮：

**1. 伤势** — 重伤槽(S)直接影响搜索能力：

| 重伤槽(S) | 搜索检定修正 | 额外限制 |
|-----------|------------|---------|
| S = 0 | 无 | — |
| S = 1 | -2 | — |
| S ≥ 2 | -5 | 无法执行彻底搜索（无法长时间集中） |
| S > 半 | 无法检定 | 昏迷或濒死，完全无法搜索 |

**2. 风险** — 搜索不是真空行为。每次出发/转移大地图前，DM 预先生成 DM 专用地图与事件表。搜索行为由 DM 根据预设事件表灵活调控——发现好东西时可能恰好有人路过，也可能惊动不该惊动的东西。事件表代替实时硬约束。

**3. 负重** — 搜得再多也背不动（详见 §二十三）：
- 负重上限 = STR × 5 + 20 kg
- 超重惩罚：移速减半 → 无法奔跑 → 无法战斗
- 常见物品参考：弹药 30 发 ≈ 0.5 kg，消耗品 ≈ 0.3 kg/件，武器见武器表

| Tier | 名称 | 颜色 | 典型内容 |
|------|------|------|----------|
| T0 | 垃圾 | 灰 | 废金属、空弹壳 |
| T1 | 常见 | 白 | 基础弹药、绷带、军粮 |
| T2 | 少见 | 绿 | HP/AP弹、急救包、标准武器 |
| T3 | 稀有 | 蓝 | 稀有武器、军用装备、结晶碎片 |
| T4 | 传说 | 紫 | 传说武器、结晶晶体 |
| T5 | 神话 | 金 | Boss专有、剧情道具 |
