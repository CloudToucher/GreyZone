# 公式速查卡：《灰区：撤离》"黑潮"战役

> DM 裁决时只看这一张卡。完整数值表在 `rules/数值配置表.md`（仅需查具体武器/敌人数据时查阅）。

---

## 命中判定

```
远程：d20 + AGI修正 + 技能 + 精度 ≥ 10 + 目标AGI修正 + 掩体
近战：d20 + STR修正 + 技能 ≥ 10 + 目标AGI修正
未察觉目标：DC = 8 + 掩体（不计AGI修正）
闪避（快速动作）：d20 + AGI修正 + PER修正/2↓ + 掩体 对抗攻击方投值
```

## 伤害计算

| 来源 | 类型 | 公式 |
|------|------|------|
| 近战/常规远程 | 创伤 | 武器伤害 - 护甲IR（最低1） |
| 重创弹/爆炸/坠落 | 重创 | 武器伤害 - 护甲CR（最低1） |
| 暴击(自然20) | 同武器 | 以上 + 1d6 |
| 坠落 | 重创 | 每3m = 1重创（CR减半↓） |

## 血槽填充

```
血槽总数 = CON × 2 + 4
创伤：H→L先，L→S后
重创：H→S先，L→S后（跳过轻伤）
```

## 重伤惩罚

| 状态 | 惩罚 |
|------|------|
| S=1 | -2 全检定 |
| S≥2 | -5 全检定 + 禁止复杂动作 |
| S > 总数/2 | 昏迷 |
| S = 总数 | 濒死（每轮 d20+CON修正 DC12→失败累计2次=死亡）|
| S 首次 ≥ 总数/2 | 触发肾上腺素激增（取消惩罚1轮+速度×2，每战1次）|

## 动作经济

每轮：**1 标准**（攻击/急救/拖曳）+ **1 快速**（换弹/闪避/搜索）+ 自由动作
移动速度：AGI × 2m/轮

## 异能

```
能量池 = RSN × 3
能量恢复/休息轮 = RSN/3↓ + 1
主动异能 → 能量消耗 + 连续使用惩罚 + RSN临时+1 → 检查失控
失控检查：RSN+临时攀升 > WIL时
  差值1~2：轻度(PER/INT-1)
  差值3~4：中度(PER/INT-3)
  差值≥5：重度(每次主动异能投 d20+WIL修正 DC15→失败=失控)
```
